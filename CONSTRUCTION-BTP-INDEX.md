# 2. Méthode human-skills

Le prix du voucher n'est jamais assimilé au coût réel :

```text
exam_fee
mandatory_training
mandatory_credentials
application_fee
membership
first_cycle_tco
renewal_tco
```

Et le BTP oblige à distinguer plusieurs natures de preuve :

| Code | Nature | Exemple |
|---|---|---|
| **CERT** | certification de personne | AACE PSP, AWS CWI, BCSP CHST |
| **QUAL** | qualification / statut professionnel | MRICS, MCIOB, CEng |
| **ACC** | accréditation liée à un scheme | BREEAM Assessor, ProjectWise Accreditation |
| **REG** | habilitation / carte / exigence réglementaire | CACES, AIPR, SSIAP, CPCS |
| **COURSE** | certificat de parcours / éditeur | Procore, CITB SMSTS |
| **ORG** | qualification/certification d'entreprise | QUALIBAT, RGE, ISO organisation |

```text
assessment fee ≠ coût complet
course certificate ≠ certification professionnelle
CACES ≠ autorisation de conduite
formation habilitation électrique ≠ habilitation employeur
membership Chartered ≠ simple examen
qualification d'entreprise ≠ certification individuelle
```

# 3. Portée géographique — obligatoire

Convention complète : [`GEOGRAPHY.md`](GEOGRAPHY.md).

```text
🌍 INT   international / réellement portable
🇪🇺 EUR   Europe / multi-pays européen
🇫🇷 FR    France
🇺🇸 US    États-Unis / codes ou réglementation US
🇬🇧 UK    Royaume-Uni
🇨🇦 CA    Canada
🇦🇺 AU    Australie
🇳🇿 NZ    Nouvelle-Zélande
🇩🇪 DE    Allemagne
🇸🇬 SG    Singapour
```

**Origine de l'organisme ≠ portée du credential.** Un organisme américain peut délivrer une certification internationale ; inversement, un credential connu mondialement peut rester fondé sur un code US.

### Règle de recommandation France

Pour une personne travaillant en France, ordre de priorité :

```text
🇫🇷 FR réglementaire nécessaire au poste
        ↓
🇪🇺 EUR / qualifications européennes pertinentes
        ↓
🌍 INT portable et valorisable
        ↓
🇬🇧 UK si marché UK / valeur Chartered recherchée
        ↓
🇺🇸 US uniquement si technologie, norme, client ou projet le justifie
```

Une certification `US` ne doit donc plus apparaître dans une shortlist française sans une phrase expliquant **pourquoi elle reste utile hors États-Unis**.

# 18. Watchlist résiduelle

Après la classification géographique, le reliquat est surtout juridictionnel ou constructeur/éditeur :

```text
licences d'architecte / Professional Engineer / surveyor par pays ou État
rail competence schemes par pays
qualifications artisanales nationales
certifications fabricants de systèmes constructifs / HVAC / fire / roofing
catalogues Bentley supplémentaires avec assessment formel
local roadway certifications hors ATSSA
```

Une entrée ne bascule dans le catalogue actif qu'après vérification de :

```text
source officielle
credential encore actif
nature CERT / QUAL / ACC / REG / COURSE / ORG
scope international / europe / national
jurisdiction / regulatory_basis éventuelle
portabilité France / Europe
formation et prérequis obligatoires
TCO initial
renouvellement / CPD
```
