# 4. Ce qu'un dirigeant de groupe doit comprendre sans devenir intégrateur

| Fonction | Comprendre / contrôler | Déléguer ou spécialiser |
|---|---|---|
| LBO | leverage, IRR, covenants, downside | structuration juridique/fiscale |
| Private credit | dette senior, unitranche, sûretés, headroom | documentation / négociation spécialisée |
| Consolidation | périmètre, éliminations, KPI, close | implémentation comptable/EPM complexe |
| Treasury | liquidité, funding, FX/taux, pooling | architecture bancaire / fiscalité |
| CorpDev | pipeline, valo, LOI, DD, synergies | expertises DD |
| PMI | gouvernance, Day 1, synergies | workstreams techniques |
| Carve-out | périmètre, TSA, stranded costs, exit | séparation juridique/IT/RH complexe |
| Sell-side | QoE, normalized EBITDA, data room | VDD / tax / legal reports |
| TMS / SWIFT / EPM | besoins et architecture cible | certification éditeur / intégration |

# 5. Credentials pivots

À utiliser uniquement lorsque le contexte les justifie :

```text
CFI FMVA / CBCA / FPAP / IB & PE
CFA Private Markets / Private Equity
ACT CertTF / AwardICM / CertICM
AFP CTP
ACCA CertIFR / DipIFR
IMAA International M&A / CPMI / SCDE
WorldCC
CIPS / CPSM
Oracle EPM / OneStream si plateformes utilisées
SWIFT / Kyriba si stack réellement déployée
INSEAD / IoD pour gouvernance avancée
```

La règle reste : **ne pas transformer un patron de groupe en consultant produit pour le plaisir d'empiler des badges**.

---

# 6. France first sur les sujets juridiques et fiscaux

Toujours faire valider localement :

- holding animatrice / passive ;
- mère-fille / intégration fiscale ;
- déductibilité des intérêts ;
- management fees ;
- conventions réglementées ;
- conventions de trésorerie ;
- prix de transfert ;
- sûretés ;
- fiscalité d'acquisition / cession ;
- Dutreil / transmission ;
- TSA et contrats de séparation.

Les credentials internationaux apportent la **méthode métier**, pas le droit français.
