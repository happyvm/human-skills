# Roadmap human-skills

> Construire progressivement un profil équilibré entre **technique, architecture, management, projet, risque, business, communication et anglais**.
>
> **Dernière mise à jour : 28 août 2026**

## Principe

La roadmap privilégie d'abord les credentials gratuits à bonne valeur CV, puis les certifications payantes ayant le meilleur rapport valeur / coût.

L'objectif est d'éviter :

- 30 badges d'introduction redondants ;
- plusieurs certifications qui prouvent exactement la même chose ;
- des formations coûteuses sans examen reconnu ;
- une liste CV illisible.

# Budget recommandé

- anglais mesuré ;
- leadership ;
- risk management ;
- project management fundamentals ;
- cloud Oracle ;
- Microsoft Applied Skills ;
- Qualys ;
- business / RevOps.


```text

+ Terraform Associate
```

Exemple Architecture / Cloud :

```text
Terraform Associate
+ AWS Solutions Architect Associate

```

Exemple Management / Transformation :

```text
TOEIC
+ Scrum.org PAL I
```

Exemple Infrastructure :

```text

+ AWS Associate
```

> Les conversions et taxes peuvent varier : toujours contrôler le checkout final avant achat.

# Règle de présentation CV

Le CV ne doit pas afficher toute la collection.

Conserver seulement les certifications les plus pertinentes pour le poste ciblé et déplacer le reste vers LinkedIn ou une page de portfolio.

Exemple :

```text
CERTIFICATIONS

Architecture & Cloud
- AWS Certified Solutions Architect — Associate
- Oracle Cloud Infrastructure Architect Associate
- HashiCorp Certified: Terraform Associate

Infrastructure
- Microsoft credential / certification pertinente
- Linux Foundation / Kubernetes selon parcours

Management & Risk
- Scrum.org Professional Agile Leadership I
- Open University — Risk Management

Languages
- TOEIC — XXX/990
```
