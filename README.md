# human-skills

> Liste de certifications et credentials IT accessibles gratuitement, avec un focus sur les parcours qui ont une vraie valeur sur un CV ou LinkedIn.
>
> **Dernière mise à jour : 28 août 2026**

## Objectif

Le but de cette page est de distinguer :

- les **vraies certifications gratuites**, avec examen ou évaluation incluse ;
- les **credentials / Applied Skills** délivrés par un éditeur reconnu ;
- les **badges de formation**, intéressants mais généralement moins valorisables qu'une certification professionnelle.

L'objectif n'est donc pas d'accumuler des dizaines de badges sans intérêt, mais de construire un parcours cohérent couvrant **cloud, architecture, infrastructure, Windows, réseau, cybersécurité et IA** sans payer les examens.

# 1. Oracle University

## OCI Foundations Associate

Certification d'introduction à Oracle Cloud Infrastructure.

Elle permet de valider les fondamentaux :

- architecture OCI ;
- compute ;
- réseau ;
- stockage ;
- IAM ;
- sécurité ;
- haute disponibilité ;
- principaux services OCI.

### Intérêt

Très bon point d'entrée avant d'attaquer une certification d'architecture plus sérieuse.

**Priorité : ⭐⭐⭐⭐**

---

## OCI Architect Associate

Probablement le meilleur rapport **valeur / coût** de cette liste lorsque l'examen est proposé gratuitement par Oracle.

Cette certification couvre notamment :

- conception d'architectures OCI ;
- disponibilité et résilience ;
- réseau ;
- sécurité ;
- compute ;
- stockage ;
- bases de données ;
- choix d'architecture ;
- optimisation des services OCI.

### Pourquoi la passer

Contrairement à un simple badge de formation, il s'agit d'une certification d'architecture cloud de niveau Associate.

**Priorité : ⭐⭐⭐⭐⭐**

### Parcours recommandé

```text
OCI Foundations Associate
        ↓
OCI Architect Associate
```

# Ce qui n'est plus considéré comme gratuit

## ISC2 Certified in Cybersecurity (CC)

ISC2 a longtemps proposé son examen **Certified in Cybersecurity** gratuitement dans le cadre de son programme *One Million Certified in Cybersecurity*.

Cette gratuité ne doit plus être considérée comme acquise pour une nouvelle inscription en 2026.

Il faut donc vérifier le prix et les éventuelles nouvelles campagnes promotionnelles directement auprès d'ISC2 avant de l'ajouter à un parcours « 0 € ».

# Stratégie CV / LinkedIn

Il vaut mieux afficher les credentials de manière structurée que de remplir le CV avec une longue liste.

Exemple :

```text
CERTIFICATIONS & CREDENTIALS

Cloud & Architecture
- Oracle Cloud Infrastructure Architect Associate
- Oracle Cloud Infrastructure Foundations Associate
- Oracle OCI AI Foundations Associate

Microsoft Infrastructure
- Microsoft Applied Skills – Administer Active Directory Domain Services
- Microsoft Applied Skills – Configure secure access using Azure networking
- Microsoft Applied Skills – Deploy and configure Azure Monitor

Cybersecurity
- Qualys VMDR
- Qualys Policy Audit
- Fortinet Training Institute / NSE
- AttackIQ Academy – MITRE ATT&CK
```

Sur LinkedIn, chaque certification obtenue devrait être ajoutée individuellement dans **Licences et certifications**, avec :

- l'organisme émetteur ;
- la date d'obtention ;
- l'identifiant du credential lorsqu'il existe ;
- l'URL de vérification du badge ou certificat.

# Principe général

Une certification gratuite n'a d'intérêt que si elle renforce une trajectoire professionnelle lisible.

Le parcours proposé ici vise donc à construire progressivement le profil suivant :

```text
Infrastructure
    +
Cloud Architecture
    +
Microsoft / Azure
    +
Network
    +
Cybersecurity
    +
AI / Agentic AI
    =
Architecte IT hybride / multicloud
```
