# IT Certification Index — human-skills

> Index **IT-first** : certifications infrastructure, cloud, virtualisation, Linux, réseau, cyber, stockage, data, platform engineering, middleware, EUC, ITSM et AI infrastructure.
>
> Revue : **28 août 2026**.

## Méthode

Le dépôt distingue toujours :

```text
exam_fee
mandatory_training
mandatory_credentials
first_cycle_tco
renewal_tco
```

Un examen à 200 $ avec 3 000 € de formation obligatoire n'est donc **pas** classé comme une certification à 200 €. Les prix sont des références publiques : vérifier taxes, devise France/EMEA, version active et prérequis avant achat.
