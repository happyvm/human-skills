# Entrepreneur / TPE / PME Index — human-skills

> Vue entrepreneur de `human-skills` : **créer, vendre, piloter, financer, acquérir, intégrer, gouverner, séparer, transmettre et développer** une entreprise ou un groupe.
>
> Principe : **France / Europe first** quand le droit, la fiscalité ou une autorisation locale dominent ; meilleur credential mondial lorsque la compétence est portable ; certification éditeur seulement si l'outil est réellement utilisé.

# 7. Treasury groupe, cash pooling & bank connectivity

## Couche métier

| Besoin | Credential | TCO indicatif 2026 |
|---|---|---:|
| Treasury foundations | ACT CertTF | **1 215 £** hors TVA |
| Cash management entrée | ACT AwardICM | **1 215 £** hors TVA |
| International cash management | ACT CertICM | **2 890 £** hors TVA |
| Treasury corporate | AFP CTP | **925 $ membre / 1 320 $ non-membre early** sur dernière grille publique ; checkout à revérifier |

ACT est particulièrement lisible depuis l'Europe ; AFP CTP est une référence métier treasury plus large et institutionnelle.

## Cash pooling France

L'article L511-7 du Code monétaire et financier permet sous conditions les opérations de trésorerie entre sociétés liées par des liens de capital donnant un contrôle effectif.

```text
méthode treasury
→ ACT / CTP

convention de trésorerie / fiscalité / intérêt social / taux
→ revue professionnelle France
```

## De portails bancaires à une payment factory

```text
BANK PORTALS
     ↓
MULTI-BANK VISIBILITY
     ↓
TMS
     ↓
HOST-TO-HOST / API
     ↓
SWIFT FOR CORPORATES
     ↓
ISO 20022 / MX
     ↓
PAYMENT FACTORY / IN-HOUSE BANK
```

### SWIFT

Credentials à regarder uniquement si le groupe utilise réellement l'écosystème :

- Swift Certified Expert — ISO 20022 & CBPR+ Phase 1 ;
- Swift Certified Expert — Swift for Corporates Specialist: MX Messages ;
- Swift for Corporates Client Advisor pour les rôles appropriés.

Le prix public individuel n'est pas suffisamment stable pour enregistrer un faux TCO : **provider / institution dependent**.

### Kyriba

Kyriba Academy est une certification **éditeur** : New to Treasury, End User, Deep Dives, Kyriba Expert. À prendre si Kyriba est effectivement le TMS du groupe, pas comme substitut au CertTF / CTP.

Crosslink : [`certifications/entrepreneur-bank-connectivity-sellside-procurement-facilities-fleet-2026.md`](certifications/entrepreneur-bank-connectivity-sellside-procurement-facilities-fleet-2026.md).

# 11. IT / RH / Cyber post-acquisition

## IT

Day 1 : IAM, mail/collaboration, réseau, ERP, HRIS, CRM, endpoint, licences, backups, monitoring, contrats et données.

Il n'existe pas de credential universel « IT M&A » suffisamment fort pour remplacer l'expérience : CPMI + project/architecture + certifications des plateformes réellement utilisées.

## Cyber

Avant interconnexion : identité, comptes admin, EDR, MFA, sauvegardes, vulnérabilités exposées, incidents connus, tiers et conformité.

Ne pas connecter trop vite une cible potentiellement compromise au SI principal.

Crosslinks : `practical-cyber-under-500.md`, `cyber-premium-over-500.md`, `business-continuity-crisis.md`.

## RH

IMAA HR M&A Expert devient pertinent pour une DRH de groupe buy-and-build ; il couvre due diligence RH, PMI, compensation & benefits et people/culture.

# 12. Sell-side readiness, carve-out & TSA

## Préparer la vente avant la data room

```text
CLEAN BOOKS
   ↓
NORMALIZED EBITDA
   ↓
WORKING CAPITAL / NET DEBT
   ↓
CUSTOMER / SUPPLIER CONCENTRATION
   ↓
CONTRACTS / IP / HR / CYBER
   ↓
REAL ESTATE / FLEET / ASSETS
   ↓
DATA ROOM
   ↓
VENDOR DD / QoE
   ↓
MANAGEMENT PRESENTATION
   ↓
TRANSACTION
```

Il n'existe pas de « certification Vendor Due Diligence » magique. CFI / IMAA fournissent de bonnes méthodes ; la VDD / QoE reste une mission transactionnelle.

## Carve-out / TSA

```text
scope de séparation
      ↓
Day 1
      ↓
TSA
      ↓
IT / Finance / HR / Cyber separation
      ↓
stranded costs
      ↓
TSA exit
```

IMAA SCDE — Certified Separation, Carve-Out and Divestment Expert — couvre le cycle de séparation et le TSA. En août 2026 : **in-house / sur devis**, donc pas de faux prix recopié du CPMI.

Checklist TSA : service catalogue, owners, SLA, pricing, security/access, data, change control, billing, exit milestones, extensions, termination.

# 18. Le principe de délégation

```text
COMPRENDRE
   ↓
SAVOIR CONTRÔLER
   ↓
DÉCIDER
   ↓
EXÉCUTER OU DÉLÉGUER
```

| Fonction | À comprendre | Souvent à déléguer |
|---|---|---|
| Comptabilité | marge, cash, bilan, résultat | tenue / clôture / fiscalité |
| LBO | dette, IRR, covenants, downside | structuration juridique / fiscale |
| Treasury | liquidity, pooling, funding, FX/taux | documentation / fiscalité / TMS complexe |
| Bank connectivity | standards, controls, architecture | implémentation SWIFT / host-to-host / API |
| Groupe | capital allocation, KPI, intercompany | consolidation / fiscalité groupe |
| Acquisition | valo, risques, synergies | due diligence spécialisée |
| PMI | gouvernance, Day 1, synergies | workstreams experts |
| Procurement | spend, contrats, leverage | sourcing spécialisé / catégories complexes |
| Facilities | coûts, baux, backlog, critical assets | FM / immobilier technique |
| Fleet | TCO, usage, policy | opérations flotte / fiscalité locale |
| Sell-side | EBITDA, WC, data room, red flags | VDD / QoE / legal DD |
| Carve-out | périmètre, TSA, exit | juridique + séparation fonctionnelle complexe |
| EPM | process, controls, outputs | implémentation technique |
| Management fees | service, coûts, preuves | avocat + fiscaliste + expert-comptable |
| Transfer pricing | fonctions / risques / actifs | spécialiste TP |
| Cyber M&A | exposition, IAM, backup, incidents | forensic / architecture / remediation |
