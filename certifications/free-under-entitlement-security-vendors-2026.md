# Free security certifications under entitlement — 2026

> Revue : **28 août 2026**. Cette fiche regroupe les certifications réellement gratuites **uniquement si l'on possède déjà le bon statut client, partenaire ou interne**. Elles ne doivent pas être mélangées avec les certifications publiques gratuites accessibles à n'importe qui.

---

# 1. Sophos Partner certifications — gratuit pour les partenaires

Depuis le **1er octobre 2025**, Sophos annonce que **tout l'eLearning Partner Training est gratuit**, notamment les parcours menant aux certifications Architect.

Sophos précise :

- aucun coût ;
- aucun code promo ;
- aucune commande administrative ;
- accès direct depuis le Partner Portal ;
- les certifications actuelles sont reconnues dans le nouveau système de certification points ;
- badges Credly disponibles pour plusieurs réalisations.

Exemples explicitement cités :

- **Endpoint Architect** ;
- **Firewall Architect** ;
- Sales Professional ;
- autres certifications/technical learning paths du Partner Program.

```text
Training / certification path    0 $ pour partenaires
Public access                     non
Entitlement                       Sophos Partner
Badge                             Credly selon credential
```

Sophos a encore confirmé en décembre 2025 que **all Sophos training is now free** pour les équipes partenaires.

Sources :

- https://partnernews.sophos.com/en-us/2025/10/partner-program/unlock-more-partner-value-with-sophos-training-and-recognition/
- https://partnernews.sophos.com/en-us/2025/11/partner-program/earn-your-sophos-sales-professional-badge-no-cost-no-barriers/
- https://partnernews.sophos.com/en-us/2025/12/partner-program/whats-new-in-the-sophos-partner-program-december-2025-updates/

### Valeur

⭐⭐⭐⭐⭐ si l'employeur est partenaire Sophos.

# 2. Nozomi Networks NNCTSP — gratuit clients / partenaires / internes

## Nozomi Networks Certified Technical Sales Professional — NNCTSP

Le catalogue Nozomi décrit NNCTSP comme un programme :

```text
Prix             FREE
Format           self-paced / on-demand
Durée            ~2 h
Quiz             oui
Tentatives       3
Certificate      oui
```

Mais l'accès est réservé à :

- internes Nozomi ;
- clients ;
- partenaires.

Les clients doivent disposer d'un **Customer Support Portal Account** et les partenaires d'un **Partner Portal Account** avant accès à l'Academy.

Le credential sert aussi de préparation au parcours Nozomi Networks Certified Engineer.

Source :

- https://www.nozominetworks.com/downloads/Academy/Nozomi-Networks-Academy-Course-Catalog.pdf

### Valeur

⭐⭐⭐⭐ pour OT / ICS / cyber industrielle si l'entitlement existe.

# 4. Barracuda Campus — training gratuit, prix certification non confirmé

Barracuda Campus maintient :

- centaines de cours on-demand gratuits ;
- certifications industry-recognized ;
- comptes Campus gratuits ;
- examens associés à certains parcours.

Cependant, la documentation publique 2026 consultée ne permet pas de prouver que **les certification exams eux-mêmes sont systématiquement gratuits**.

Donc :

```text
Training          gratuit
Campus account    gratuit / business identity requise
Certification     programme actif
Exam fee          non confirmé publiquement
```

**Ne pas classer Barracuda comme certification gratuite générale tant que le checkout / portail ne confirme pas 0 $.**

Source :

- https://campus.barracuda.com/

# 5. Tenable — cours gratuits, certifications payantes

```text
Free course             oui selon cours
```

Les certifications Tenable VM / Security Center / OT ne doivent donc pas être classées gratuites.

# 6. KnowBe4 — training certificates, pas certification gratuite publique

KnowBe4 délivre des certificats après les formations assignées par une organisation et propose divers badges Learner Experience.

Mais :

- l'accès est lié à une campagne / organisation ;
- ces certificats prouvent une complétion de formation ;
- aucune certification professionnelle technique gratuite publique n'a été confirmée.

À ne pas confondre avec une certification vendor indépendante.

Sources :

- https://support.knowbe4.com/hc/fr-fr/articles/227567208
- https://support.knowbe4.com/hc/fr-fr/articles/360011915933

# Règle de classement

```text
Public + exam free              → free-it.md
Partner/customer + exam free    → cette fiche
Training free + exam paid       → pas gratuit
Training certificate only       → completion credential
Price unknown                   → watchlist, pas "free"
```

Cette séparation évite un des problèmes les plus fréquents des listes de certifications gratuites sur Internet : confondre **formation gratuite**, **entitlement déjà payé par l'entreprise** et **examen réellement gratuit pour le public**.
