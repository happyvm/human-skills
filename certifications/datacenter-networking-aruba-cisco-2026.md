# Cisco — spécialiste Data Center à 300 $

Cisco permet d'obtenir des **Specialist certifications autonomes** en réussissant une concentration CCNP, même sans compléter le CCNP Data Center.

Chaque concentration :

- **300 $** ;
- aucun prérequis ;
- validité : 3 ans ;
- compte également comme concentration vers CCNP Data Center.

Source :

- https://www.cisco.com/site/us/en/learn/training-certifications/certifications/datacenter/ccnp-data-center/index.html

# CCNP Data Center

Le titre complet demande :

- core `350-601 DCCOR` — **400 $** ;
- une concentration — **300 $**.

```text
DCCOR             400 $
Concentration     300 $
----------------------
CCNP DC minimum   700 $
```

Source :

- https://www.cisco.com/site/us/en/learn/training-certifications/certifications/datacenter/ccnp-data-center/index.html

Le core DCCOR donne également automatiquement :

**Cisco Certified Specialist – Data Center Core**.

Donc même une seule tentative réussie à 400 $ produit déjà un credential Specialist.

---

# CCIE Data Center

Le DCCOR sert également de qualification écrite pour la voie CCIE Data Center.

Tarifs Cisco généraux :

- core : **400 $** ;
- CCIE lab : **1 600 $** en centre ;
- certains mobile lab formats peuvent atteindre **1 900 $**.

Source :

- https://www.cisco.com/site/us/en/learn/training-certifications/certifications/faq.html

TCO minimal examen :

```text
DCCOR          400 $
CCIE Lab     1 600 $
------------------
Minimum     2 000 $
```

hors voyage / retake / formation.
