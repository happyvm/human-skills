# 2. IBM z/OS Mainframe Practitioner — gratuit

IBM maintient un **IBM z/OS Mainframe Practitioner** dont la fiche Credly actuelle affiche :

```text
Issuer          IBM
Type            Learning
Level           Intermediate
Cost            Free
```

Le credential valide des compétences hands-on sur un **live IBM Z server**.

Domaines :

- IBM Z hardware/software ;
- z/OS ;
- commands ;
- panels ;
- security ;
- system administration ;
- TSO ;
- system operations.

Pour l'obtenir, il faut terminer les cours et réussir les assessments des badges requis, notamment :

- Introduction to IBM z/OS ;
- Introduction to z/OS Commands and Panels ;
- Introduction to System Programming on IBM Z ;
- parcours Practitioner correspondant.

IBM propose également un learning path `IBM Z System Administrator` avec plusieurs assets **No cost** pour préparer ce credential.

### Attention aux homonymes

Il existe aussi un ancien / autre **z/OS Mainframe Practitioner** lié à Coursera, classé `Cost Paid`.

Le credential intéressant ici est la version **Issued by IBM / Cost Free**.

Sources :

- https://www.credly.com/org/ibm/badge/ibm-z-os-mainframe-practitioner
- https://www.ibm.com/training/learning-path/ibm-z-system-administrator-306
