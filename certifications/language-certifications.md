# 1. TOEIC

## Listening & Reading

ETS France affiche en août/septembre 2026 à Paris :

- **189 €** ;
- test 2 heures ;
- attestation digitale incluse ;
- sessions fréquentes chez ETS France et centres partenaires.

Source :

- https://www.etsglobal.org/fr/fr/session/search/ile-de-france/paris

### Nature du credential

Le TOEIC fournit un **score**, non une certification de compétence à vie.

Les résultats TOEIC sont généralement utilisés comme preuve récente du niveau professionnel et ETS communique une période de validité / pertinence limitée pour les scores.

**Valeur : ⭐⭐⭐⭐⭐** en France pour CV / recrutement / écoles.

# 4. Cambridge B2 / C1 / C2

## B2 First

- recommandé : **285 €** ;
- niveau CECR B2 ;
- diplôme international ;
- reconnu notamment dans des contextes académiques et professionnels.

## C1 Advanced

- recommandé : **295 €** ;
- accepté par de nombreuses universités et organisations internationales.

## C2 Proficiency

- recommandé : **305 €** ;
- plus haut niveau Cambridge généraliste.

Contrairement à un test de score type TOEIC/IELTS, le **certificat Cambridge n'a pas d'expiration formelle**. Une institution peut néanmoins exiger un résultat obtenu récemment.

Sources :

- https://www.cambridgeenglish.org/fr/exams-and-tests/first/tarif-cambridge-english-first-fce/

# 5. EF SET

Le **EF SET 4 Skills** reste un des meilleurs credentials linguistiques gratuits :

- reading ;
- listening ;
- speaking ;
- writing ;
- CEFR / CECR A1–C2 ;
- certificate shareable.

Prix : **0 €**.

Source :

- https://www.efset.org/

À utiliser comme preuve gratuite / baseline, sans prétendre qu'il remplace systématiquement TOEIC, IELTS ou Cambridge pour les institutions qui exigent un test spécifique.
