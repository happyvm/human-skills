# Free IaC, platform & orchestration credentials — 2026

> Revue : **28 août 2026**. Fiche dédiée aux certifications et badges évalués gratuits en Infrastructure as Code, platform engineering et process orchestration.

---

# 1. Pulumi Practitioner — Foundational

Le credential **Pulumi Practitioner - Foundational** est actuellement publié par Pulumi/Credly comme :

```text
Type          Certification
Level         Foundational
Cost          Free
Time          Days
Issuer        Pulumi
```

Le titulaire démontre des compétences sur :

- Infrastructure as Code ;
- Pulumi programs/components ;
- providers ;
- AWS / Azure / GCP ;
- CI/CD ;
- self-service infrastructure ;
- policy as code ;
- Pulumi Cloud ;
- platform engineering best practices.

## Critère

Le badge indique comme Certification Criteria :

- suivre une formation **multi-day, hands-on** couvrant les compétences ci-dessus.

Pulumi propose régulièrement des workshops gratuits, et Pulumi Cloud Individual est lui-même gratuit sans carte bancaire pour l'apprentissage.

```text
Credential cost       0 $
Hands-on              oui
Pulumi Cloud learning 0 $ pour individu
```

### Valeur

⭐⭐⭐⭐⭐ pour IaC / platform engineering.

Sources :

- https://www.credly.com/org/pulumi/badge/pulumi-practitioner-foundational
- https://www.pulumi.com/workshop-signup/
- https://www.pulumi.com/pricing/

> Vérifier le calendrier des workshops / learning events Pulumi : le badge est gratuit, mais son earning criterion passe par la formation hands-on correspondante.

# 4. Akuity — Argo CD learning gratuit, pas CAPA gratuite

Akuity Academy propose actuellement :

- `Introduction to CD and GitOps with Argo CD` — **Free**.

Mais le véritable examen CNCF **Certified Argo Project Associate (CAPA)** reste :

```text
Prix      250 $
Proctored oui
```

Donc :

```text
Akuity course      gratuit
CAPA certification payante
```

Sources :

- https://academy.akuity.io/
- https://www.cncf.io/training/certification/capa/

Ne pas recycler les anciennes campagnes Codefresh/Akuity comme certification Argo gratuite permanente.
