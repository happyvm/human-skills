# 1. Jamf

Jamf est particulièrement intéressant pour ajouter une vraie brique **Apple enterprise / MDM / endpoint security** à faible coût.

**Auto-formation officielle et gratuite :** [training.jamf.com](https://training.jamf.com/) — cours 100/140/170 self-paced et gratuits, base des certifications.

## Associate — 100 $

Les tracks self-paced 100 / 140 / 170 mènent aux certifications Associate :

- **Jamf Certified Associate - Jamf Pro** ;
- **Jamf Certified Associate - Jamf School** ;
- **Jamf Certified Associate - Jamf Protect**.

Le Jamf Pro Associate exam coûte **100 USD**.

Caractéristiques :

- cours Jamf 100 self-paced gratuit ;
- examen online ;
- 50 QCM ;
- 60 minutes ;
- seuil : 80 % ;
- une tentative par achat ;
- retake achetable après 7 jours ;
- certification Associate : **n'expire pas** selon la grille Jamf 2026.

Le Jamf School Associate est également affiché à **100 $**.

## Niveaux supérieurs

Jamf maintient aussi :

- Jamf 200 — Certified Tech ;
- Jamf 240 — Certified Tech, Jamf School ;
- Jamf 270 — Certified Tech, Jamf Protect ;
- Jamf 300 — Certified Admin ;
- Jamf 370 — Certified Admin, Jamf Protect ;
- Jamf 400 — Certified Expert.

Ces niveaux sont associés à des formations Instructor-Led et ne doivent pas être classés sur le seul prix d'un examen.

Validité : généralement **3 ans** pour 200+ dans le programme 2026.

Sources :

- https://support.jamf.com/en/articles/13180165-jamf-training-courses-certifications
- https://learn.jamf.com/r/en-US/jamf-100-course-current/About_the_Exam
- https://training.jamf.com/jamf-certified-associate-exam-english-en
- https://www.jamf.com/training/

# 2. Omnissa

Omnissa publie une règle extrêmement simple :

> **All certification exams are priced at 250 USD.**

Les credentials Omnissa sont valides **2 ans**.

Le portefeuille 2026 comprend notamment des credentials autour de :

- Horizon ;
- Workspace ONE ;
- platform engineering / administration ;
- **Omnissa Certified Platform Engineer (OCPE)** ;
- autres tracks publiés dans Clarus.

Les examens se réservent via Clarus puis Pearson VUE.

### Verdict

À **250 $**, Omnissa est une certification très cohérente pour les profils VDI/EUC venant de l'écosystème VMware Horizon / Workspace ONE.

Source :

- https://www.omnissa.com/learning/

# 3. Citrix

Citrix a migré son programme sur **Webassessor** et maintient des certifications Virtual Apps and Desktops ainsi que NetScaler/App Delivery & Security.

**Portail officiel :** [citrix.com/training-and-certifications](https://www.citrix.com/training-and-certifications/).

## Prix

La FAQ certification Citrix publiée récemment indique :

```text
Standard / Associate proctored exam    200 $
Premium / Expert proctored exam        300 $
```

Le programme actuel expose notamment :

### Virtual Apps and Desktops

- **CCA-V — Citrix Certified Associate - Virtualization** ;
- **CCP-V — Citrix Certified Professional - Virtualization**.

### NetScaler / App Delivery and Security

- CCA-AppDS Gateway ;
- CCA-AppDS Traffic Management ;
- CCP-AppDS Advanced Features.

Les certifications sont valides **2 ans** selon la FAQ actuelle et la recertification par simple formation a été supprimée : il faut repasser l'examen pertinent.

### ROI

Citrix reste intéressant sous 500 $ :

```text
CCA-V    200 $
CCP-V    300 $  + prerequisite Associate
```

Attention : le **TCO from-zero** pour Professional inclut donc au moins deux examens si le candidat ne possède pas déjà l'Associate.

Sources :

- https://www.citrix.com/training-and-certifications/
- https://www.citrix.com/content/dam/citrix61/en_us/documents/citrix-certification-faqs-2025.pdf

# 4. Parallels RAS

Parallels maintient des certifications telles que :

- **Parallels RAS Technical Professional (TP)** ;
- **Parallels RAS Technical Professional Advanced (TPA)** ;
- certifications Sales / Pre-Sales selon portail.

Le TP exige la formation/learning path et la réussite de l'examen Parallels Learning & Certification Academy.

En France, un partenaire affiche en 2026 un parcours TPA d'une journée à **1 750 € HT**, examen inclus, avec TP comme prérequis.

### Verdict

Parallels RAS est bien un vrai credential mais n'est **pas** à classer automatiquement sous 500 € pour un candidat français sans entitlement partenaire.

Sources :

- https://www.credly.com/org/parallels/badge/parallels-ras-technical-professional-tp
- https://miel.catalogueformpro.com/4/formation-parallels/3058381/parallels-ras-technical-professional-advanced-ras-tpa
