# 1. Niveaux IPC

## CIS — Certified IPC Specialist

Orientation :

- opérateurs ;
- techniciens ;
- inspecteurs ;
- personnes appliquant directement le standard.

## CSE — Certified Standards Expert

Niveau plus approfondi pour :

- lead technicians ;
- référents qualité ;
- personnes arbitrant l'interprétation du standard.

## CIT — Certified IPC Trainer

Permet de former / certifier des CIS dans le cadre du programme IPC selon les règles applicables.

Le TCO est donc naturellement bien supérieur au niveau CIS.

# 2. IPC-A-610 — Acceptability of Electronic Assemblies

Un des standards les plus courants de l'industrie pour l'acceptabilité des assemblages électroniques.

Chez CTTi, centre IPC licencié, les formations comparables sont annoncées à partir d'environ **1 305 $** pour le niveau CIS.

Compétences :

- inspection ;
- critères d'acceptabilité ;
- défauts d'assemblage ;
- classes 1 / 2 / 3 ;
- composants / PCB / soldering quality.

# 6. TCO

IPC est un excellent cas où le coût ne doit pas être réduit à « exam fee » :

```text
training center
+ standard / copyrighted material
+ workmanship kits
+ exam
+ éventuelle pratique
+ recertification tous les 2 ans
```

Les prix peuvent varier significativement selon :

- pays ;
- centre ;
- standard inclus ou non ;
- pratique ;
- présentiel / virtual ;
- niveau CIS/CSE/CIT.
