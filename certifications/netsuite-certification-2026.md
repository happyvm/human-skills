# Oracle NetSuite certifications — 2026

> **Angle mort comblé lors de cette revue** : NetSuite (ERP cloud le plus déployé au monde selon Oracle, forte base installée PME/ETI) n'avait aucune mention dans tout le dépôt, malgré 7 certifications actives.

---

# SuiteFoundation — prix confirmé par plusieurs sources convergentes

```text
SuiteFoundation (1Z0-1003)    250 $
```

Prérequis de fait pour la plupart des certifications avancées (bien que non systématiquement imposé techniquement). Corroboré par plusieurs guides indépendants convergents ; la page officielle `oracle.com/education` n'a pas pu être consultée directement lors de cette revue (redirections/contenu non exploitable) — à reconfirmer au moment de l'inscription.

---

# Certifications avancées — prix non confirmé, sources contradictoires

**Statut : recherché 2026-08-30, sans résultat fiable.** Deux guides tiers indépendants se contredisent sur le prix des certifications avancées :

- l'un indique un tarif **uniforme de 250 $** pour les 7 certifications (Foundation, Administrator, ERP Consultant, SuiteAnalytics User, SuiteCloud Developer I/II, Financial User) ;
- l'autre indique **250 $ pour Foundation, mais 400 $** pour Administrator / ERP Consultant / SuiteCloud Developer.

```text
Certified Administrator (1Z0-997)          250 $ ou 400 $ — non tranché
Certified ERP Consultant (1Z0-1050)        250 $ ou 400 $ — non tranché
Certified SuiteAnalytics User (1Z0-324)    250 $ (une seule source)
SuiteCloud Developer I (1Z0-231)           250 $ ou 400 $ — non tranché
SuiteCloud Developer II (1Z0-232)          250 $ (une seule source)
Certified Financial User (1Z0-334)         250 $ (une seule source)
```

Ne pas trancher arbitrairement — à revérifier directement sur `oracle.com/education` au moment de l'inscription, ou dans ~6 mois.

Source :

- https://www.brokenrubik.com/blog/netsuite-certifications-guide
- https://suitepedia.com/basics/netsuite-certification-pricing/

# À poursuivre

- confirmation directe sur oracle.com/education (page non exploitable lors de cette revue) ;
- format d'examen exact (nombre de questions, durée, score de passage) — non trouvé, aucune source consultée ne le détaillait ;
- politique de retake exacte (une source indique 14 jours d'attente, une autre un tarif retake de 150–200 $ voire 250 $ selon la source — également contradictoire).
