# Cloudflare — nouveau programme certification 2026

Cloudflare lance en 2026 des certifications techniques officielles dans le cadre de **Cloudflare University**.

Les deux certifications confirmées :

- **Application Security Associate** ;
- **Zero Trust Associate**.

**Prix confirmé :** University Pass à **495 $** (early bird), incluant l'accès aux sessions de formation Application Security / Cloudflare One-Zero Trust et **une tentative pour chacun des deux examens**.

**Disponibilité :** au moment de la revue, ces certifications sont **exclusivement liées à la conférence Cloudflare Connect 2026** (19–21 octobre, San Francisco) — pas de parcours d'examen indépendant en ligne identifié. À vérifier si un accès standalone apparaît après l'événement.

Source :

- https://www.cloudflare.com/connect/cloudflare-university/

---

## Cloudflare Connect 2026 — bundle public

À Cloudflare Connect 2026 (San Francisco) :

**Cloudflare University Pass : 495 $**.

Le pass inclut :

- live technical training Application Security ;
- Cloudflare One / Zero Trust training ;
- **une tentative Application Security Associate** ;
- **une tentative Zero Trust Associate** ;
- proctoring sur place.

Source :

- https://www.cloudflare.com/connect/cloudflare-university/

### Coût par credential implicite

Impossible de séparer honnêtement :

```text
495 $
= training
+ 2 exam attempts
+ event delivery
```

Il ne faut donc pas écrire `Cloudflare exam = 247.50 $` : ce serait une division artificielle d'un bundle.

## Exam-only Cloudflare

La FAQ événementielle mentionne la possibilité / question de prendre un exam sans University Pass, mais au moment de la revue la page publique indexable ne donne pas de **prix universel exam-only** suffisamment clair.

Statut :

```yaml
Application Security Associate: ACTIVE-2026
Zero Trust Associate: ACTIVE-2026
public_bundle: 495 USD event
exam_only_public_price: TBD
```

Cloudflare avait historiquement des **Accredited Configuration Engineer / Services Architect** pour partenaires, mais ces accreditations ne doivent pas être confondues avec les nouvelles Associate certifications publiques.
