# 1. SQFI — Safe Quality Food

## Certified SQF Practitioner

SQFI propose désormais un credential individuel **Certified SQF Practitioner**.

Tarif :

- application + registration + examen : **250 $** ;
- annual recertification : **175 $**.

Le TCO est donc faible la première année mais le maintien annuel devient une part importante du coût long terme.

Source :

- https://www.sqfi.com/training-events/search-for-training/certified-sqf-practitioner-credential

## Advanced SQF Practitioner Exam

- prix : **85 $**.

Attention : SQFI précise qu'un examen isolé ne suffit pas nécessairement à qualifier une personne comme practitioner sur un site ; distinguer **credential individuel** et exigences de rôle dans le système SQF.

Source :

- https://www.sqfi.com/training-events/our-training/exams

## Training Program

Le bundle de sept cours self-paced est affiché à **899 $**.

Source :

- https://www.sqfi.com/training-events/search-for-training/course/sqf-edition-10--practitioner-training-program

# 2. FSPCA — Preventive Controls / PCQI

Le cursus FSPCA est utilisé dans le contexte FSMA / FDA.

**Portail officiel :** curriculum FSPCA dispensé via des organismes agréés (NSF, SGS, SCS Global…) ; pas de couche gratuite officielle identifiée.

## Preventive Controls for Human Food — PCQI v2.0

### Part 1

- self-paced ;
- **299 $**.

### Part 2

- instructor-led ;
- prix variable selon provider.

La certification / attestation officielle FSPCA suit un curriculum standardisé reconnu par la FDA dans son contexte réglementaire.

Source :

- https://www.fspca.net/pchf-pcqi-v2-0

# 3. ICC Academy — International Chamber of Commerce

## Incoterms 2020 Certificate

La certification officielle ICC comprend :

- 6 mois d'accès ;
- 7 leçons ;
- study guide ;
- examen online de 1 h ;
- 70 % requis ;
- certificat digital ICC.

Prix :

- **399 $** sur ICC Academy ; — 🇺🇸 US
- store européen observé : **380 €** ;
- bundle avec eBook : **429 $ / 410 €**.

Sources :

- https://academy.iccwbo.org/incoterms/certifications/incoterms-2020-certificate/
- https://2go.iccwbo.org/explore-our-products/certificates/icc-academy-certificates.html

## Export / Import Certificate

Le store ICC Knowledge 2 Go affiche également un certificat Export/Import autour de **670 €**.

## CDCE — Certified Documentary Credits Expert

Le store affiche **1 060 €**.

Pertinent pour :

- trade finance ;
- letters of credit ;
- documentary credits ;
- banking / international trade.

# 4. IATA Dangerous Goods Regulations

Les prix varient fortement selon la fonction et le niveau.

## General Cargo e-learning

Exemple actuel :

- 4 h e-learning ;
- **170 $**.

## Processing DG Consignments — Initial

- virtual classroom ;
- **2 250 $** catalogue sur sessions 2026 observées.

## Accepting DG Consignments — Initial

- 5 jours / 40 h ;
- **2 380 $** sur Amsterdam / Genève / Miami observés.

Il faut donc éviter de parler d'une unique « certification IATA DGR » : le cursus dépend de la fonction CBTA.

Sources :

- https://www.iata.org/en/training/subject-areas/dangerous-goods-regulations-courses/
- https://www.iata.org/en/training/courses/dgr-cargo-accepting/dgc002elen01/en/
- https://www.iata.org/en/training/courses/accepting-dgr-initial/dgc019veen01/en/

# 5. BRCGS

BRCGS dispose d'un large portefeuille de formations :

- Food Safety ;
- auditor ;
- lead auditor ;
- sites / manufacturers ;
- packaging ;
- storage & distribution.

Les prix sont souvent dépendants du partenaire de formation, du pays et du format. Le catalogue doit donc conserver les formations BRCGS comme **provider-dependent** tant qu'un prix final individuel France / Europe n'est pas stabilisé.

Source :

- https://www.brcgs.com/training/

# 6. Rapport valeur / prix

## International trade généraliste

**ICC Incoterms Certificate — 380 €** est un credential assez propre : organisme normatif directement associé aux règles Incoterms, cursus court, examen vérifiable.

## Food safety

**Certified SQF Practitioner — 250 $** est remarquablement accessible, mais son renouvellement **175 $/an** doit être intégré au TCO.

## Dangerous Goods

Les petits modules IATA peuvent être très accessibles ; les qualifications opérationnelles complètes grimpent rapidement à **2 k$+**.
