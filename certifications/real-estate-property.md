# 1. RICS — Royal Institution of Chartered Surveyors

RICS est une qualification professionnelle / membership institution plutôt qu'un simple examen unique.

Le coût dépend :

- du pays ;
- de la route ;
- du grade ;
- des assessment fees ;
- de la candidate subscription ;
- de l'election fee ;
- de la subscription annuelle après qualification.

---

# 2. RICS Chartered — France 2026

Pour la zone Europe incluant la France, RICS affiche :

## Chartered Assessment

Routes concernées :

- APC including Preliminary Review ;
- Senior Professional ;
- Specialist ;
- Academic.

Frais :

- assessment : **774 €** ;
- candidate subscription 2026 : **212 €**.

Premier ticket candidat :

```text
Assessment             774 €
Candidate subscription 212 €
----------------------------
≈ 986 €
```

avant éventuels frais de formation, préparation, retake ou expérience professionnelle.

## Après qualification

- Chartered Election Fee Europe : **193 €** ;
- Professional Member / MRICS subscription France 2026 : **705 €/an** ;
- Fellow / FRICS : **858 €/an**.

Sources :

- https://www.rics.org/join-rics/join-fees
- https://www.rics.org/renew-my-membership/professional-fees

---

# 3. RICS Associate — France

## Assessment

- Associate Assessment : **104 €** ;
- candidate subscription : **162 €**.

```text
104 + 162 = 266 €
```

avant autres coûts.

## Après qualification

- Associate Election Fee : **141 €** ;
- Associate annual subscription France : **319 €/an**.

Le ticket d'entrée est donc nettement plus faible que MRICS, mais il s'agit d'un grade différent.

---

# 4. Recognised Professional Qualification routes

Pour les personnes possédant déjà une qualification professionnelle reconnue, RICS publie des routes spécifiques.

France / Europe 2026 :

## Chartered RPQ

- fee : **193 €** ;
- subscription : **705 €**.

## Associate RPQ

- fee : **141 €** ;
- subscription : **319 €**.

Ces routes ne sont pas disponibles à tout le monde : elles dépendent d'une qualification professionnelle reconnue par RICS.

# 5. CCIM — Certified Commercial Investment Member

Le CCIM est un parcours de commercial real estate / investment analysis.

Core curriculum :

- CI 101 — Financial Analysis ;
- CI 102 — Market Analysis ;
- CI 103 — User Decision Analysis ;
- CI 104 — Investment Analysis ;
- negotiations ;
- ethics ;
- electives ;
- qualifying portfolio ;
- comprehensive examination.

### Important — international membership

La grille globale de cursus utilise une cotisation de référence US à 695 $, mais CCIM publie séparément ses dues candidat :

- US : **695 $/an** ;
- Canada : **420 $/an** ;
- **International : 195 $/an**.

Un résident France relève donc potentiellement du tarif international pour le membership, sous réserve de satisfaire la règle de résidence hors US/Canada au moins neuf mois par an.

Sources :

- https://www.ccim.com/membership-and-tools/become-member/candidate-membership
- https://www.ccim.com/membership-and-tools/become-member/guidelines-use-candidate-membership

Il serait donc incorrect de présenter **8 286 $ comme le TCO France exact** : les cours, formats, electives et membership régional doivent être recalculés au moment du parcours.

# 7. Maintien du titre CCIM

Pour utiliser le CCIM designation, le professionnel doit rester **member in good standing**.

Dues Designee publiés :

- US : **799 $** ;
- Canada : **500 $** ;
- International : **195 $**.

Source :

- https://www.ccim.com/membership-and-tools/become-member/guidelines-use-designation-membership

# 9. TCO

Les deux programmes illustrent parfaitement deux formes de credential :

```text
RICS
assessment
+ annual professional subscription
+ professional experience / route
```

versus :

```text
CCIM
multi-course curriculum
+ membership
+ portfolio
+ exam/review
+ ongoing designation membership
```
