# Entrepreneur — certifications fonctionnelles internationales utiles depuis la France 2026

> Un credential étranger n'est pas automatiquement « hors sujet » pour un entrepreneur français.
>
> Ce catalogue sélectionne les certifications et formations certifiantes étrangères qui apportent une **compétence portable** : vente, marketing, finance, opérations, contrats, RH, privacy, qualité, CRM et commerce international.
>
> La règle est inverse pour les credentials fortement dépendants d'un droit local : on les garde comme référence, mais on ne les recommande pas comme substitut à la réglementation française.

---

# 0. Comment lire la pertinence France

| Niveau | Lecture |
|---|---|
| **TRÈS HAUTE** | compétence directement réutilisable en France, peu dépendante d'une juridiction |
| **HAUTE** | très utile, avec éventuellement adaptation aux pratiques françaises |
| **MOYENNE** | intéressante si l'entreprise utilise le produit, le marché ou le contexte concerné |
| **FAIBLE** | trop spécialisée ou trop dépendante d'un contexte étranger pour un dirigeant français généraliste |

La colonne `Portée` reste géographique ; `Pertinence FR` répond à une autre question :

```text
Est-ce que ce credential vaut le temps / l'argent
pour un entrepreneur opérant depuis la France ?
```

# 2. Finance, comptabilité & lecture des chiffres

## Xero — excellente formation certifiante pour comprendre les workflows

Xero propose **trois niveaux de certification**, à passer dans l'ordre :

| Credential | Niveau | Durée indicative | Coût | Renouvellement | Pertinence FR | Portée |
|---|---|---:|---:|---|:---:|:---:|
| Xero Associate — Level 1 | fondations setup / usage | 1–2 h | **0 €** | 12 mois | HAUTE | 🌍 INT |
| Xero Professional — Level 2 | bonnes pratiques | 4–5 h | **0 €** | 12 mois | HAUTE | 🌍 INT |
| Xero Specialist — Level 3 | reporting, multi-devise, projets, inventaire, immobilisations | 6–8 h | **0 €** | 12 mois | HAUTE | 🌍 INT |

Xero permet aussi une route **assessment only** pour les utilisateurs expérimentés ; le seuil de réussite est 80 %.

### Pourquoi c'est intéressant en France

La valeur n'est **pas** d'apprendre la fiscalité française.

La valeur est d'apprendre :

- factures clients/fournisseurs ;
- rapprochement bancaire ;
- plan de comptes ;
- cash ;
- reporting ;
- multi-devise ;
- immobilisations ;
- suivi de projet ;
- qualité de la donnée financière.

Autrement dit : apprendre le **système d'information financier d'une PME**.

Source :
- https://central.xero.com/s/article/Become-Xero-advisor-certified

## QuickBooks Online ProAdvisor

**CERT / vendor certification — 🌍 INT · US-centric**

Le programme ProAdvisor donne accès aux formations et certifications via QuickBooks Online Accountant.

### Parcours observé en 2026

- QuickBooks Online Certification Level 1 ;
- QuickBooks Online Certification Level 2 ;
- certifications / badges additionnels selon le catalogue ProAdvisor ;
- recertification annuelle pour conserver le statut.

Le programme ProAdvisor est annoncé **gratuit** pour les professionnels comptables utilisant QuickBooks Online Accountant dans les régions où il est proposé.

### Point important pour la France

QuickBooks est utile pour comprendre :

```text
facturation
bookkeeping workflow
accounts receivable / payable
reporting
automation comptable
```

mais **ne valide absolument pas** :

```text
PCG français
TVA française
liasse fiscale
droit comptable français
```

Le propre guide ProAdvisor rappelle d'ailleurs que le badge n'autorise pas à donner du conseil comptable/fiscal hors de sa compétence réglementaire locale.

Sources :
- https://quickbooks.intuit.com/accountants/proadvisor/
- https://quickbooks.intuit.com/accountants/training-certification/certification/
- https://quickbooks.intuit.com/learn-support/en-us/help-article/accountant-certification/sign-proadvisor-quickbooks-certification-courses/L18zzgR5K_US_en_US

**Pertinence entrepreneur France : MOYENNE / HAUTE** si activité anglophone, SaaS, international ou conseil.

# 9. RH — apprendre à devenir employeur sans étudier le droit US

## HRCI aPHRi — Associate Professional in Human Resources International

**CERT — 🌍 INT**

C'est presque exactement le credential étranger qu'il faut préférer à un `aPHR/PHR` centré US pour un entrepreneur français.

### Conditions

- **aucune expérience RH requise** ;
- conçu pour les personnes hors États-Unis ;
- HRCI le positionne aussi pour les personnes qui **gèrent des gens sans formation RH formelle**. — 🌍 INT

### Prix

```text
application fee   100 $
exam fee          300 $
-----------------------
first attempt     400 $
```

- validité : 3 ans ;
- maintenance : **45 HR recertification credits / 3 ans** ou repasser l'examen.

Source :
- https://www.hrci.org/certifications/individual-certifications/aphri

**Pertinence FR : HAUTE** après les premières embauches.

> Ne remplace évidemment ni le Code du travail français ni la paie française.

---

## HRCI PHRi

**CERT — 🌍 INT**

Plus professionnel que l'aPHRi.

### Prix

```text
application fee   100 $
exam fee          395 $
-----------------------
first attempt     495 $
```

### Éligibilité

Une combinaison de diplôme + expérience RH est requise, par exemple :

- master + 1 an d'expérience HR professionnelle ;
- bachelor + 2 ans ;
- ou 4 ans d'expérience HR professionnelle.

Validité : 3 ans, **60 recertification credits** ou nouvel examen.

Source :
- https://www.hrci.org/certifications/individual-certifications/phri

**Pertinence FR : HAUTE uniquement si le dirigeant exerce réellement une fonction RH structurée.**

La règle du dépôt devient :

```text
1. si la compétence dépend du droit / fiscal / réglementation française
      → credential France / UE

2. si la compétence est une méthode métier portable
      → choisir le meilleur credential mondial

3. si la compétence dépend d'un outil réellement utilisé
      → vendor certification pertinente, peu importe le pays de l'éditeur

4. si le credential étranger enseigne surtout la réglementation de son pays
      → faible priorité sauf marché cible correspondant
```

Exemples :

```text
vente             HubSpot                   oui
marketing         Google / AMA              oui
finance workflow  Xero / QuickBooks         oui, avec limites
projet            Scrum.org                 oui
qualité           ASQ                       oui
contrats B2B      WorldCC                   oui
privacy UE        IAPP CIPP/E               oui
RH                HRCI aPHRi / PHRi         oui

fiscalité US      non comme compétence France
droit du travail US non
CIPP/US           non sauf exposition US
```
