# Entrepreneur — private credit, finance groupe, PMI & corporate development 2026

> Cette fiche couvre le stade où l'entrepreneur possède ou pilote **plusieurs sociétés**, finance des acquisitions, consolide le reporting, intègre des cibles et structure une fonction de corporate development.
>
> Règle `human-skills` : la **finance transactionnelle, l'IFRS, le PMI et les méthodes M&A sont portables** ; les management fees, conventions réglementées, prix de transfert et règles fiscales d'un groupe français restent **France / UE first**.

```text

```

## CFA Institute — Private Markets & Alternative Investments Certificate

**CERT — 🌍 INT**

- **890 $** prix public ;
- 70–90 h ;
- cinq cours + assessment final ;
- 6 mois d'accès ;
- certificat + digital badge ;
- couvre private equity **et private credit**, structures, frais, capital mechanics, performance et due diligence.

Source : https://www.cfainstitute.org/programs/private-markets-alternative-investments-certificate

**Lecture entrepreneur :** excellent pour acquérir le vocabulaire et comprendre comment pensent fonds, prêteurs privés et investisseurs, mais moins opérationnel qu'un modèle LBO complet.

## CFA Institute — Private Equity Certificate

**CERT — 🌍 INT**

- **890 $** ;
- environ 125 h ;
- LBO modeling ;
- dette / private debt ;
- structuration ;
- due diligence ;
- value creation.

Source : https://www.cfainstitute.org/programs/private-equity-certificate

## CFA Institute — Advanced Private Equity Certificate

**CERT — 🌍 INT**

- **890 $** ;
- prérequis : Private Equity Certificate ;
- environ 100 h ;
- financial modeling avancé ;
- **debt valuation** ;
- deal structures ;
- portfolio governance.

Source : https://www.cfainstitute.org/programs/advanced-private-equity-certificate

```text
Private Equity Certificate       890 $
Advanced PE Certificate          890 $
--------------------------------------
TCO minimal chemin avancé      1 780 $
```

## CFI — CBCA®

**CERT — 🌍 INT**

Le Commercial Banking & Credit Analyst est utile au dirigeant parce qu'il apprend à analyser sa société comme le ferait un prêteur : cash-flow, couverture de dette, risque de crédit, sûretés, covenants, pricing et documentation.

Le credential est inclus dans le plan CFI Self-Study standard à **497 $/an** avec les autres certifications CFI.

Source : https://corporatefinanceinstitute.com/certifications/commercial-banking-credit-analyst-certification-cbca/

# 3. Consolidation & IFRS

## ACCA — Certificate in International Financial Reporting (CertIFR)

**CERT — 🌍 INT · UK-origin**

Point d'entrée léger pour comprendre l'IFRS sans devenir expert-comptable :

- 12 modules ;
- self-paced ;
- examen online d'une heure ;
- 25 QCM ;
- 12 mois d'accès ;
- certificat + digital badge.

### Coût public 2026

```text
cours + assessment       310 £
assessment only          200 £
ACCA member bundle       230 £
```

Source : https://www.accaglobal.com/uk/en/qualifications/glance/certifr/date-fee.html

**Pertinence : HAUTE** si acquisitions internationales, investisseurs IFRS, reporting à un groupe IFRS ou volonté de comprendre les ajustements de consolidation.

---

## ACCA — Diploma in International Financial Reporting (DipIFR)

**QUAL — 🌍 INT · UK-origin**

Diplôme plus sérieux que CertIFR, destiné aux professionnels finance/comptabilité ayant déjà de l'expérience pertinente.

Éligibilité typique :

- professionnel comptable / audit ; ou
- deux ans d'expérience pertinente + diplôme pertinent ; ou
- deux ans d'expérience + CertIFR ; ou
- trois ans d'expérience pertinente ; ou
- statut ACCA affiliate.

### TCO minimal indicatif UK 2026

```text
initial registration       89 £
exam Dec. 2026            160 £
--------------------------------
minimum direct fees       249 £
```

Préparation / tuition éventuelle non incluse ; les frais peuvent varier selon marché et session.

Sources :
- https://www.accaglobal.com/uk/en/qualifications/glance/dipifr/who.html
- https://www.accaglobal.com/gb/en/qualifications/glance/dipifr/date-fee.html

> Pour un patron de petite holding française, DipIFR est souvent surdimensionné. Pour un CFO de groupe multi-pays ou un dirigeant très impliqué dans le reporting financier, il devient cohérent.

Une entreprise qui fait une acquisition ponctuelle n'a pas nécessairement besoin d'une fonction CorpDev.

```text

screening
valuation
LOI
due diligence
financing
SPA / closing
integration plan
synergy tracking
portfolio review
```

## IMAA — International M&A Expert (IM&A)

**CERT — 🌍 INT**

Programme cross-disciplinary couvrant stratégie, valorisation, transaction, exécution et post-merger integration.

### Prix observé 2026

```text
self-paced online bundle   3 290 $
regular displayed value    4 360 $
```

Environ 60 h online ; options live / onsite plus chères.

Source : https://imaa-institute.org/m-and-a-trainings/international-m-and-a/

**Pertinence FR : HAUTE** pour un dirigeant / head of corporate development qui réalise plusieurs transactions ; trop cher pour apprendre une reprise unique.

## IMAA — Mergers & Acquisitions Professional (M&AP)

**CERT — 🌍 INT**

- self-paced bundle observé : **3 290 $** ;
- environ 60 h ;
- transaction process, auditing, consulting, deal advisory et organisation d'une activité M&A.

Source : https://imaa-institute.org/m-and-a-trainings/m-and-a-professional/

**Lecture entrepreneur :** IM&A est généralement plus naturel pour l'acquéreur / CorpDev ; M&AP est davantage orienté professionnels du deal et conseil.

# 5. Post-merger integration — le deal n'est pas fini au closing

## IMAA — Certified Post Merger Integration Expert (CPMI)

**CERT — 🌍 INT**

Le CPMI est une des rares certifications spécialisées sur la phase qui détruit ou crée réellement la valeur après une acquisition.

### Contenu

- integration planning avant closing ;
- governance d'intégration ;
- synergies coût / croissance ;
- intégration finance, RH, IT, sales / marketing ;
- Day 1 ;
- culture ;
- communication ;
- change management.

### Coût 2026

```text
self-paced bundle          3 290 $
regular displayed value    4 360 $
live online standard       4 390 $
onsite standard            5 490 $
```

Le bundle inclut une première année de membership IMAA / accès eLibrary.

Source : https://imaa-institute.org/m-and-a-trainings/post-merger-integration/

**Pertinence entrepreneur : ⭐⭐⭐⭐⭐** si buy-and-build / plusieurs acquisitions ; **⭐⭐** pour une seule petite reprise où un bon playbook PMI suffit.

# 6. Management fees & conventions intra-groupe — France

Ici, la priorité n'est **pas une certification étrangère**.

Le dirigeant doit comprendre :

```text
quelle prestation existe réellement ?
qui la fournit ?
à qui ?
comment est calculé le prix ?
la prestation fait-elle doublon avec un mandat social ?
TVA ?
déductibilité ?
convention réglementée ?
preuve du service rendu ?
prix de pleine concurrence si cross-border ?
```

## SAS — conventions réglementées

L'article **L227-10 du Code de commerce** prévoit un rapport sur certaines conventions intervenant entre la SAS et son président, dirigeants, certains actionnaires ou société contrôlante. L'article **L227-11** exclut les opérations courantes conclues à des conditions normales.

Sources :
- https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034584108/
- https://www.legifrance.gouv.fr/codes/section_lc/LEGITEXT000005634379/LEGISCTA000006146048/

## Alerte 2026 — management fees / rémunération de dirigeant

La Cour de cassation, **2e civ., 4 juin 2026, pourvoi n°23-20.189**, a validé dans le litige examiné la réintégration dans l'assiette des cotisations sociales de sommes facturées au titre d'une convention de gestion lorsque les prestations correspondaient à l'exercice des fonctions du dirigeant.

Source : https://www.legifrance.gouv.fr/juri/id/JURITEXT000054256173

> Conséquence `human-skills` : management fees, conventions de trésorerie, prestations holding et rémunération de direction sont classés **LEGAL/TAX REVIEW REQUIRED**, pas comme une recette standard d'optimisation.

# 7. Prix de transfert — seulement quand le groupe devient international

## CIOT / ADIT — Transfer Pricing option module

**QUAL module — 🌍 INT · UK-origin**

Le module couvre :

- OECD / UN models ;
- arm's length principle ;
- functional analysis ;
- comparability ;
- documentation / compliance ;
- dispute resolution ;
- double taxation.

Environ **200 h** de préparation recommandées ; examen de **3 h 15** en juin ou décembre.

### Frais 2026

```text
ADIT student registration    303 £ / 5 ans
exam entry                    278 £ / tentative
-------------------------------------------
1er module, frais directs     581 £
```

Le **full ADIT** exige davantage qu'un seul module ; ne pas présenter le passage de l'option Transfer Pricing comme la qualification ADIT complète.

Sources :
- https://www.tax.org.uk/adit/tp
- https://www.tax.org.uk/adit/qualification-fees

**Pertinence entrepreneur : FAIBLE** pour un groupe domestique français ; **TRÈS HAUTE** si prestations, IP, financement ou fonctions sont répartis entre sociétés de plusieurs pays.

# 8. Stack recommandée par maturité

## Première acquisition

```text
CCI RS7413 / Bpifrance reprise
+ CFI FMVA / CBCA
+ modèle LBO
+ avocat / fiscaliste France
```

## Holding avec 2–5 filiales

```text
CFI FPAP
+ reporting groupe mensuel
+ board pack
+ règles intercompany documentées
+ CertIFR si IFRS utile
```

## Buy-and-build

```text
CFI / CFA Private Equity
        ↓
IMAA IM&A ou équivalent CorpDev
        ↓
IMAA CPMI
        ↓
playbook Day 1 / 30 / 100 jours
        ↓
synergy tracking
```

## Groupe international

```text
CertIFR / DipIFR selon rôle finance
+ ICC / export si pertinent
+ ADIT Transfer Pricing si vraie exposition cross-border
+ conseil fiscal local dans chaque juridiction
```

# 9. Ce qu'un dirigeant doit savoir déléguer

| Sujet | Comprendre en interne | Validation / exécution spécialisée |
|---|---|---|
| Dette d'acquisition | leverage, covenants, cash sweep, downside | banque / debt adviser / avocat finance |
| Consolidation | intercompany, périmètre, adjustments, KPI | expert-comptable / consolidation specialist |
| PMI | governance, synergies, Day 1, culture | specialists selon taille du deal |
| Management fees | service, cost base, allocation key | avocat + fiscaliste + expert-comptable |
| Prix de transfert | fonctions / risques / actifs / flux | tax adviser / TP specialist |
| Gouvernance groupe | droits, délégations, board cadence | avocat corporate selon structure |
