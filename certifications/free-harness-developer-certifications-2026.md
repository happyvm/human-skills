# Harness Developer certifications gratuites — 2026

> Revue : **28 août 2026**. Harness University confirme que les certifications de niveau **Developer sont gratuites**. Les niveaux Administrator / Architect restent payants.

---

# Politique Harness 2026

La FAQ Harness University indique :

```text
Developer certification exam     0 $
Retakes Developer                 5
Admin / Architect                 payants
Retakes paid exams                2
Proctoring                        non
Open-book                         oui
Credential                        Credly / Harness Technical Certification
```

Les examens peuvent combiner :

- knowledge questions via Caveon Scorpion ;
- portions hands-on via Instruqt ;
- environnements de lab fournis par Harness selon le track.

Sources :

- https://developer.harness.io/university/policies-and-faqs/
- https://developer.harness.io/university/
