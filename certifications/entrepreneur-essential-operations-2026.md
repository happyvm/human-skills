# Entrepreneur — activités essentielles & opérations France 2026

> Cette fiche décrit **ce qu'un dirigeant doit savoir piloter** et conserve comme données canoniques les **certifications opérationnelles françaises CCI**.
>
> Les credentials internationaux portables ne sont plus recopiés ici : leur source canonique est [`entrepreneur-international-functional-credentials-2026.md`](entrepreneur-international-functional-credentials-2026.md).

# 1. Priorités opérationnelles

```text
P0 — avant / juste après le lancement
  vendre
  trouver des clients
  maîtriser marge + cash
  contractualiser
  facturer / encaisser
  protéger données et accès
  piloter les priorités

P1 — quand l'activité se structure
  achats / fournisseurs
  relation client
  projet
  recrutement
  management
  paie / administration

P2 — selon le modèle
  export
  e-commerce
  supply chain
  qualité
  conformité
  levée de fonds
```

Le but n'est pas d'être expert partout : **comprendre → contrôler → décider → exécuter ou déléguer**.

# 2. Carte canonique des certifications CCI opérationnelles

| Fonction | Certification | Lecture entrepreneur | Coût / TCO | Portée |
|---|---|---|---:|:---:|
| Prospection | CCI France RS6951 — Prospection commerciale phygitale | P0 vente / acquisition | provider-dependent | 🇫🇷 FR |
| Gestion | CCI France RS7378 — Maîtriser les fondamentaux de la gestion d'une TPE-PME | P0 marge / cash / pilotage | **≈1 750 €** exemple Savoie, variable | 🇫🇷 FR |
| Achats | CCI France RS7380 — Réaliser des achats en TPE-PME | P1 fournisseurs / négociation | provider-dependent | 🇫🇷 FR |
| Projet | CCI France RS7385 — Manager un projet | P1 exécution | **≈1 500–2 260 €** observés | 🇫🇷 FR |
| Relation client | CCI France RS7376 — Développer la qualité de service et la relation client | P1 fidélisation / réclamations | **≈1 350 €** exemple Creuse | 🇫🇷 FR |
| Recrutement | CCI France RS6952 — Conduire un recrutement | P1 première équipe | provider-dependent | 🇫🇷 FR |
| Management | CCI France RS7377 — Animer une équipe de travail | P1 management | provider-dependent | 🇫🇷 FR |
| Paie | CCI France RS7382 — Préparer et traiter la paie | P1/P2 selon internalisation | provider-dependent | 🇫🇷 FR |
| Formation interne | CCI France RS7379 — Exercer la mission de formateur en entreprise | P2 transmission interne | provider-dependent | 🇫🇷 FR |
| Import-export | CCI France RS7383 — Piloter les opérations à l'international | P2 export/import | provider-dependent | 🇫🇷 FR |

Les prix CCE peuvent être inclus dans le parcours ou facturés séparément selon la CCI : vérifier le **first-cycle TCO**, pas seulement le prix formation.

# 6. Achats & fournisseurs — P1

**CCI RS7380** couvre :

- besoin / cahier des charges ;
- sourcing ;
- comparaison coût-qualité-délai ;
- négociation ;
- contractualisation ;
- suivi fournisseur ;
- achats responsables.

Quand les achats deviennent une fonction métier à part entière, sortir du parcours entrepreneur vers [`supply-chain-procurement-over-500.md`](supply-chain-procurement-over-500.md).

# 7. Relation client — P1

**CCI RS7376** est la certification locale canonique.

Le patron doit au minimum savoir organiser :

```text
onboarding
support
SLA / délais
réclamations
satisfaction
fidélisation
retour d'expérience
```

Les certifications HubSpot Service / customer experience sont routées vers les catalogues internationaux dédiés au lieu d'être dupliquées ici.

# 8. Recrutement, management, paie — P1

## Recruter

**CCI RS6952** : cadrer le besoin, sourcer, sélectionner, conduire l'entretien et intégrer.

## Manager

**CCI RS7377** : animation d'équipe et management opérationnel.

## Paie

**CCI RS7382** est utile si la compétence est réellement internalisée. Le droit social et la paie restent **France first**.

## Monter en compétence

**CCI RS7379** si le dirigeant ou un manager doit structurer la formation interne.

Pour HRCI aPHRi / PHRi, voir la source canonique internationale : [`entrepreneur-international-functional-credentials-2026.md`](entrepreneur-international-functional-credentials-2026.md).

# 12. Principe de délégation

| Fonction | Le dirigeant doit comprendre | À déléguer quand complexe |
|---|---|---|
| Comptabilité | marge, cash, bilan, résultat | tenue / clôture / fiscalité |
| Vente | pipeline, conversion, pricing | exécution spécialisée / agence |
| Achats | besoin, coût complet, fournisseur | procurement complexe |
| Projet | objectifs, risques, arbitrages | PMO lourd |
| RH | besoin, entretien, management | droit social / paie complexe |
| Contrats | obligations, risques, economics | rédaction / litige |
| Cyber | exposition, accès, backup | expertise technique avancée |
| Export | marché, risque, Incoterms | douane / fiscalité locale |
