# Entrepreneur — activités essentielles, opérations & credentials 2026

> Une entreprise ne vit pas seulement de sa création juridique. Ce catalogue cartographie les **activités qu'un entrepreneur doit comprendre, exécuter ou savoir déléguer** : vente, marketing, finance, trésorerie, achats, RH, paie, relation client, projet, management, protection des données, cybersécurité et international.
>
> La logique reste celle de `human-skills` : **gratuit d'abord**, puis faible coût, puis certifications/qualifications plus lourdes ; toujours distinguer **CERT / BADGE / COURSE / QUAL**, coût affiché et **TCO réel**.

---

# 0. Priorités d'un dirigeant de TPE / PME

```text
P0 — indispensable dès le démarrage
  vendre
  trouver des clients
  fixer/préserver les marges
  suivre trésorerie + coûts
  contractualiser
  facturer / encaisser
  protéger données et accès
  piloter son activité

P1 — dès que l'activité se structure
  achats / fournisseurs
  gestion de projet
  relation client / support
  recrutement
  management
  paie / administration du personnel

P2 — selon le modèle économique
  e-commerce
  export / import
  supply chain
  levée de fonds
  qualité / conformité
  data / analytics avancée
```

Un entrepreneur n'a **pas besoin d'être expert certifié dans tout**. L'objectif est de posséder suffisamment de compétence pour :

1. prendre de bonnes décisions ;
2. détecter une erreur ou un risque ;
3. briefer et contrôler un prestataire ;
4. savoir quand il faut déléguer à un expert-comptable, avocat, juriste, DPO, RH, etc.

# 4. Finance, gestion, marge, trésorerie & comptabilité — P0

## CCI France — Maîtriser les fondamentaux de la gestion d'une TPE-PME — RS7378

**CERT — 🇫🇷 FR**

Active jusqu'au **27 novembre 2028**.

Elle couvre exactement les sujets qu'un dirigeant doit comprendre :

- bilan / compte de résultat ;
- rentabilité ;
- coûts fixes / variables ;
- seuil de rentabilité ;
- EBE / CAF / ratios ;
- plan de trésorerie ;
- besoins de financement ;
- tableaux de bord ;
- indicateurs financiers et extra-financiers.

### TCO observé en 2026

CCI Savoie :

```text
formation   1 250 €
certification CCE   500 €
-------------------------
first-cycle TCO ≈ 1 750 €
```

D'autres CCI affichent environ **1 400–2 250 €** pour la formation selon centre et format ; vérifier si le passage CCE est inclus ou ajouté.

Sources :

- https://www.francecompetences.fr/recherche/rs/7378/
- https://www.savoie.cci.fr/produit/maitriser-les-fondamentaux-de-la-gestion-dune-tpe-pme

# 10. Juridique, contrats & conformité — P0

Le besoin n'est pas de devenir avocat. Le dirigeant doit surtout savoir :

- identifier les clauses risquées ;
- comprendre responsabilité, paiement, propriété intellectuelle, confidentialité ;
- maîtriser CGV / devis / bon de commande / contrat ;
- savoir quand demander un avis juridique.

Le dépôt contient déjà :

Pour une TPE française généraliste, les certifications internationales de contract management sont souvent **moins prioritaires** qu'une formation juridique française ciblée + validation des modèles par un professionnel.
