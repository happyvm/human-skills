# Green building, ESG reporting & sustainability credentials

> Credentials appliqués au bâtiment durable, santé des bâtiments et reporting sustainability. Vérifié fin août 2026.

---

# 1. LEED Green Associate

Credential GBCI / USGBC d'entrée dans l'écosystème LEED.

## Prix 2026

- tarif standard : **250 $** ;
- membre USGBC : **200 $** ;
- étudiant : **100 $**.

## Format

- 100 questions ;
- 2 heures ;
- aucun prérequis ;
- centre Prometric ou remote proctoring ;
- traduction française disponible selon version.

Source :

- https://www.usgbc.org/credentials/leed-green-associate

---

# 2. LEED AP with Specialty

Spécialités LEED selon le domaine :

- BD+C ;
- O+M ;
- ID+C ;
- Homes ;
- ND.

## Prix

### Specialty exam seul

Pour une personne qui détient déjà un LEED Green Associate actif :

- **350 $ standard** ;
- **250 $ membre USGBC**.

### Combined Green Associate + AP

- **550 $ standard** ;
- **400 $ membre USGBC**.

Source :

- https://www.usgbc.org/credentials/exam-preparation

### Lecture TCO

Le credential AP peut donc être acquis sous 500 $ si Green Associate est déjà détenu, ou via le combined exam au tarif membre.

# 3. WELL AP

Credential de l'International WELL Building Institute orienté :

- santé ;
- bien-être ;
- qualité des espaces ;
- WELL Building Standard.

## Prix 2026

- examen : **299 $** ;
- exam + study materials : **369 $** ;
- étudiant : **125 $**.

Des réductions de groupe existent jusqu'à environ 164 $ par personne selon taille du groupe.

## Maintenance

Cycle : **24 mois**.

- 30 heures de continuing education ;
- dont 6 WELL-specific ;
- renewal fee : **125 $** ;
- 80 $ dans certains emerging markets.

Sources :

- https://support.wellcertified.com/hc/en-us/articles/25696901381015-WELL-AP-overview
- https://support.wellcertified.com/hc/en-us/articles/25697075504535-How-to-renew-your-WELL-AP-credential

# 4. BREEAM AP

BREEAM fonctionne via plusieurs national scheme operators et les prix varient selon pays.

## Exemple DACH 2026 — BREEAM New Construction AP

Le schéma Allemagne / Autriche affiche :

- formation 3 jours + test : **1 500 € HT** ;
- possibilité de demander la licence AP après réussite ;
- assurance responsabilité professionnelle requise pour la licence ;
- listing volontaire : **500 € HT / an**.

Source :

- https://breeam.de/ausbildung/ausbildung-breeam-neubau-ap/

### TCO avec listing 1 an

```text
Formation + test     1 500 € HT
Listing optionnel      500 € HT
------------------------------
                      2 000 € HT
```

Les tarifs Royaume-Uni / France / autres NSO peuvent être différents.

Source générale :

- https://breeam.com/training

# 5. GRI Certified Sustainability Professional

Le programme GRI a été restructuré en 2025 et repose désormais sur **quatre cours obligatoires** puis l'examen de certification.

## Cours obligatoires

La Route A GRI Academy comprend :

1. Reporting with the GRI Standards ;
2. Reporting on Human Rights with the GRI Standards ;
3. Navigating the GRI Sector Standards ;
4. Transparency for Tomorrow: Decoding the Sustainability Reporting Landscape.

Puis :

5. GRI Professional Certification Exam.

Source :

- https://www.globalreporting.org/academy/certification/

## Examen final

- **250 €** ;
- 40 questions ;
- 60 minutes ;
- score de réussite : 75 % ;
- prerequisite : quatre cours complétés.

Le programme délivre le titre :

**GRI Certified Sustainability Professional**.

Source :

- https://www.globalreporting.org/Academy/Course?id=989

## Retake

Les tentatives supplémentaires sont affichées autour de **125 €**.

Source :

- https://www.globalreporting.org/Academy/Course?id=645

## Prix du parcours complet

GRI précise que le prix du learning plan complet est égal au cumul des quatre cours + examen.

Les prix individuels du catalogue évoluent ; le TCO exact doit donc être recalculé au checkout à partir des quatre cours actifs.

Des remises existent :

- étudiant : 25 % ;
- GRI Community : 25 % ;
- NGOs : 15 % sur cours ;
- bulk discounts.

Source :

- https://www.globalreporting.org/academy/faqs
