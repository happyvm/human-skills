# Customer experience — CCXP and CX credentials

> Certifications professionnelles autour du Customer Experience Management, CX strategy, metrics, design and culture.

---

# 1. CCXP — Certified Customer Experience Professional

Le **CCXP** de la Customer Experience Professionals Association est une certification professionnelle indépendante orientée expérience client.

**Auto-formation officielle :** [CXPA — Prep Resources](https://cxpaglobal.org/get-certified/prep-resources) — CX Book of Knowledge (300+ pages) et programme de mentorat CCXP.

Contrairement à de nombreuses formations CX propriétaires, le programme :

- impose une expérience professionnelle admissible ;
- examine plusieurs domaines CX ;
- comprend un examen formel ;
- n'impose pas de formation propriétaire obligatoire ;
- exige un maintien périodique.

Source :

- https://www.cxpaglobal.org/earn-your-ccxp/about-ccxp
- https://www.cxpaglobal.org/get-certified

---

# 2. Prix 2026

Le handbook CCXP de mars 2026 confirme :

- **495 $** pour les membres CXPA ;
- **645 $** pour les non-membres.

Le prix comprend :

- review de l'application ;
- première tentative d'examen.

Une part de **150 $** correspond au processing fee non remboursable.

Source :

- https://cxpaglobal.org/storage/app/media/CCXP/CCXP_Handbook_March_2026.pdf

---

# 3. Retakes

Si la première tentative échoue :

- membre : **198 $** ;
- non-membre : **348 $**.

Le candidat dispose d'une fenêtre d'éligibilité d'environ un an à compter de la soumission de l'application selon les règles 2026.

Il n'y a pas de période d'attente obligatoire entre les tentatives ; chaque retake est payant.

Sources :

- https://cxpaglobal.org/get-certified/test-info
- https://cxpaglobal.org/storage/app/media/CCXP/Handbooks/Next_Steps_Checklist_Full.pdf

---

# 4. Compétences évaluées

Le handbook 2026 structure l'expérience autour de plusieurs axes :

- Customer Insights and Understanding ;
- Customer Experience Strategy ;
- Metrics, Measurements and ROI ;
- Design, Implementation and Innovation ;
- Culture and Accountability.

La candidature doit démontrer une expérience CX suffisamment large et un niveau de responsabilité pertinent.

---

# 5. Prérequis

Le programme utilise un modèle **education + experience**.

Exemple du handbook 2026 :

- diplôme post-secondaire ou équivalent global ;
- ou niveau secondaire avec davantage d'expérience qualifiante ;
- expérience professionnelle CX documentée ;
- largeur d'expérience dans les core competencies.

Le prix de 645 $ ne permet donc pas à lui seul de « devenir CCXP » sans expérience admissible.

---

# 6. Recertification

Cycle : **3 ans**.

Exigence : **30 credits** de développement professionnel / structured learning CX.

Frais :

- membre : **299 $** ;
- non-membre : **449 $**.

Source :

- https://cxpaglobal.org/get-certified/maintain-certification

---

# 7. TCO indicatif

## Non-member — premier cycle sans retake

```text
Application + exam 645 $
```

## Sur six ans — non-member, hors coût des crédits

```text
Initial            645 $
Recertification    449 $
-----------------------
≈ 1 094 $
```

La membership CXPA peut modifier le calcul ; elle n'est pas obligatoire pour gagner le credential.

# 8. Positionnement

Le CCXP est particulièrement adapté à :

- CX leaders ;
- service design ;
- customer journey ;
- VOC / customer insights ;
- CX metrics ;
- experience transformation ;
- customer-centric operating models.

Il se combine bien avec :

- product management ;
- service management ;
- marketing ;
- UX/accessibility ;
- Lean / process improvement ;
- change management.
