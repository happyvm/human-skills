# 3. Altered Security

Altered Security est l'un des rapports **hands-on / coût** les plus intéressants trouvés pendant la revue.

## CRTP — Certified Red Team Professional

Active Directory offensive, examen pratique 24h.

| Accès | Prix |
|---|---:|
| 30 jours labo + cours + examen | **249 $** |
| 60 jours | **379 $** |
| 90 jours | **499 $** |

- accès à vie aux supports ;
- une tentative de certification ;
- retake : **99 $** ;
- certifications valables 3 ans, avec mécanisme de renouvellement ;
- Altered Security a annoncé en 2026 un renouvellement pouvant inclure cours + une tentative sans frais pour les titulaires éligibles.

Source : https://www.alteredsecurity.com/adlab

## CRTE — Certified Red Team Expert

AD avancé / multi-forest.

| Accès | Prix |
|---|---:|
| 30 jours + cours + examen | **299 $** |
| 60 jours | **499 $** |
| 90 jours | **699 $** |

Le **credential peut donc être obtenu sous 500 €** avec l'option minimale, même si l'option 90 jours appartient à une tranche supérieure.

- retake : **99 $** ;
- renouvellement : cours + une tentative annoncés gratuits pour titulaire éligible ;
- labo de renouvellement optionnel : **179 $ / 30 jours** ;
- tentative supplémentaire de renouvellement : **29 $**.

Sources :

- https://www.alteredsecurity.com/redteamlab
- https://www.alteredsecurity.com/post/renewal-process-for-altered-security-certifications

## Autres parcours

Les bundles complets peuvent dépasser 2–3 k$, mais chaque credential doit être classé selon son option minimale permettant réellement l'obtention.

# 5. CREST — Practitioner sous 500, Registered/Certified au-dessus

CREST publie en 2026 une grille internationale en GBP :

| Niveau | Exemples | Prix hors taxes |
|---|---|---:|
| Practitioner | CPSA, CPTIA, CPIA | **275 £** |
| Registered | CRT, CRTIA, CRIA | **600 £** |
| Certified | CCT INF, CCT APP, CCRTS, CCRTM, CCTIM, CCIM | **1 600 £*** |

`*` Les examens Certified sont constitués de deux parties qui doivent être réservées séparément selon CREST.

Les niveaux Registered et Certified sont donc documentés dans la page premium, tandis que **CPSA / CPTIA / CPIA** restent dans cette tranche.

Source : https://www.crest-approved.org/skills-certifications-careers/certifications-pricing-booking/
