# 1. Hurricane Electric IPv6 Certification — vraie certification pratique gratuite

Hurricane Electric maintient toujours en 2026 son **IPv6 Certification Project** et son site corporate affiche explicitement : **Free IPv6 Certifications!**

Le parcours vérifie réellement la capacité à configurer et exposer des services IPv6.

## Compétences validées

Le test demande notamment de démontrer :

- connectivité IPv6 ;
- serveur web accessible en IPv6 ;
- adresse e-mail fonctionnant en IPv6 ;
- DNS forward IPv6 ;
- reverse DNS IPv6 ;
- serveurs DNS joignables en IPv6 ;
- connaissances IPv6 via questions/tests.

Concepts couverts :

- adresses IPv6 ;
- enregistrements AAAA ;
- reverse DNS ;
- loopback ;
- default route ;
- documentation prefix ;
- link-local ;
- multicast ;
- ping/traceroute IPv6 ;
- tailles de préfixes /64, /48, /32.

## Niveaux

Le programme contient historiquement et toujours dans les présentations actuelles les niveaux :

```text
Newbie
Explorer
Enthusiast
Administrator
Professional
Guru
Sage
```

```text
Prix            0 $
Type            practical / infrastructure validation
Credential      Hurricane Electric IPv6 Certification
```

### Valeur

⭐⭐⭐⭐⭐ pour réseau, DNS, infrastructure Internet et IPv6.

Sources :

- https://ipv6.he.net/certification/
- https://www.he.net/
- https://ipv6.he.net/presentations.php

# 2. arcX Cyber Threat Intelligence 101 — vraie certification gratuite

arcX propose **Cyber Threat Intelligence 101** gratuitement.

Le parcours actuel comprend :

- plus de 4 heures de contenu ;
- autoformation online/on-demand ;
- exercices ;
- plus de 100 practice questions ;
- **arcX final micro exam** ;
- certification finale vérifiable publiquement.

Le site de vérification arcX montre des certifications FTIA `Cyber Threat Intelligence 101` émises encore en **2026**.

```text
Training          0 $
Final micro exam  inclus
Certification     oui
Verification      publique
```

arcX est également un organisme de formation accrédité CREST, mais le credential gratuit arcX FTIA ne doit pas être confondu avec un examen CREST séparé, dont le voucher est payant.

### Valeur

⭐⭐⭐⭐⭐ pour CTI / SOC / threat intelligence.

Sources :

- https://arcx.io/courses/cyber-threat-intelligence-101
- https://arcx.io/verify-certificate

# 3. Centri / ex-Security Blue Team — Blue Team Junior Analyst pathway gratuit

Security Blue Team est devenu **Centri** en 2026. Le programme gratuit **Blue Team Junior Analyst Pathway Bundle** reste actif.

Pour obtenir le certificate BTJA, il faut terminer à 100 % les six cours :

1. Introduction to Threat Hunting ;
2. Introduction to Vulnerability Management ;
3. Introduction to Digital Forensics ;
4. Introduction to Network Analysis ;
5. Introduction to Dark Web Operations ;
6. Introduction to OSINT.

Chaque parcours comprend des quizzes et/ou activités évaluées.

```text
Prix              0 $
Durée estimée    ~30 h
Cours requis       6
Certificate        Blue Team Junior Analyst pathway
```

### Important

Le BTJA gratuit est un **pathway certificate**. Il ne faut pas le confondre avec :

- Blue Team Level 1 ;
- Blue Team Level 2 ;
- CJDE ;
- autres certifications professionnelles Centri payantes.

### Valeur

⭐⭐⭐⭐ pour blue team / SOC junior.

Sources :

- https://www.centri.org/courses/blue-team-junior-analyst-pathway-bundle
- https://support.centri.org/hc/en-gb/articles/16796664331164-How-to-Claim-Your-BTJA-Pathway-Certificate
- https://www.centri.org/training?prices=Free

# 4. Salesforce Trailhead Superbadges — évaluations hands-on gratuites

Salesforce Trailhead est une plateforme gratuite et les Superbadges sont des **technical skills assessments hands-on** basés sur des scénarios métiers.

En 2026, Salesforce a modernisé le programme :

- plus de prérequis obligatoires ;
- learning recommandé mais non bloquant ;
- assessments davantage hands-on ;
- durée typique 1 à 3 heures ;
- Developer Edition spéciale gratuite pour les challenges qui en ont besoin.

Exemples techniques actuels :

- **Apex Web Services** ;
- **Apex for Agentforce** ;
- **Multi-Factor Authentication and SSO** ;
- **Authentication Governance** ;
- **Access Governance** ;
- **Flow Interactions** ;
- **Screen Flow Fundamentals** ;
- **Prompt Builder Templates** ;
- Data / object / security assessments.

### Taxonomie 2026

Point important : Salesforce a annoncé que les **Superbadges ne sont plus considérés comme des credentials** dans sa nouvelle taxonomie. Ils restent cependant des évaluations pratiques affichées sur le profil Trailblazer.

Donc classer :

```text
coût              0 $
format            hands-on technical assessment
credential 2026   non — Superbadge/assessment
portfolio signal  oui
```

Ils restent très utiles comme preuve pratique, mais ne doivent pas être présentés comme une `Salesforce Certified` certification.

Sources :

- https://help.salesforce.com/s/articleView?id=005299049&type=1
- https://www.salesforce.com/blog/advance-career-superbadges-super-sets/
- https://www.salesforce.com/blog/salesforce-superbadges-on-trailhead/
- https://trailhead.salesforce.com/content/learn/superbadges/
