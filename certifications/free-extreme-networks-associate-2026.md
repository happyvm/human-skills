# Extreme Networks Associate certifications gratuites — 2026

> Revue : **28 août 2026**. Cette fiche documente les certifications **Extreme Networks Associate / XNA** dont le training et l'examen sont accessibles gratuitement.

---

# Statut général

Extreme Networks publie une **Welcome Series** composée de cours vidéo gratuits. La page training 2026 indique explicitement qu'après le dernier épisode, le candidat reçoit les instructions lui permettant d'accéder au **free certification exam**.

Le programme Extreme Academy permet également à des apprenants individuels d'obtenir plusieurs qualifications **Extreme Networks Associate (XNA)**.

```text
Training introductory / Welcome Series    0 $
Associate certification exam              0 $
Credential                                Extreme Networks Associate / Credly
Niveau                                    Foundational / Associate
```

Sources :

- https://www.extremenetworks.com/support/training/welcome-series-training
- https://www.extremenetworks.com/support/training

# Différence avec les certifications Extreme payantes

Ne pas mélanger les **Associate gratuits** ci-dessus avec :

- Extreme Administrator ;
- Extreme Professional ;
- Expert ;
- certifications produits avancées.

Ces niveaux supérieurs utilisent des examens/assessments dont les prix peuvent être de plusieurs centaines de dollars/euros.
