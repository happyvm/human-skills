# 2. Kong — prix 2026 enfin confirmé

Kong publie deux certifications Associate actives :

- **Kong Gateway Certified Associate** ;
- **Kong Konnect Certified Associate**.

Le FAQ officiel **2026** fournit une grille très claire.

**Auto-formation officielle :** [Kong Academy](https://education.konghq.com/) — modules self-paced et labs hands-on.

## Prix et règles

```text
Prix première tentative     275 $
Passing score                75 %
Retake après échec            49 $
Délai avant retake        2 semaines
Validité certification      3 ans
Training obligatoire          non
Delivery                   remote proctored
```

La formation est **recommandée mais non obligatoire**.

### Gateway Certified Associate

- examen d'environ 2 heures ;
- QCM + tâches performance-based ;
- pondération performance / multiple choice : **60 / 40**.

### Konnect Certified Associate

- examen d'environ 2 heures ;
- 60 multiple-choice / multiple-answer questions ;
- couvre notamment architecture, Gateway, AI Gateway, Service Mesh, Developer Portal, Service Catalog, Analytics, Organizations et cross-platform scenarios.

### Très bon point : retake à 49 $

Contrairement à de nombreux vendors qui refacturent un examen complet, Kong envoie après échec un coupon de resit à **49 $**.

```text
1 réussite du premier coup      275 $
1 échec + 1 réussite            324 $
```

### Verdict

À 275 $, Kong est maintenant une vraie option APIM low-cost et doit sortir de la watchlist prix.

Sources officielles :

- https://konghq.com/academy/certification
- https://konghq.com/academy/exam-preparation
- https://assets.prd.mktg.konghq.com/files/2026/04/69e68804-kong-certification-faq-2026.pdf

# 4. Google Cloud / Apigee

Aucune certification professionnelle actuelle **spécifiquement Apigee** n'a été identifiée dans le catalogue Google Cloud Certification.

Google propose en revanche des Skill Badges pratiques :

- Develop and Secure APIs with Apigee X ;
- Deploy and Manage Apigee X ;
- contenus Apigee Hybrid / Private Cloud.

La certification **Professional Cloud Developer** inclut Apigee dans son blueprint mais n'est pas une certification Apigee dédiée.

Sources :

- https://cloud.google.com/learn/training/api-management
- https://www.cloudskillsboost.google/paths/21/course_templates/661
- https://cloud.google.com/learn/certification/guides/cloud-developer
