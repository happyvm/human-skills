## WSO2 Certified API Manager Expert - V4

Prérequis : **API Manager Developer V4**.

Le niveau Expert utilise deux examens pratiques proctorés :

```text
Practical 1   150 $   120 min
Practical 2   200 $   180 min
```

Practical 2 nécessite la réussite du Practical 1.

### TCO examens depuis zéro

```text
Developer       100 $
Expert P1       150 $
Expert P2       200 $
---------------------
Total           450 $
```

La formation self-paced étant gratuite, **450 $** constitue un TCO d'examens remarquable pour arriver à un niveau Expert pratique.

> Le Practitioner à 50 $ n'est pas indiqué comme prerequisite du Developer/Expert dans la page Expert ; il peut être ajouté pour le signal initial mais n'est pas inclus dans le calcul minimal ci-dessus.

Source :

- https://wso2.com/training/certification/api-manager-expert-v4-api-management-profile

# 2. Tyk — cours gratuits avec certificats

Tyk propose une Academy de cours API couvrant notamment API management, API observability et sujets connexes.

Tyk indique qu'à la fin de chaque cours, le participant reçoit un **certificate** et que l'accès peut démarrer gratuitement.

### Attention au vocabulaire

Ces éléments doivent être classés comme **course completion certificates**, et non comme une certification professionnelle proctorée équivalente à WSO2 Developer, Kong Associate ou MuleSoft Architect.

### Verdict

Bon pour apprendre et obtenir une preuve de formation gratuite, mais signal plus faible qu'un examen surveillé.

Source :

- https://tyk.io/courses/

# 3. Google Cloud / Apigee

Aucune certification professionnelle actuelle **spécifiquement Apigee** n'a été identifiée dans le catalogue Google Cloud Certification lors de cette revue.

Google propose en revanche des **Skill Badges** pratiques :

- Develop and Secure APIs with Apigee X ;
- Deploy and Manage Apigee X ;
- contenus Apigee Hybrid / Private Cloud.

Les skill badges reposent sur des labs hands-on et challenge assessments.

Le contenu pédagogique peut être consultable gratuitement, mais les labs nécessitent généralement un abonnement ou des crédits, sauf campagnes donnant accès gratuitement.

### Certification proxy

La certification Google **Professional Cloud Developer** inclut Apigee dans son blueprint, mais ne constitue pas une certification Apigee dédiée.

Sources :

- https://cloud.google.com/learn/training/api-management
- https://www.cloudskillsboost.google/paths/21/course_templates/661
- https://cloud.google.com/learn/certification/guides/cloud-developer
