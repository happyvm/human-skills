# 1. ISA — Certified Automation Professional

## CAP

Certification de personne de l'International Society of Automation.

Prix :

- ISA Member : **373 $** ;
- Non-Member : **467 $**.

Examen :

- 175 questions ;
- 4 heures ;
- closed book.

La review course ISA est facultative et l'exam fee CAP n'est pas inclus dans le prix de la review course.

Sources :

- https://www.isa.org/certification/certification-faqs
- https://www.isa.org/certification/certification-testing

**Valeur : ⭐⭐⭐⭐⭐** pour automation / control engineering.

# 2. ISA — CCST

## Certified Control Systems Technician

Trois niveaux :

| Niveau | Membre | Non-membre |
|---|---:|---:|
| Level 1 | **331 $** | **415 $** |
| Specialist Level 2 | **315 $** | **397 $** |
| Master Level 3 | **331 $** | **415 $** |

Question counts :

- Level 1 : 150 ;
- Level 2 : 125 ;
- Level 3 : 150.

Les CCST review courses incluent le testing fee correspondant lorsqu'elles sont achetées selon le programme ISA.

Source :

- https://www.isa.org/certification/certification-testing

---

# 3. ISA recertification

Cycle : **3 ans**.

## CAP

- 150 PDP ;
- renewal par PDP : **270 $ membre / 340 $ non-membre** ;
- par exam : **336 / 420 $**.

## CCST

- 90 PDP ;
- renewal par PDP : **210 $ membre / 265 $ non-membre** ;
- par exam : **300 / 375 $**.

Source :

- https://www.isa.org/certification/recertification

# 4. ISA cybersecurity / safety certificate programs

À ne pas confondre avec CAP/CCST.

ISA possède aussi des **certificate programs** IEC 62443 / safety avec cursus obligatoire par modules.

Le dépôt les traite dans :

- `ot-ics-functional-safety-over-500.md`.

Certains parcours imposent un **Fundamental Specialist** avant les certificates avancés.
