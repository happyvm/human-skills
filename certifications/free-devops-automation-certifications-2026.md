# Free DevOps, automation & RPA certifications — 2026

> Revue : **28 août 2026**. Cette fiche complète [`free-it.md`](free-it.md) avec des certifications et examens **réellement gratuits** dans les domaines CI/CD, GitOps, resilience/chaos, enterprise automation et RPA.

---

# 1. Harness — certifications Developer gratuites

Harness University confirme dans sa FAQ 2026 que les certifications de niveau **Developer sont gratuites**.

Politique actuelle :

```text
Developer certifications     0 $
Retakes Developer             5
Admin / Architect             payants
Retakes Admin / Architect     2 par paiement
Proctoring                    non
Open book                     oui
Credential                    Harness Technical Certification / Credly
```

Harness utilise notamment :

- Caveon Scorpion pour les knowledge questions ;
- Instruqt pour les portions hands-on.

Source générale :

- https://developer.harness.io/university/policies-and-faqs/

## Harness CD & GitOps Developer Certification

La documentation Harness 2026 décrit explicitement une **Developer Certification** comme le premier niveau du parcours CD & GitOps.

Le candidat est évalué sur :

- Continuous Delivery ;
- GitOps ;
- pipelines ;
- deployment infrastructure ;
- templates ;
- triggers ;
- approvals ;
- Continuous Verification ;
- infrastructure provisioning ;
- policy-as-code ;
- API / Terraform provider / Git Experience.

Le parcours continue ensuite vers les certifications Administrator et Architect, qui sont payantes.

**Coût Developer : 0 $.**

Source :

- https://developer.harness.io/docs/continuous-delivery/cd-onboarding/certification/onboarding-guide

## Harness Chaos Engineering Developer Certification

Harness documente également la **Harness Chaos Engineering Developer Certification**.

L'examen inclut une dimension pratique autour de :

- chaos experiments ;
- Kubernetes ;
- resilience ;
- sample application / lab workflow ;
- génération et validation d'un code issu du scénario pratique.

La documentation de sandbox a évolué en 2026, mais le credential Developer reste référencé dans le programme Harness University.

**Coût Developer : 0 $ selon la politique globale Developer.**

Sources :

- https://developer.harness.io/docs/resilience-testing/resources/training/certification/
- https://developer.harness.io/university/policies-and-faqs/

### Valeur

⭐⭐⭐⭐⭐ pour DevOps / CD / GitOps / platform engineering.

Le combo gratuit :

```text
Harness CD & GitOps Developer
Harness Chaos Engineering Developer
```

est particulièrement intéressant pour un profil infrastructure / platform engineering.

# 2. Workato — examens Foundations gratuits

Workato Academy expose explicitement ses deux examens Foundations comme **Free**.

## Workato Foundations Level 1 Exam

```text
Prix             0 $
Format           multiple choice
Durée            <25 min annoncée
Open book        oui
Open notes       oui
Open resources   oui
Certificate      oui après réussite
```

Source :

- https://academy.workato.com/learn/courses/78/workato-foundations-level-1-exam

## Workato Foundations Level 2 Exam

Le catalogue Workato Academy affiche également :

- **Workato Foundations Level 2 On-Demand — Free** ;
- **Workato Foundations Level 2 Exam — Free**.

Source :

- https://academy.workato.com/learn/public/catalog/view/19

## Workato Automation Pro

Workato présente son Academy comme offrant des **free automation training and certifications** et maintient une progression Automation Pro I / II / III.

L'accès à certains labs nécessite un compte Workato valide ; un trial peut être utilisé pour certains contenus.

Lorsque le catalogue n'affiche pas séparément un prix d'examen, ne pas extrapoler un prix : les deux examens Foundations ci-dessus sont les gratuités les plus explicitement vérifiables publiquement.

### Valeur

⭐⭐⭐⭐ pour enterprise integration / orchestration / automation.

# 3. Automation Anywhere Essentials Certification — gratuite

Automation Anywhere University affiche en 2026 :

**Essentials Certification — Free**.

Elle valide les bases de :

- automation et AI fundamentals ;
- Automation Anywhere platform ;
- identification des processus à automatiser ;
- construction d'automations simples ;
- packages Automation 360 ;
- Automation Development Lifecycle.

Le programme est destiné notamment aux débutants et citizen developers.

Une réponse officielle Automation Anywhere confirme également que l'Essentials Certification est gratuite, avec un nombre de tentatives limité avant intervention du support.

```text
Essentials Certification    0 $
Advanced Certification     80 $
Master Certification      130 $
```

> Advanced et Master ne doivent donc pas être ajoutées au catalogue gratuit général, sauf entitlement partenaire ou promotion explicite.

Sources :

- https://pathfinder.automationanywhere.com/university
- https://pathfinder.automationanywhere.com/faq
- https://community.automationanywhere.com/automation-anywhere-university-85038/essentials-certification-reschedule-certification-90436

### Partner exception

Automation Anywhere indique que certaines certifications Advanced peuvent être gratuites pour les partenaires via un parcours Partner Exclusive. C'est une gratuité **conditionnelle**, pas publique générale.

### Advanced Automation Developer Certification — prix confirmé pour les non-partenaires

Contrairement à l'Essentials ci-dessus, l'**Advanced Automation Developer Certification** est payante hors statut partenaire : **80 $** (tarif standard confirmé sur le blog officiel Automation Anywhere, après expiration d'une promotion à 5 $ le 15 octobre 2024).

- prérequis : Essentials Automation Developer Certification ou connaissance équivalente ;
- **60 questions**, QCM.

Source :

- https://community.automationanywhere.com/pathfinder-blog-85009/new-certification-big-savings-greater-impact-88598

### Valeur

⭐⭐⭐⭐ pour RPA / enterprise automation.

# 4. Automation Anywhere Agentic Quest — challenges gratuits avec certificates

Automation Anywhere propose aussi **Agentic Quest**, gratuit pour tous.

Les challenges peuvent être réalisés avec Community Edition / Automation 360 selon le challenge.

Après un challenge réussi :

- un Submission ID est généré ;
- le candidat peut télécharger un certificate associé ;
- le challenge valide une réalisation pratique.

> Ce sont des challenge certificates, pas les certifications professionnelles Advanced/Master.

Sources :

- https://pathfinder.automationanywhere.com/faq
- https://pathfinder.automationanywhere.com/botgames/validate

# 5. Astronomer / Apache Airflow — promotion gratuite fin août 2026

La certification **Apache Airflow 3 Fundamentals** d'Astronomer coûte normalement environ **150 $**.

Cependant, **Airflow Summit 2026**, du **31 août au 2 septembre 2026**, annonce la possibilité de passer gratuitement l'examen de certification Airflow 3 pendant l'événement.

```text
Prix normal       ~150 $
Promo événement      0 $
Événement          31/08–02/09/2026
```

À classer comme **promotion événementielle**, pas gratuité permanente.

Sources :

- https://www.astronomer.io/certification/
- https://airflowsummit.org/

# 6. Celonis — training gratuit mais certifications payantes

Celonis Academy offre gratuitement :

- online training ;
- hands-on exercises.

En revanche :

```text
Qualification Exam attempt   75 $
Certification Exam           payant selon examen
```

Les Qualification Exams génèrent des qualifications/badges, mais ne sont pas gratuits.

Ne pas confondre **free training** et **free credential**.

Sources :

- https://academy.celonis.com/pages/your-journey
- https://academy.celonis.com/pages/celonis-qualifications
- https://academy.celonis.com/pages/faq-certification-exams

# 7. JFrog / APIsec — formation gratuite ≠ certification gratuite

## JFrog

JFrog propose des contenus self-paced gratuits, mais l'examen de certification est acheté séparément.

## APIsec University

APIsec propose beaucoup de formation gratuite, mais ses certifications professionnelles sont payantes, par exemple selon la grille observée :

```text
CASA / ACP       ~250 $
ASCP             ~450 $
```

Ne pas les classer comme certifications gratuites permanentes.
