# BCSP — safety professional certifications

> Certifications de personne du Board of Certified Safety Professionals (BCSP), couvrant safety, construction safety, occupational hygiene, training et management.
>
> **Vérification : 28 août 2026**

---

# 1. Tarification BCSP

BCSP permet d'acheter application et examen séparément ou via un combo légèrement remisé.

Pour les credentials principaux :

## CSP / ASP / SMP

- application : **160 $** ;
- single exam : **350 $** ;
- app + exam combo : **494 $** ;
- exam bundle deux tentatives + self-assessment : **600 $** ;
- app + exam bundle combo : **744 $**.

## OHST / CHST / CIT

- application : **140 $** ;
- exam : **300 $** ;
- app + exam combo : **426 $**.

## STS / STSC

- application : **120 $** ;
- exam : **185 $** ;
- app + exam combo : **293 $**.

Source :

- https://www.bcsp.org/credentials-at-a-glance

---

# 2. CSP — Certified Safety Professional

BCSP décrit le CSP comme son credential SH&E de référence.

## Prérequis

- bachelor degree minimum ;
- **4 ans** d'expérience SH&E ;
- au moins 50 % de l'activité dans du travail professional-level preventive safety ;
- détenir un **BCSP-approved credential** préalable.

## Coûts

```text
Application   160 $
Exam          350 $
```

ou combo : **494 $**.

Renewal : **180 $** avec exigences de recertification / points.

Source :

- https://www.bcsp.org/certified-safety-professional-csp

**Valeur : ⭐⭐⭐⭐⭐** dans le marché safety US/international.

---

# 3. ASP — Associate Safety Professional

Peut servir de credential préalable au CSP.

Prérequis :

- bachelor degree ; ou associate degree SH&E avec volume de cours requis ;
- un an d'expérience SH&E professional-level.

Coût combo : **494 $**.

Renewal : **170 $**.

Source :

- https://www.bcsp.org/associate-safety-professional-asp

---

# 4. SMP — Safety Management Professional

Orientation management.

Prérequis :

- pas de diplôme minimum imposé ;
- **10 ans d'expérience** ;
- au moins 35 % des tâches liées au management de programmes/process/personnel safety.

Coût combo : **494 $**.

Renewal : **170 $**.

---

# 5. CHST — Construction Health and Safety Technician

- application : 140 $ ;
- exam : 300 $ ;
- combo : **426 $** ;
- renewal : 145 $.

Prérequis :

- 3 ans d'expérience construction safety ;
- au moins 35 % des duties dans SH&E technique.

Très intéressant pour compléter un PMI-CP / construction profile.

---

# 6. OHST — Occupational Hygiene and Safety Technician

Même structure tarifaire que CHST :

- combo **426 $** ;
- renewal 145 $.

Orientation occupational hygiene + safety technique.

---

# 7. CIT — Certified Instructional Trainer

Credential spécifique aux personnes qui développent et délivrent de la formation SH&E.

- application + exam combo : **426 $** ;
- prerequisite : **135 heures** de teaching / training / development dans une spécialité SH&E ;
- renewal : **145 $**.

Bon exemple de croisement entre safety et learning & development.

---

# 8. STS / STSC

## Safety Trained Supervisor

## Safety Trained Supervisor Construction

Tarif combo : **293 $**.

Ces credentials visent les managers/supervisors qui ne sont pas nécessairement des safety professionals à plein temps.

Ils exigent notamment :

- 30 h de safety/environmental training ;
- expérience supervision / travail selon route.

Renewal : **70 $**.

---

# 9. TCO et progression

Le parcours vers CSP depuis zéro peut impliquer :

```text
Degree / eligibility
+ ASP ou autre approved credential
+ CSP application/exam
+ renewal
+ recertification activities
```

Donc :

**CSP ≠ simplement 494 $.**

Le prix exam est très raisonnable ; l'éligibilité est la vraie barrière.

---

# 10. Positionnement avec NEBOSH / IOSH

| Objectif | Credential |
|---|---|
| Safety course manager général | IOSH Managing Safely |
| Qualification internationale safety | NEBOSH IGC / Diploma |
| US-style professional certification | BCSP ASP/CSP |
| Construction safety | BCSP CHST |
| Chartered professional status UK | CMIOSH |

Un profil international peut cumuler NEBOSH + CSP/CMIOSH, mais le TCO et les prérequis sont très différents.
