# 0. Légende : ne pas tout appeler « certification »

| Code | Nature | Exemple |
|---|---|---|
| **CERT** | certification de personne avec examen/assessment | AACE PSP, BCSP CHST, AWS CWI |
| **QUAL** | qualification / statut professionnel avec expérience, dossier ou interview | MRICS, MCIOB, CEng |
| **ACC** | accréditation professionnelle liée à un scheme | BREEAM Assessor, Fitwel Ambassador |
| **REG** | exigence réglementaire, habilitation, carte ou attestation | AIPR, CACES, SSIAP |
| **COURSE** | credential / certificat de parcours ou produit | Procore Certification |
| **ORG** | qualification/certification d'entreprise, pas de personne | QUALIBAT, ISO 9001 entreprise |

Le dépôt conserve la logique TCO :

```text
exam_fee
mandatory_training
mandatory_credentials
application_fee
membership
first_cycle_tco
renewal_tco
```

# 23. Taille du radar 2026

En comptant les spécialités explicitement nommées dans ce fichier, le domaine construction dépasse déjà largement **150 credentials / qualifications / accréditations / catégories réglementaires** avant même de compter :

- toutes les certifications fire protection NICET ;
- toutes les licences professionnelles d'architecte/PE/ingénieur par État ou pays ;
- toutes les cartes chantier nationales ;
- toutes les qualifications artisanales ;
- toutes les certifications fabricants ;
- les milliers de certifications produits et bâtiments.

L'objectif de `human-skills` reste de recenser ce qui produit une **preuve professionnelle portable et identifiable**, avec un TCO et un statut clair.
