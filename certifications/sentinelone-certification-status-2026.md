# SentinelOne certification status & pricing visibility — 2026

> Revue : **29 août 2026**, dans le cadre d'un balayage des vendors EDR/XDR après l'ajout de CrowdStrike (`crowdstrike-certification-2026.md`).

---

# Conclusion rapide

Contrairement à CrowdStrike, **SentinelOne University n'est pas un programme d'inscription individuelle ouverte** :

- accès **via le Customer Portal**, réservé aux clients/partenaires avec un compte actif ;
- modèle **abonnement annuel** (paliers Essentials / Premium), pas de tarif à l'examen affiché publiquement ;
- inscription/achat **exclusivement via contact commercial** (`sales@sentinelone.com` ou account representative) — aucun checkout self-service trouvé ;
- certifications identifiées via sources tierces (non confirmées officiellement dans ce format) : **SIREN** (SentinelOne Incident Response Engineer, ~45h), **CTP** (Certified Technical Professional, orienté partenaires techniques), **CSP** (Certified Sales Professional, orienté revendeurs).

### Classification correcte

```text
Accès              customer/partner portal uniquement
Modèle tarifaire    abonnement annuel (Essentials/Premium), pas de prix à l'examen public
Achat individuel    non confirmé — contact commercial requis
```

**Ne pas documenter de prix inventé.** À l'inverse de CrowdStrike (250 $/examen, self-service Pearson), SentinelOne ne correspond pas au format "certification individuelle achetable" de ce dépôt en l'état — probablement hors périmètre plutôt qu'à re-rechercher, sauf annonce d'un programme public équivalent.

Source :

- https://www.sentinelone.com/global-services/university/

# À poursuivre

- confirmer si un accès individuel hors organisation cliente/partenaire existe réellement (non trouvé lors de cette revue) ;
- prix Essentials vs Premium si un jour publié ;
- statut des certifications SIREN/CTP/CSP à confirmer sur une source officielle primaire (trouvées uniquement via un article tiers).
