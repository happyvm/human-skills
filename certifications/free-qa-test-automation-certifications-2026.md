# Free QA & test automation certifications — 2026

> Revue : **28 août 2026**. Cette fiche regroupe les certifications et credentials gratuits autour du test logiciel, test automation et quality engineering.

---

# 1. Katalon Practitioner Certification — vraie certification hands-on gratuite

Katalon Academy confirme explicitement que la **Practitioner Certification** et Katalon Studio sont disponibles **at no cost**.

Il n'y a pas d'examen traditionnel : la certification est obtenue en réalisant des activités réelles dans Katalon Studio, suivies automatiquement par le produit.

```text
Certification      Katalon Practitioner
Prix               0 $
Produit requis      Katalon Studio Free suffit
Examen             aucun
Validation          usage réel / hands-on
Validité            2 ans
PDF certificate     oui
LinkedIn            oui
```

Exemples d'exigences actuelles :

- créer des test cases ;
- créer des test objects ;
- variables ;
- test suites ;
- test suite collections ;
- data files ;
- exécutions réelles.

Katalon affiche plus de **5 700** titulaires lors de la revue.

### Valeur

⭐⭐⭐⭐⭐ pour QA / automation, car il s'agit d'une validation de pratique réelle et non d'un QCM théorique.

Sources :

- https://academy.katalon.com/certifications/practitioner/
- https://academy.katalon.com/certifications/
- https://academy.katalon.com/learning-path/practitioner-certification-fast-track/

# 2. Katalon Professional Certification — certification gratuite, Enterprise requis

Katalon indique :

- certification elle-même **gratuite** ;
- aucun examen traditionnel ;
- validation par activités réelles ;
- Katalon Studio **Enterprise** nécessaire ;
- le **trial de 30 jours** peut être utilisé pour réaliser les exigences sans achat.

```text
Certification       0 $
Licence requise     Enterprise
Trial gratuit       30 jours
Examen              aucun
Validité            2 ans
```

Exemples de compétences :

- custom keywords ;
- data-driven testing ;
- parallel execution ;
- CLI / CI-CD ;
- cloud executions ;
- debugging ;
- scalable automation ;
- AI agents et MCP.

### Classement

**Gratuit réalisable sous condition temporelle** : la certification est gratuite, mais l'accès gratuit aux fonctions Enterprise est limité au trial si le candidat n'a pas déjà une licence.

Source :

- https://academy.katalon.com/certifications/professional/

# 4. BrowserStack Test University — certifications gratuites

La page Test University actuelle affiche une section **Get BrowserStack Certified** avec :

- **BrowserStack Manual Testing Expert** ;
- **BrowserStack Automation Testing Expert**.

Le CTA actuel indique **Get Started for Free**.

BrowserStack avait officiellement annoncé Test University comme :

- accessible à tous les apprenants **free of cost** ;
- fournissant un accès gratuit au BrowserStack Cloud pour les labs ;
- délivrant certificates/badges après les parcours.

Les deux certifications portent sur :

### Manual Testing Expert

- cross-browser testing ;
- browser/device compatibility ;
- diagnostic de problèmes ;
- BrowserStack Live.

### Automation Testing Expert

- automation frameworks ;
- BrowserStack Automate ;
- exécution de tests automatisés à l'échelle ;
- BrowserStack Cloud.

```text
Training platform      free access annoncé
Certification          Manual Testing Expert / Automation Testing Expert
Current CTA             Get Started for Free
```

### Niveau de certitude

🟢 **fort**, mais BrowserStack ne publie pas actuellement une FAQ tarifaire aussi explicite que Katalon avec la phrase `exam price = $0`. Vérifier l'écran d'inscription final si la plateforme change son modèle.

Sources :

- https://www.browserstack.com/test-university
- https://www.browserstack.com/blog/introducing-test-university/

# 5. Applitools Test Automation University — certificates gratuits

**Test Automation University (TAU)** d'Applitools propose gratuitement une grande bibliothèque de cours de test automation.

Le modèle comprend :

- vidéos ;
- transcripts ;
- quizzes ;
- points / ranks ;
- badges ;
- certificates.

Technologies couvertes notamment :

- Selenium WebDriver ;
- Java ;
- Python ;
- Cypress ;
- Playwright ;
- Appium ;
- WebdriverIO ;
- API testing ;
- Jenkins / CI ;
- visual testing ;
- accessibility testing ;
- test automation architecture.

```text
Prix cours         0 $
Quizzes            oui
Certificates       oui
Type               course certificates / learning credentials
```

Sources :

- https://testautomationu.applitools.com/

# 6. LambdaTest certifications — programme actif, gratuité non suffisamment publiée

LambdaTest maintient activement en 2025/2026 des certifications avec pages de vérification publique, par exemple :

- Selenium 101 ;
- Selenium Java 101 ;
- Selenium Python 101 ;
- Selenium Advanced ;
- TestNG ;
- Manual Testing ;
- Cypress / autres tracks selon catalogue.

Les pages de titulaires confirment que le programme est encore utilisé récemment.

Cependant, les pages publiques explorées ne publient pas suffisamment clairement **le coût d'inscription actuel à la certification**.

### Statut

🟡 **programme certifiant actif, prix à confirmer**.

Ne pas le classer comme gratuit permanent tant que l'écran d'inscription / FAQ actuelle ne confirme pas 0 $.

Source :

- https://www.lambdatest.com/certified/
