# 1. Prosci Change Management

Prosci est un bon exemple de credential où **formation et certification sont un même produit**.

**Auto-formation officielle et gratuite (partielle) :** [prosci.com/resources/downloads](https://www.prosci.com/resources/downloads) — eBooks, worksheets, checklists et vidéos gratuits en amont du programme certifiant payant.

## Change Management Certification Programme

Tarifs Prosci Europe observés pour septembre 2026 :

- **3 386 €** pour le programme virtuel de trois jours ;
- **3 810 €** pour le programme présentiel ;
- taxes applicables en sus.

Le tarif couvre notamment :

- formation ;
- supports ;
- outils / ressources ;
- parcours de certification.

Exemple France : sessions en français proposées en ligne ou en région parisienne.

Sources :

- https://eu-store.prosci.com/training.html
- https://eu-store.prosci.com/cert-vir-eu-sep0126-fr.html
- https://eu-store.prosci.com/training/cert-f2f-eu-sep2226-fr.html

**Valeur CV estimée : ⭐⭐⭐⭐⭐** pour transformation, change management, adoption et grands programmes.

## Prosci Certified Advanced Change Practitioner — PCACP

L'examen avancé seul est affiché autour de :

- **545 €** sur le store Europe consulté ;
- **600 $** sur la page globale Prosci.

Mais ce tarif est très trompeur si l'on part de zéro.

### Prérequis

Prosci exige :

1. le **Prosci Change Management Practitioner / Certification Program** ;
2. les **quatre Model Mastery Programs** ;
3. puis l'examen PCACP.

Le vrai TCO du PCACP est donc **plusieurs milliers d'euros**, très au-dessus des 545 € affichés pour l'examen final.

Sources :

- https://www.prosci.com/solutions/pcacp
- https://eu-store.prosci.com/p-vir-mm24e-eu.html

**Valeur CV : ⭐⭐⭐⭐⭐** dans une carrière réellement centrée change/transformation ; faible ROI si le changement organisationnel n'est qu'une compétence secondaire.

## APMG Change Management (PCM) — alternative à Prosci

**QUAL — 🌍 INT · UK-origin**

Contrairement à Prosci (produit intégré formation+outillage), l'accréditation **APMG Change Management** suit le modèle classique Foundation → Practitioner avec des examens achetables séparément via l'**APMG Store**, un peu comme PRINCE2/MSP.

```text
Practitioner exam    448 £ TTC (voucher -25 % → 336 £)
Foundation exam       prix non confirmé lors de cette revue
```

Un exam bundle inclut généralement l'ouvrage *Effective Change Manager's Handbook*.

Source :

- https://store.apmg-international.com/certification/change-management

**Statut prix : 🟡 partiellement confirmé.** Page boutique officielle bloquée lors de cette revue (403) ; le prix Practitioner est corroboré par plusieurs pages APMG (bundle produit, code promo) mais pas vérifié en accès direct — **à revérifier au checkout**.

**Pertinence :** alternative plus légère que Prosci pour un profil qui veut une accréditation change management reconnue sans s'engager dans le parcours complet Prosci (Practitioner + 4 Model Mastery Programs + PCACP).

# 2. SABSA — Enterprise Security Architecture

SABSA Chartered Security Architect Foundation est particulièrement intéressant pour une trajectoire architecture + sécurité.

Mais contrairement à TOGAF, il n'existe pas de voie simple self-study + exam.

## Exigence de formation

The SABSA Institute précise que les examens de certification ne peuvent être passés **qu'après une formation fournie par un Accredited Education Partner (AEP)**.

Pour Foundation :

```text
Official SABSA Foundation training
             ↓
F1 + F2 examinations
             ↓
SABSA Chartered Security Architect – Foundation (SCF)
```

Source :

- https://sabsa.org/training-schedule/
- https://sabsa.org/certification/

## Exemple de prix Europe

Le partenaire TSTC affiche en 2026 :

- Amsterdam : **3 200 € HT** ;
- Bruxelles : **3 200 € HT** ;
- Live Online : **3 200 € HT**.

Source :

- https://www.tstc.nl/index.php/en/training/sabsa-foundation-training

Une adhésion SABSA Institute est proposée à **£50/an**, mais elle doit être distinguée du coût permettant d'obtenir le SCF.

Source :

- https://sabsa.org/membership-benefits/

## SABSA Practitioner (SCP) — modules Advanced

Comme pour Foundation, il n'existe pas de voie self-study + exam isolé : le Practitioner (**SABSA Chartered Architect — Practitioner, SCPR**) s'obtient en réussissant **un seul module Advanced au choix parmi A1 à A5** (Risk Assurance & Governance, Architectural Design, etc.), chacun vendu comme un bloc formation + examen par un AEP.

```text
SABSA Foundation (prérequis obligatoire)
             ↓
1 module Advanced (A1–A5)
             ↓
SABSA Chartered Architect — Practitioner (SCPR)
```

Exemples de prix observés (2026) :

```text
David Lynas Consulting — A1, 5 jours    prix variable selon devise/région du site
ALC Training — A1 virtuel               4 850 AU$ + GST
ALC Training — A1 présentiel            5 450 AU$ + GST
```

Les deux formats incluent l'examen (QCM/ouvert selon partenaire) et le badge Credly ; ALC précise un examen **open-book, project-based**, avec choix de 2 questions sur 5 et un délai de rendu de 4 semaines.

Sources :

- https://davidlynas.com/sabsa-training/sabsa-a1-risk-assurance-governance/
- https://alctraining.com.au/course/sabsa-advanced-risk-assurance-governance/
- https://sabsa.org/certification/

**Statut prix : 🟡 exemples de partenaires AEP, pas de tarif catalogue unique publié par le SABSA Institute.** Comme pour Foundation, le prix dépend du partenaire, de la devise et de la région — à revérifier au moment de l'inscription.

**TCO combiné Foundation + Practitioner (un seul module Advanced), ordre de grandeur** : env. **3 200 € + 3 000–3 500 €** selon partenaire/devise, soit environ **6 000–7 000 €** avant taxes — donc un palier nettement au-dessus de TOGAF ou CISSP pour un profil équivalent.

Master (SCM) nécessite les cinq modules Advanced A1–A5 et reste hors du périmètre TCO documenté ici : voir `research/over-500-watchlist.md`.

**Valeur CV : ⭐⭐⭐⭐⭐** pour Enterprise Security Architect / Security Architecture.

# 3. IIBA CBAP — Certified Business Analysis Professional

**Auto-formation officielle et gratuite :** [Global Business Analysis Core Standard](https://www.iiba.org/) sur iiba.org — accessible même aux non-membres.

IIBA publie actuellement :

- application : **145 $** ;
- examen CBAP : **505 $** ;
- premier an de membership inclus avec l'examen selon la grille IIBA ;
- recertification : **85 $ membre / 120 $ non-membre**.

## Coût initial

```text
Application   145 $
Exam          505 $
------------------
Total         650 $ ≈ 558 €
```

Le CBAP est valable trois ans et doit ensuite être recertifié.

Sources :

- https://www.iiba.org/business-analysis-certifications/cbap/
- https://www.iiba.org/business-analysis-certifications/certification-fees/

**Valeur CV : ⭐⭐⭐⭐⭐** pour Business Analysis, requirements, transformation métier et pilotage transverse.

### À distinguer : CCBA

CCBA est moins cher :

```text
Application 145 $
Exam        405 $
-----------------
Total       550 $
```

À la conversion EUR actuelle cela reste sous 500 € avant éventuelles taxes ; CCBA doit donc être classé dans la tranche inférieure.

# 4. DAMA CDMP — Data Management

**Auto-formation officielle :** [damadmbok.org/resources](https://www.damadmbok.org/resources) — papers et case studies gratuits ; un practice exam gratuit est inclus à l'achat de l'examen.

DAMA International facture actuellement **311 $ par examen online**, frais de proctoring compris.

## Associate

- 1 examen Data Management Fundamentals ;
- **311 $** ;
- donc tranche `<500 €`.

## Practitioner

Requiert :

- Fundamentals ;
- deux Specialist Exams ;
- score minimum de niveau Practitioner ;
- expérience professionnelle correspondante.

```text
3 × 311 $ = 933 $ ≈ 801 €
```

## Master

Même nombre d'examens, mais seuil de réussite et expérience plus élevés :

```text
3 × 311 $ = 933 $ ≈ 801 €
```

Les examens / badges ont des fenêtres de validité à respecter pour construire le titre et la certification est ensuite maintenue selon les règles DAMA.

Sources :

- https://dama.org/certification/exam-information-and-pricing/
- https://dama.org/cdmp-frequently-asked-questions/

**Valeur CV : ⭐⭐⭐⭐–⭐⭐⭐⭐⭐** pour Data Governance / Data Management / CDO office.

# 5. HRCI — SPHR et GPHR

**Auto-formation officielle et gratuite :** [Exam Content Outlines](https://www.hrci.org/certifications/exam-preparation-resources) — gratuits, base des packages payants (practice exams, flashcards).

HRCI publie la grille suivante :

| Credential | Application | Exam | Total |
|---|---:|---:|---:|
| PHR | 100 $ | 395 $ | **495 $** |
| SPHR | 100 $ | 495 $ | **595 $** |
| SPHRi | 100 $ | 495 $ | **595 $** |
| GPHR | 100 $ | 495 $ | **595 $** |

Ainsi, PHR reste sous la barre de 500 $ tandis que les certifications senior/global basculent juste au-dessus.

Pour GPHR, le credential est valide trois ans et exige 60 crédits de recertification, dont 15 Global.

La documentation HRCI de recertification consultée affiche une **recertification application fee de 169 $**.

Sources :

- https://www.hrci.org/certifications/apply-for-certification/exam-fees
- https://www.hrci.org/certifications/individual-certifications/gphr

**Valeur CV : ⭐⭐⭐⭐–⭐⭐⭐⭐⭐** dans les métiers RH, surtout sur marché international.

# 6. SHRM — correction 2026

**Auto-formation officielle et gratuite (partielle) :** [shrm.org/credentials/certification/exam-preparation](https://www.shrm.org/credentials/certification/exam-preparation) — questions retirées gratuites (10 par set) et démo gratuite du SHRM Learning System.

Une ancienne version du handbook 2026 montrait des tarifs supérieurs. La **page officielle actuelle SHRM** affiche désormais pour la fenêtre fin 2026 :

### Early bird

- membre : **350 $** ;
- non-membre : **450 $**.

### Standard

- membre : **399 $** ;
- non-membre : **499 $**.

Cela vaut actuellement pour SHRM-CP et SHRM-SCP sur la grille publique.

Les examens seuls appartiennent donc désormais à la tranche `<500 €`.

Le **SHRM Certification Prep System** est facultatif et coûte beaucoup plus cher :

- 820 $ membre ;
- 1 130 $ non-membre.

Il ne doit donc pas être intégré au TCO minimal si le candidat peut préparer autrement.

Sources :

- https://www.shrm.org/credentials/certification
- https://learningsystem.shrm.org/chapters/2026-shrm-certification-prep-system-online-only.html

# 7. SAFe — nouveau modèle proctored exam

Scaled Agile a modifié certains chemins en 2026.

**Auto-formation officielle et gratuite :** [scaledagile.com/resources](https://scaledagile.com/resources/) — Resource Center et framework SAFe explorables gratuitement.

Pour plusieurs credentials, il est désormais possible d'acheter directement un **proctored exam sans formation obligatoire**, notamment :

- SAFe Agilist ;
- SAFe Practitioner ;
- SAFe Scrum Master ;
- SAFe Product Owner/Product Manager ;
- AI-Native Foundations.

## Prix du proctored exam

Scaled Agile indique :

- **495 $ + taxes** ;
- deux tentatives dans une fenêtre de 60 jours.

Source :

- https://support.scaledagile.com/en/articles/15452551-proctored-exams-faq-overview-and-general-information
- https://support.scaledagile.com/en/articles/9791437-general-exam-faqs

### Cas France

Le prix hors taxes converti en euros reste sous 500 €.

Avec une TVA française de 20 % si elle est effectivement appliquée au checkout :

```text
495 $ × 1,20 = 594 $
≈ 510 € au taux de référence utilisé par le dépôt
```

SAFe est donc une **entrée frontière** : vérifier le prix TTC réel au checkout.

Pour les autres certifications SAFe, la formation complète reste obligatoire avant l'examen.

# 8. FinOps — attention au choix exam-only vs formation

Le parcours FinOps Certified Practitioner illustre l'importance de ne pas confondre formation et certification.

Les prix publics 2026 relevés autour du catalogue FinOps sont :

- examen seul : **325 $** ;
- self-paced + examen : **500 $** ;
- instructor-led : autour de **1 500 $** chez le fournisseur global ;
- une offre française Global Knowledge affiche **1 695 €** pour la formation FOCP.

L'examen seul reste donc dans la tranche `<500 €`.

Le prix d'une formation instructor-led **ne doit pas devenir artificiellement le TCO minimal** puisqu'elle n'est pas obligatoire pour le Practitioner.

Sources secondaires à revalider dans le checkout FinOps Foundation :

- https://learn.finops.org/
- https://www.globalknowledge.com/fr-fr/formation/linux/cloud_computing/finops/vc/langfr

## FinOps Certified Professional

Le parcours Professional est plus complexe et repose sur plusieurs credentials / prérequis. Son **TCO exact 2026 reste à consolider** avant ajout au catalogue définitif.

Statut : `RESEARCH`.

# 9. Achats / procurement — CPSM

Le Certified Professional in Supply Management (CPSM) mérite une analyse séparée car il exige plusieurs examens.

Une synthèse ASCM 2026 basée sur la grille ISM relevée le 28 juillet 2026 indique :

- **495 $ par examen pour les membres** ;
- **795 $ par examen pour les non-membres** ;
- trois examens obligatoires ;
- application : 0 $ membre / 295 $ non-membre ;
- recertification : 135 $ membre / 295 $ non-membre.

### Examens seuls

Membre :

```text
3 × 495 $ = 1 485 $
```

Non-membre :

```text
3 × 795 $ + 295 $ application
= 2 680 $
```

Le Learning System est vendu séparément et ne doit être inclus que si choisi.

Source de consolidation 2026 :

- https://jobs.ascm.org/career-resources/on-the-job-3/cpsm-certified-professional-in-supply-management-guide-2026-96

> Cette entrée doit encore être recroisée avec le checkout ISM avant d'être considérée comme tarif officiel définitif dans le dépôt.

**Valeur CV : ⭐⭐⭐⭐⭐** dans procurement / strategic sourcing / supply management.
