# 1. AIPMM — Certified Product Manager

AIPMM distingue explicitement ses **certifications** des simples course certificates.

Le programme est basé sur un body of knowledge et un examen proctoré.

## CPM — Certified Product Manager

Voucher standalone officiel : **500 $**.

Le checkout 2026 inclut :

- **2 tentatives** ;
- **1 an** pour compléter les tentatives ;
- aucun course material ;
- credential considéré comme **lifetime achievement**, sans expiration.

Le candidat peut donc préparer l'examen par ses propres moyens sans acheter une formation AIPMM Authorized Training Partner.

Source :

- https://aipmm.com/cpm
- https://members.aipmm.com/offers/54WcNwqL/checkout

Compétences :

- product lifecycle ;
- business case ;
- market planning ;
- competitive analysis ;
- requirements ;
- launch planning ;
- phase-gate ;
- product / market data.

**Valeur : ⭐⭐⭐⭐** pour product management généraliste.

# 4. Pourquoi AIPMM est intéressant dans cette cartographie

AIPMM explique que seules certaines certifications peuvent être achetées en exam-only :

- CPM ;
- CPMM ;
- CBM.

Les autres credentials AIPMM passent généralement par un Authorized Training Partner.

AIPMM se déclare conforme aux principes **ANSI/ISO/IEC 17024:2012** applicables aux organismes de certification de personnes.

Source :

- https://aipmm.com/certification
- https://aipmm.com/contact

# 7. Rapport valeur / prix

## Certification formelle économique

```text
AIPMM CPM = 500 $
2 attempts
no mandatory training
no expiry
```

C'est un rapport prix / preuve intéressant dans le domaine product.

## Formation structurée premium

Product School ou Pragmatic peuvent être plus intéressants lorsqu'on achète avant tout :

- instruction live ;
- réseau ;
- framework propriétaire ;
- coaching / practice ;
- communauté.

Mais ils ne doivent pas être comparés sur le seul « prix d'un badge ».
