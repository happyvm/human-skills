# 1. Artisanat — CMA RS6996

## Créer son projet d'entreprise

**CERT — 🇫🇷 FR**

RS6996 est active depuis le **18 décembre 2024** jusqu'au **18 décembre 2029** et remplace l'ancienne RS5838.

Compétences :

- marché / positionnement ;
- statut juridique ;
- fiscal / social ;
- administration ;
- comptabilité / finance / trésorerie ;
- plan de financement ;
- coûts de revient ;
- commercial / communication ;
- RSE ;
- immatriculation / télédéclarations.

### Prix 2026 observé

```text
CMA Île-de-France       875 € / 35 h
CMA Nouvelle-Aquitaine  875 € / 35 h
CMA Grand Est           875 € / 35 h
CMA Bretagne            875 € / 35 h
CMA Occitanie           875 € / 35 h
```

Sources :

- https://www.cma-idf.fr/metiers-et-formations/creer-son-projet-dentreprise-presentiel
- https://cma-nouvelleaquitaine.fr/catalogue/creer-son-projet-d-entreprise-presentiel

**Priorité : ⭐⭐⭐⭐⭐** pour un projet artisanal.

# 2. Micro-entreprise artisanale — CMA RS6994

## Consolider son projet de micro-entreprise

**CERT — 🇫🇷 FR**

RS6994 remplace l'ancienne RS5070.

Travaille notamment :

- devis / factures ;
- plan de financement ;
- CA / résultat prévisionnel ;
- régime micro ;
- déclarations sociales / fiscales ;
- organisation administrative / comptable.

### Exemples 2026

```text
CMA Bretagne       450 € / 14 h
CMA Île-de-France  450 € / 14 h indicatif
CMA Normandie      525 € / 21 h
```

Sources :

- https://www.cma-bretagne.fr/produit/formation/creation-reprise-dentreprise/consolider-son-projet-de-micro-entreprise-parcours-initiation/
- https://formation.cma-normandie.fr/formations/creation-micro-lancement/

Pour une micro **non artisanale**, comparer avec CCI RS7438 / BGE / CréActifs dans [`entrepreneurship-startup-business-creation-2026.md`](entrepreneurship-startup-business-creation-2026.md).

# 3. Agriculture — RS7277

## Chambres d'agriculture France — Création ou reprise d'une entreprise agricole

**CERT — 🇫🇷 FR**

```text
décision France Compétences  24/09/2025
échéance                      24/09/2030
dernière délivrance possible 24/03/2031
```

La certification vise :

- foncier / infrastructures ;
- moyens de production ;
- choix juridiques / fiscaux / sociaux agricoles ;
- calendrier d'installation ;
- viabilité technico-économique ;
- présentation banques / cédants / partenaires.

Évaluation : dossier professionnel + soutenance orale.

Source : https://www.francecompetences.fr/recherche/rs/7277

**TCO : provider-dependent** selon Chambre, modules et financements.

# 5. Incubateurs / accélérateurs

Admission dans un accélérateur, demo day, incubation universitaire ou startup studio peut avoir beaucoup de valeur, mais cela ne constitue pas automatiquement une **certification de compétence**.

Règle du repo :

```text
sélection / accompagnement
≠ certification
```

Aucun credential généraliste d'accélérateur suffisamment standard, portable et tarifé n'est retenu en priorité devant les parcours déjà catalogués.

# 6. Microcredentials européens — radar

L'EIT développe des dispositifs entrepreneurship / innovation et publie des appels 2026 liés aux microcredentials et à l'EIT Label.

Mais la barre `human-skills` reste :

```text
credential individuel disponible
+ prix public
+ assessment clair
+ portabilité identifiable
```

À la revue du 28 août 2026, aucun microcredential entrepreneurial européen n'est assez stabilisé pour devenir une recommandation cœur.

Sources :

- https://www.eit.europa.eu/our-activities/opportunities
- https://www.eit.europa.eu/our-activities/opportunities/eit-label-call-applications-2026

Statut : `RADAR`.
