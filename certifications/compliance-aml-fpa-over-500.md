# 1. ACAMS — CAMS

Le **Certified Anti-Money Laundering Specialist (CAMS)** est l'un des credentials AML les plus connus mondialement.

**Auto-formation officielle (ACAMS, gamme CAMS/CAFS/CGSS ci-dessous) :** [acams.org/en/training/webinars](https://www.acams.org/en/training/webinars) — plus de 1000 h de contenu, une partie gratuite, avec crédits pour la certification/recertification.

## Prix 2026

### Standard CAMS package

- secteur privé : **2 095 $** ;
- secteur public : **1 595 $**.

Le package comprend :

- guide d'étude PDF ;
- flashcards ;
- eLearning ;
- cours électifs ;
- simulateur ;
- **examen CAMS**. — 🌍 INT

### Avec Virtual Classroom

- privé : **2 495 $** ;
- public : **2 095 $**.

### Options

- retake : **299 $** ;
- extension examen : **100 $** ;
- Virtual Classroom seule : **595 $**.

## Membership obligatoire

ACAMS précise qu'une **adhésion active est obligatoire pour obtenir et maintenir toute certification ACAMS**.

La page française consultée affiche une adhésion individuelle à **375 $**.

Le TCO d'un candidat privé partant de zéro est donc au minimum de l'ordre de :

```text
CAMS package        2 095 $
ACAMS membership      375 $
---------------------------
≈ 2 470 $ avant taxes
```

## Maintenance

La recertification CAMS est requise tous les trois ans.

Frais publiés :

- early : **200 $** ;
- standard : **250 $** ;
- late : **300 $**.

L'adhésion active reste nécessaire.

Sources :

- https://www.acams.org/fr/certifications/certification-cams
- https://www.acams.org/fr/adh%C3%A9sion/adh%C3%A9sion-acams-pour-les-particuliers

**Valeur CV : ⭐⭐⭐⭐⭐** en AML / financial crime / banque.

# 12. AFP — Certified Corporate FP&A Professional (FPAC)

Le **FPAC** est un credential spécialisé Financial Planning & Analysis.

## Fenêtre août–septembre 2026

### Early

- AFP Member : **1 025 $** ; — 🌍 INT
- Non-member : **1 420 $**.

### Standard

- Member : **1 125 $** ;
- Non-member : **1 520 $**.

Le tarif non-membre inclut une année de membership AFP.

Le tarif new applicant couvre les **deux parties** de l'examen.

La préparation officielle est facultative :

- Exam Prep Platform membre : **1 095 $** ;
- non-membre : **1 195 $**.

Elle ne doit donc pas être intégrée au TCO minimal.

## Prérequis

Le credential nécessite des conditions d'éducation et d'expérience autour de :

- financial analysis ;
- budgeting ;
- forecasting ;
- financial modeling ;
- corporate financial planning ;
- data / BI appliqués à FP&A.

Sources :

- https://fpacert.afponline.org/about-exam/deadlines
- https://fpacert.afponline.org/about-exam/eligibility

**Valeur CV : ⭐⭐⭐⭐⭐** pour FP&A / finance corporate.
