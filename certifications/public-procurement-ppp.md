# CP³P — APMG Public-Private Partnerships Certification Program

**Auto-formation officielle et gratuite (partielle) :** [APMG — Career-Ready Toolkit](https://apmg-international.com/) — ressources gratuites en complément de la formation payante dispensée par les Training Organizations APMG.

Le programme CP³P est développé avec / soutenu par plusieurs institutions multilatérales :

- African Development Bank ;
- Asian Development Bank ;
- EBRD ;
- Inter-American Development Bank ;
- Islamic Development Bank ;
- World Bank Group ;
- PPIAF.

Le **PPP Guide** officiel est disponible gratuitement.

- https://ppp-certification.com/

# Structure du credential

Le titre **CP³P Certified PPP Professional** nécessite de réussir trois examens :

```text
Foundation
   ↓
Preparation
   ↓
Execution
   ↓
CP³P Certified PPP Professional
```

## Foundation

Couvre :

- concepts PPP ;
- lifecycle ;
- terminology ;
- institutional framework ;
- principes de financement / risk allocation.

Foundation est obligatoire pour accéder aux niveaux suivants.

## Preparation

Orientation :

- project identification ;
- screening ;
- appraisal ;
- value for money ;
- bankability ;
- structuration initiale.

## Execution

Orientation :

- tendering ;
- drafting ;
- procurement process ;
- PPP contract management ;
- construction / operation phase management.

# Formation

Le programme peut être préparé :

- en self-study ;
- avec le PPP Guide gratuit ;
- avec training provider accrédité ;
- avec online training selon les ressources disponibles.

Les cours typiques indiqués par le programme sont :

- Foundation : environ 2 jours ;
- Preparation : environ 5 jours ;
- Execution : environ 5 jours.

La formation n'est pas à confondre avec l'examen régional APMG.
