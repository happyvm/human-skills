# Attention aux parcours Splunk avancés

Le **prix de l'examen** peut rester 130 $, alors que le TCO réel explose si des formations sont obligatoires.

Exemple : Splunk Enterprise Certified Architect :

- exam : **130 $** ;
- prérequis certifications ;
- coursework préalable : Architecting, Troubleshooting, Cluster Administration et Practical Lab.

Source :

- https://www.splunk.com/en_us/training/certification-track/splunk-enterprise-certified-architect.html

Splunk publie des prix corporate de formation pouvant atteindre plusieurs milliers de dollars par cours. Il faut donc classer séparément :

```text
EXAM PRICE
vs
FULL PATH TCO
```

Source training pricing :

- https://www.splunk.com/en_us/training/pricing.html
