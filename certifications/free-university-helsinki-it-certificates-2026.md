# Free University of Helsinki IT certificates — 2026

> Revue : **28 août 2026**. L'Université d'Helsinki propose plusieurs MOOCs informatiques gratuits avec exercices pratiques et certificats. Les certificats sont distincts des crédits ECTS : selon le parcours, le certificat peut être obtenu gratuitement sans inscription universitaire officielle.

---

# 1. Full Stack Open — certificat gratuit

La page actuelle indique explicitement :

```text
Course               totally free of charge
Course certificate   oui
Open University      non requis pour le certificat
ECTS                  optionnels / procédure séparée
```

Pour le certificat :

- réaliser suffisamment d'exercices pour obtenir une note de passage ;
- soumettre le code via GitHub / submission system ;
- télécharger le certificat dans le système.

L'Université précise :

> Course materials and a certificate (without credits) are available to everyone without official enrollment on the course.

Sources :

- https://fullstackopen.com/en/part0/general_info/
- https://www.helsinki.fi/en/admissions-and-education/open-university/multidisciplinary-themed-modules/full-stack

### Stack couverte

- React ;
- Node.js ;
- REST ;
- GraphQL ;
- MongoDB ;
- testing ;
- TypeScript ;
- React Native ;
- CI/CD ;
- containers ;
- relational databases ;
- configuration / runtime environments.

### Valeur

⭐⭐⭐⭐⭐ pour développement / DevOps, car les exercices reposent sur du code réellement soumis.

# 3. Python Programming MOOC 2026

Cours officiel 2026 du Department of Computer Science.

Deux blocs :

- **Introduction to Programming — BSCS1001** ;
- **Advanced Course in Programming — BSCS1002**.

Pour réussir :

```text
Programming exercises   obligatoires
Exam                    obligatoire
Passing grade           requis
Certificate             oui
University account      non requis pour étudier
```

Le FAQ 2026 indique :

- si vous obtenez une note de passage, un certificat est disponible dans le profil MOOC ;
- même lorsqu'un participant ne peut pas recevoir de crédits, il reçoit toujours un certificat à la réussite.

Sources :

- https://programming-26.mooc.fi/
- https://programming-26.mooc.fi/faq/

### Contenu

Introduction :

- variables / expressions ;
- conditions ;
- loops ;
- functions ;
- lists/dictionaries ;
- files/data ;
- modules ;
- programming exercises.

Advanced :

- objects/classes ;
- advanced data structures ;
- functional programming ;
- generators ;
- regex ;
- larger programming exercises.

### Valeur

⭐⭐⭐⭐⭐ : **Université + programmation réelle + examen + certificat gratuit**.

Vérifier la page spécifique de chaque édition avant de commencer pour confirmer le mécanisme de certificat téléchargeable ; ne pas supposer automatiquement qu'un cours listé au catalogue délivre le même certificate que Full Stack/Python.

Une séquence très forte :

```text

Python Programming MOOC — Advanced
Full Stack Open base 0–7

Full Stack Part 11 — CI/CD
```
