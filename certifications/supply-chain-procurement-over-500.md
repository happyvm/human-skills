# Supply chain, logistics & procurement — TCO des certifications

> Tarifs revérifiés fin août 2026. Cette page privilégie les bundles réellement nécessaires plutôt que le prix d'un examen isolé lorsqu'il n'est pas représentatif.

---

# ASCM / APICS

ASCM maintient quatre grandes certifications APICS :

- CPIM — Certified in Planning and Inventory Management ;
- CSCP — Certified Supply Chain Professional ;
- CLTD — Certified in Logistics, Transportation and Distribution ;
- CTSC — Certified in Transformation for Supply Chain.

## Bundles self-study 2026

Les tarifs publics ASCM relevés en juillet/août 2026 pour le bundle comprenant **Learning System + examen + second-chance exam** sont :

| Certification | Membre + Certification Upgrade | Autres acheteurs |
|---|---:|---:|
| CPIM | **2 275 $** | **3 175 $** |
| CSCP | **2 620 $** | **3 650 $** |
| CLTD | **1 980 $** | **2 760 $** |
| CTSC | **~2 275 $** | **~3 175 $** selon offre active |

Le tarif membre bas suppose le membership ASCM et le **Certification Upgrade**, affichés séparément sur certaines pages.

Points importants :

- membership non obligatoire pour passer l'examen ;
- le bundle inclut les supports et une seconde chance sous conditions ;
- maintien de la certification par points / professional development ;
- le TCO dépend donc du membership choisi et de la recertification.

Sources :

- https://www.ascm.org/learning-development/certifications-credentials/cpim/
- https://www.ascm.org/learning-development/certifications-credentials/cscp/
- https://www.ascm.org/learning-development/certifications-credentials/cltd/
- https://www.ascm.org/learning-development/certifications-credentials/ctsc/

# CSCMP SCPro

## SCPro Level One

Tarif standard observé :

- **650 $ membre CSCMP** ;
- **975 $ non-membre** ;
- options bundles avec learning materials plus élevées ;
- tarifs étudiants réduits sous conditions.

Level One valide les fondamentaux end-to-end de la supply chain.

Source :

- https://cscmp.org/CSCMP/Certify/SCPro_Certification/Level_One.aspx

## SCPro Level Two

Le parcours Level Two repose sur l'analyse d'un cas complexe et exige une validation d'éligibilité.

Le package officiel **Study Materials + Exam** est :

- **1 695 $ membre** ;
- **2 350 $ non-membre** ;
- une tentative ;
- accès aux supports 180 jours.

Source :

- https://cscmp.org/CSCMP/CSCMP/Certify/Level_Two/Exam_Dates_and_Policies.aspx

## SCPro Level Three

Le niveau supérieur fonctionne davantage comme une démonstration de compétences / projet appliqué. Le TCO exact doit être confirmé selon la cohorte et le processus actif.

# ISM — CPSM

## Certified Professional in Supply Management

Le CPSM demande **trois examens**.

Ordres de grandeur 2026 par examen :

- environ **495 $ membre** ;
- environ **795 $ non-membre**.

Soit, pour les examens seuls :

```text
membre :       3 × 495 $ ≈ 1 485 $
non-membre :   3 × 795 $ ≈ 2 385 $
```

À cela peuvent s'ajouter :

- application ;
- membership ;
- learning system / préparation ;
- retakes ;
- recertification.

ISM indique lui-même des fourchettes totales plus larges selon les supports choisis.

Source :

- https://www.ismworld.org/certification-and-training/certification/cpsm/

# ISM — CPSD

Certified Professional in Supplier Diversity.

ISM publie une fourchette de coût dépendant du statut membre et des ressources :

- membre : environ **495–1 337 $** ;
- non-membre : environ **795–2 028 $**.

Source :

- https://www.ismworld.org/certification-and-training/certification/cpsd/

# CIPS / MCIPS

Le Chartered Institute of Procurement & Supply structure son parcours autour de :

- Level 2 ;
- Level 3 ;
- Level 4 Diploma ;
- Level 5 Advanced Diploma ;
- Level 6 Professional Diploma ;
- expérience / membership menant à **MCIPS**.

Le TCO varie fortement selon :

- pays ;
- centre d'examen ;
- mode d'étude ;
- exemptions ;
- membership ;
- nombre d'unités ;
- tuition provider.

Il est donc préférable de stocker le coût **par qualification complète**, et non une pseudo-valeur unique mondiale.

Source :

- https://www.cips.org/qualifications

**Statut prix France : à consolider via CIPS / centres EMEA.**

# Quel signal pour quel objectif ?

## Supply chain généraliste / direction

**CSCP** est probablement le plus lisible internationalement.

## Planning / production

**CPIM**.

## Logistique / distribution

**CLTD**.

## Transformation

**CTSC**.

## Procurement / achats

**CPSM** ou parcours **CIPS → MCIPS**.

## Validation appliquée senior

**SCPro Level Two / Three**.
