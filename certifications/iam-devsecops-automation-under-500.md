# Okta

Okta affiche désormais **250 $ pour la première tentative** de ses examens de certification standards, avec :

- retake : **100 $** ;
- maintenance exam : **100 $** sur première tentative ;
- validité standard : **2 ans**.

L'exception majeure est **Okta Certified Technical Architect**, dont le board defense coûte **5 000 $**.

Source :

- https://www.okta.com/services/certification/

## Okta Certified Professional

Depuis le **6 juillet 2026**, Okta a retiré l'ancien Professional Hands-On Configuration Exam et impose désormais le **Professional Performance Exam**, 100 % pratique :

- 6 use cases hands-on ;
- pas de QCM traditionnel.

Source :

- https://support.okta.com/help/s/blog/a67WR00000Ljkk9YAB/okta-certified-professional-exam-changes

## Okta Certified Administrator

Examen mixte :

- DOMC ;
- use cases performance-based ;
- prix : **250 $** ;
- prérequis : certification Okta Professional active.

Source :

- https://www.okta.com/resources/whitepapers/administrator-hands-on-exam-study-guide/

### TCO

Un parcours Professional → Administrator représente au minimum :

```text
Professional      250 $
Administrator     250 $
----------------------
Total             500 $
```

hors retakes et maintenance.

**Valeur : ⭐⭐⭐⭐⭐** pour IAM / identity engineering.

```text

EX294 Ansible
+ au moins 3 specialist exams parmi EX374 / EX417 / EX457 / EX467...
```

```text
5 examens × 500 $ = 2 500 $ minimum
```

avant formation ou retakes.

- https://www.redhat.com/fr/services/certifications
