# 1. VDA 6.3 — Certified Process Auditor

Le VDA 6.3 est un credential très utilisé dans la supply chain automobile pour les audits de processus.

Le schéma VDA QMC comporte :

- qualification préalable ;
- expérience automobile ;
- connaissances quality management ;
- Core Tools ;
- examen de certification.

## Exemple officiel via partenaire VDA QMC / TÜV SÜD

Le cours **ID 382 — VDA 6.3 Examination for Certified Process Auditor** publié par TÜV SÜD India affiche :

- **15 000 INR HT / 17 700 INR TTC avec GST** pour l'examen ;
- 1 journée ;
- certificat VDA 6.3 avec registration number ;
- validité **5 ans**.

Ce prix est explicitement réservé au marché indien et **ne doit pas servir de prix France**.

La page permet néanmoins de documenter le modèle de qualification et les prérequis.

## Prérequis majeurs

Exemples mentionnés :

- formation / qualification ISO 9001 ou IATF 16949 auditor ;
- Automotive Core Tools ;
- expérience professionnelle automobile ;
- expérience quality management ;
- qualification VDA 6.3 préalable.

Source :

- https://www.tuvsud.com/en-in/store/academy-in/sectors/automotive/0208-vda-6-3-process-auditor-qualification-with-certified-examination

# 2. ISO 26262 — Functional Safety

Le marché contient plusieurs programmes de **Functional Safety Engineer / Professional** autour d'ISO 26262, notamment chez les organismes TÜV.

Le schéma historique TÜV SÜD comprend :

- modules de management de la functional safety ;
- system design / HARA ;
- software / hardware ;
- supporting processes ;
- examen de personnel.

Le titre **Functional Safety Engineer ISO 26262** est obtenu après examen dans les parcours concernés.

Les prix varient fortement selon :

- pays ;
- nombre de modules ;
- provider ;
- examen standalone vs bundle.

Le dépôt doit donc collecter un **TCO France/Europe** avant classement budgétaire définitif.

# 3. IATF 16949

IATF 16949 est le référentiel qualité automobile majeur.

Les qualifications d'auditeur doivent être distinguées :

- internal auditor ;
- supplier auditor ;
- second-party auditor ;
- certification-body auditor ;
- formations Core Tools associées.

Les termes « IATF certified auditor » peuvent désigner des niveaux et schémas différents. Ne pas présenter une simple formation interne comme une certification tierce partie équivalente.

# 3bis. intacs — Automotive SPICE (ASPICE) Assessor

**QUAL — 🌍 INT**

**intacs** (International Assessor Certification Scheme) délivre les certifications d'assesseur Automotive SPICE, référentiel d'évaluation de maturité process largement exigé par les OEM automobiles pour leurs fournisseurs logiciel/embarqué.

Comme VDA 6.3 et ISO 26262 ci-dessus, il n'existe pas de voie exam-only isolée : formation et certification sont vendues ensemble par des **intacs Training Providers** accrédités, l'examen lui-même étant administré/facturé séparément par le **VDA/ECQA**.

## Parcours

```text
intacs certified Provisional Assessor
   (co-assessor sous supervision d'un Assessor confirmé)
             ↓
intacs certified Competent Assessor
   (expérience d'assessments supplémentaire requise)
```

Un niveau **Process Expert** existe en parallèle/complément, souvent packagé avec le Provisional Assessor dans une formation combinée.

## Exemple de prix — partenaire européen (Knüvener Mackert)

```text
Formation Process Expert + Provisional Assessor (Combined Lane)   3 185 €
VDA/ECQA license fee                                                700 €
VDA/ECQA exam fee                                                   450 €
                                                          TOTAL   4 335 €
```

- 7 jours de formation, anglais, format online public ;
- remises possibles (-10 % à partir de 2 personnes, -15 % à partir de 4, -10 % freelance) et promotions ponctuelles ;
- license fee et exam fee sont facturés par VDA/ECQA, distincts du prix formation du training provider.

Source :

- https://www.knuevenermackert.com/en/training/training-intacs-certified-process-expert-and-provisional-assessor-automotive-spice
- https://intacs.info/

**Statut prix : 🟡 exemple d'un training provider, pas un tarif catalogue intacs unique.** Comme pour VDA 6.3 et SABSA, le prix dépend du partenaire, de la région et de la devise — à revérifier avant inscription.

**Pertinence :** profil ingénierie logicielle automobile / embarqué qui doit auditer ou faire auditer la maturité process fournisseur, complémentaire à IATF 16949 (QMS) et ISO 26262 (functional safety) plutôt que substituable.

# 4. IRIS Certification — Railway

Le secteur ferroviaire dispose du schéma **IRIS Certification**, piloté par UNIFE.

## Internal IRIS Auditor Training — UNIFE Academy 2026

UNIFE a annoncé en juillet 2026 un parcours officiel :

- cinq journées de virtual classroom ;
- self-study ;
- exercices / project work ;
- coaching individuel ;
- certificat d'**Internal IRIS Certification Auditor** après réussite.

Prix :

- **2 500 € par participant hors TVA**.

Sessions annoncées en allemand et anglais sur septembre–décembre 2026.

Source :

- https://iris-rail.org/index.php?content=global_information&desc=news&page=global

# 5. Railway vs automotive

Ces qualifications répondent à des besoins très différents :

| Secteur | Référentiels / credentials |
|---|---|
| Automotive QMS | IATF 16949 |
| Automotive process audit | VDA 6.3 |
| Automotive quality tools | APQP / PPAP / FMEA / SPC / MSA |
| Automotive functional safety | ISO 26262 |
| Automotive cyber | ISO/SAE 21434 |
| Railway QMS / performance | IRIS Certification |
| Railway RAMS / safety | EN 50126 / 50128 / 50129 et équivalents |
