# Certifications au-delà de 500 € — coût réel et TCO

> Catalogue des certifications et parcours dont le **coût réel pour obtenir ou maintenir le credential** dépasse environ 500 €.
>
> **Dernière vérification : 28 août 2026**

## Pourquoi cette page raisonne en TCO

À partir de 500 €, le prix affiché de l'examen devient souvent trompeur.

Une certification peut avoir :

- un examen à moins de 500 € mais des frais obligatoires d'application ou de maintenance ;
- plusieurs examens obligatoires ;
- une formation accréditée obligatoire ;
- un prérequis lui-même payant ;
- des frais de renouvellement ;
- des CPE / PDU / CPD à maintenir ;
- un examen pratique imposant un déplacement.

Le dépôt distingue donc :

```text
EXAM PRICE      prix du voucher / examen
FIRST-CYCLE TCO coût minimal réaliste pour obtenir et activer le titre
LONG-TERM TCO   maintenance / renouvellement sur plusieurs années
```

### Conversion utilisée

Pour les comparaisons indicatives en euros, cette page utilise le taux de référence BCE du **27 août 2026** :

```text
1 EUR = 1,1645 USD
1 USD ≈ 0,8587 EUR
```

Les montants en euros calculés à partir de dollars sont donc des **ordres de grandeur**. TVA, taux de carte bancaire et prix régionaux peuvent modifier le montant final.

Source : https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html

# 1. ISC2 — CISSP, CCSP, CGRC, CSSLP et concentrations

## Prix des examens EMEA

ISC2 publie directement ses prix régionaux.

Exemples :

- **CISSP : 719,04 €** ;
- **CCSP : 575,04 €** ;
- **CGRC : 575,04 €** ;
- **CSSLP : 575,04 €** ;
- **ISSAP / ISSEP / ISSMP : 575,04 €**.

À cela s'ajoute une **Annual Maintenance Fee de 135 $ par an** pour les membres titulaires de ces certifications. ISC2 ne facture qu'une seule AMF même si plusieurs de ces certifications sont détenues.

### TCO indicatif

```text
CCSP : 575,04 €
+ 3 × 135 $ d'AMF ≈ 348 €
= ≈ 923 € sur trois ans, hors éventuel coût des CPE
```

```text
CISSP : 719,04 €
+ ≈ 348 € d'AMF sur trois ans
= ≈ 1 067 € sur trois ans, hors éventuel coût des CPE
```

Le coût monétaire des CPE peut être nul si les crédits sont obtenus via des activités gratuites, mais l'obligation de maintien doit être intégrée à la décision.

Sources :

- https://www.isc2.org/register-for-exam/isc2-exam-pricing
- https://www.isc2.org/policies-procedures/amfs-overview

**Valeur CV : ⭐⭐⭐⭐⭐** pour CISSP ; **⭐⭐⭐⭐⭐** pour CCSP sur un profil cloud/security.

# 2. ISACA — CISA, CISM, CRISC, CGEIT, CDPSE

Les grandes certifications ISACA utilisent une tarification membre / non-membre.

Ordre de grandeur actuel :

- **575 $ membre** ;
- **760 $ non-membre** ;
- **50 $ de frais d'application** après réussite pour les certifications concernées.

Pour CISA, la maintenance annuelle est actuellement :

- **45 $ membre** ;
- **85 $ non-membre**.

### Cas non-membre — exemple CISA

```text
Exam                 760 $
Application           50 $
--------------------------
Obtention             810 $ ≈ 696 €

+ maintenance 3 ans  255 $ ≈ 219 €
--------------------------
≈ 915 € sur trois ans hors CPE
```

La voie membre peut réduire l'examen et la maintenance mais il faut alors ajouter le coût d'adhésion ISACA. Le TCO exact dépend donc du pays / chapitre et du maintien ou non de l'adhésion.

Sources :

- https://www.isaca.org/credentialing/cisa
- https://www.isaca.org/credentialing/cisa/maintain-cisa-certification
- https://www.isaca.org/credentialing/cism

**Valeur CV : ⭐⭐⭐⭐⭐** pour CISA/CISM/CRISC dans leurs domaines respectifs.

Exam          550 $

# 4. GIAC / SANS

GIAC est un cas à séparer en deux modèles.

## GIAC exam-only

Tarifs actuels :

- certification attempt : **999 $** ;
- retake : **899 $** ;
- extension : **479 $** ;
- practice exam : **399 $** ;
- renewal : **499 $**.

Un examen seul représente donc environ **858 €**, hors taxes.

## SANS + GIAC

La formation SANS associée peut coûter plusieurs milliers d'euros.

Sur des événements européens 2026, on observe des cours autour de **8 230 €**, auxquels peut s'ajouter une certification autour de **905 €**, avant taxes selon l'événement.

Le vrai budget d'un parcours SANS + GIAC est donc plutôt de l'ordre de :

```text
≈ 9 000 € pour une formation + certification
```

et non 999 $.

Source principale :

- https://www.giac.org/pricing

**Valeur CV : ⭐⭐⭐⭐⭐**, mais rapport valeur/prix très différent selon que l'employeur finance ou non la formation.

|---|---:|---:|---:|

Le modèle est différent : selon les conditions PECB, le paiement lié à la formation partenaire peut inclure :

- premier examen ;
- premier retake ;
- application à la certification ;
- première année d'AMF.

Le prix réel devient alors **le prix du partenaire**, qui varie fortement.

La formation accréditée est recommandée mais le parcours officiel permet également le self-study et la réservation de l'examen.

Source :

- https://certification.opengroup.org/examinations/exam-fees
- https://www.opengroup.org/certifications/togaf

> La grille publique Open Group accessible via la recherche peut être publiée sur une infrastructure de staging et doit être revérifiée au checkout avant achat.

**Valeur CV : ⭐⭐⭐⭐⭐** pour architecture d'entreprise / SI.

# 17. Veeam 2026 — prix encore à consolider

Le programme a changé :

- VMCA et VMCE sont retirés ;
- VMCE+ et VMCSE ont été annoncés pour Q2 2026 ;

- Veeam renvoie vers Pearson VUE pour le prix final de l'examen.

Cela signifie que le **TCO ne peut pas être réduit au voucher Pearson VUE** : il faut inclure la formation officielle obligatoire.
