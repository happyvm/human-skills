# F5 — nouveau modèle modulaire très compétitif

F5 a refondu sa certification BIG-IP Administrator.

## BIG-IP Certified Administrator

Le titre nécessite désormais **5 examens** :

1. F5CAB1 — Install, Initial Configuration, and Upgrade ;
2. F5CAB2 — Data Plane Concepts ;
3. F5CAB3 — Data Plane Configuration ;
4. F5CAB4 — Control Plane Administration ;
5. F5CAB5 — Support and Troubleshooting.

Chaque examen coûte :

- **50 $** en ligne via Certiverse ;
- **65 $** en test center Pearson VUE.

Source :

- https://support.education.f5.com/hc/en-us/articles/37607208476059-What-is-the-F5-Certified-Administrator-BIG-IP-F5-CA-BIG-IP-certification
- https://support.education.f5.com/hc/en-us/articles/37276542073371-Price-list-for-F5-Certified-exams

### TCO minimal

Fortinet maintient ses niveaux FCF/FCA/FCP/FCSS/FCX autour des examens NSE.

Source programme :

- https://www.fortinet.com/fr/training-certification

## FCF / FCA

Les niveaux d'entrée utilisent les formations/évaluations Fortinet Training Institute et sont traités dans le catalogue gratuit lorsqu'ils sont accessibles sans frais.

## NSE 4-6

Prix examen : **200 $** hors taxes.

## NSE 7 — changement au 2 novembre 2026

Au **28 août 2026** :

- NSE 7 : **200 $**.

À partir du **2 novembre 2026** :

- NSE 7 : **400 $** ;
- Industry certification exams : **400 $** ;
- NSE 7 recertification assessment : **400 $**.

Les NSE 4-6 restent à **200 $**.

- https://helpdesk.training.fortinet.com/support/solutions/articles/73000672897-nse-certification-program-notice-exam-fees
