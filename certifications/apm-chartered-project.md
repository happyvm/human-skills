# APM — Chartered Project Professional (ChPP)

> Statut professionnel chartered britannique pour les professionnels projet, programme et portefeuille.
>
> **Vérification : 28 août 2026**

---

# Vue rapide

| Route ChPP | Prix HT | Prix TTC UK publié | Quand |
|---|---:|---:|---|
| Pathway 1 | **£1 325** | **£1 590** | sans recognised assessment |
| Pathway 2 | **£900** | **£1 080** | recognised technical knowledge |
| Pathway 3 | **£900** | **£1 080** | recognised professional practice |
| Pathway 4 | **£300** | **£360** | technical + professional practice already recognised |
| Annual ChPP registration | **£99/an + VAT** | **£118.80** | après award |

---

# 1. Qu'est-ce que ChPP ?

Le **Chartered Project Professional — ChPP** est le chartered status de l'Association for Project Management, organisme chartered britannique de la profession projet.

Le statut atteste :

- technical knowledge ;
- professional practice ;
- ethical behaviour ;
- continuing professional development.

Après réussite, le titulaire peut utiliser le post-nominal :

```text
Name ChPP
```

Source :

- https://www.apm.org.uk/chartered-standard/
- https://www.apm.org.uk/chartered-standard/faqs/

---

# 2. Pathway 1 — route complète

Pour les candidats qui répondent aux critères mais ne disposent pas d'une recognised assessment utilisable.

Frais :

| Étape | HT | TTC |
|---|---:|---:|
| Stage 1 — application | **£730** | **£876** |
| Stage 2 — interview | **£595** | **£714** |
| Total | **£1 325** | **£1 590** |

Source :

- https://www.apm.org.uk/chartered-standard/pathway-1/

Le processus inclut notamment :

- application détaillée ;
- evidence de professional practice ;
- project/programme/portfolio overviews ;
- competence evidence ;
- interview ;
- proposers ;
- CPD declaration.

# 3. Pathway 2 — recognised technical knowledge

Pour un candidat disposant déjà d'une assessment reconnue sur la technical knowledge.

Frais :

| Étape | HT | TTC |
|---|---:|---:|
| Stage 1 | **£475** | **£570** |
| Stage 2 interview | **£425** | **£510** |
| Total | **£900** | **£1 080** |

Source :

- https://www.apm.org.uk/chartered-standard/pathway-2/

---

# 4. Pathway 3 — recognised professional practice

Même grille :

- stage 1 : **£475 HT / £570 TTC** ;
- stage 2 : **£425 HT / £510 TTC** ;
- total : **£900 HT / £1 080 TTC**.

APM cite notamment le **APM Project Management Qualification — PMQ** dans les mécanismes de validation / recognised assessment selon critères.

Source :

- https://www.apm.org.uk/chartered-standard/pathway-3/

---

# 5. Pathway 4 — technical + professional practice recognised

Lorsque les deux dimensions sont déjà couvertes par une recognised assessment :

- application + interview : **£300 HT** ;
- **£360 TTC**.

C'est un excellent exemple de credential dont le TCO dépend énormément des qualifications déjà détenues.

Source :

- https://www.apm.org.uk/chartered-standard/pathway-4/

---

# 6. Maintien du ChPP

Après award :

- annual registration fee : **£99 HT** ;
- **£118.80 TTC** publié ;
- première échéance 12 mois après award ;
- **35 heures de CPD par an** ;
- CPD log susceptible d'être audité.

Source :

- https://www.apm.org.uk/chartered-standard/faqs/

---

# 7. Retakes / resubmissions

Si une étape doit être répétée, les frais de l'étape correspondante doivent être repayés.

Cela signifie que le first-cycle TCO peut augmenter de :

- £730/475 selon application stage ;
- £595/425 selon interview ;
- ou £300 selon Pathway 4.

---

# 8. Évolution 2026–2027

APM travaille en 2026 sur une évolution du modèle d'assessment ChPP.

Timeline officielle :

- pilot / analyse en 2026 ;
- préparation transition late 2026–2027 ;
- nouveau modèle envisagé au printemps 2027 sous réserve d'approbation.

APM précise que le standard et la valeur des ChPP existants ne doivent pas être diminués par cette transition.

Source :

- https://www.apm.org.uk/chartered-standard/our-future-chartered-project-professional-assessment/

Un pilot assessment 2026 a été facturé **£693 + VAT**, mais ce tarif pilote ne doit pas être confondu avec les routes standard ci-dessus.

---

# 9. Positionnement face à PMP / IPMA

| Credential | Nature |
|---|---|
| PMI PMP | certification examen + experience |
| IPMA | competence assessment par niveaux D/C/B/A |
| APM ChPP | chartered professional status |
| PRINCE2 | méthode / certification scheme |

Ils peuvent être complémentaires plutôt que concurrents.

Pour un profil senior :

```text
PMP / IPMA
   +
ChPP
```

peut combiner certification de project management et professional chartership.

---

# 10. TCO long terme

Exemple Pathway 1, premier cycle et trois années de registration :

```text
Application + interview  £1 325 HT
3 × annual registration     £297 HT
----------------------------------
≈ £1 622 HT
```

hors CPD, membership APM facultative/complémentaire, préparation, retake et fiscalité selon pays.
