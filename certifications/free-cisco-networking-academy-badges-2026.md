> Revue : **28 août 2026**. Cisco Networking Academy et Skills for All proposent des cours gratuits pouvant délivrer des **digital badges Cisco** après réussite d'un comprehensive exam. Ces badges sont des student-level credentials, pas des certifications CCNA/CCST.

# 8. CCNA: Introduction to Networks badge

Cisco délivre aussi un badge de cours **CCNA: Introduction to Networks** après :

- passing grade du cours ;
- final exam réussi ;
- jusqu'à 54 labs et ~14 h de hands-on.

Compétences :

- Ethernet ;
- IP connectivity ;
- IP services ;
- subnetting ;
- IPv4/IPv6 ;
- switching ;
- security fundamentals.

Source :

- https://www.credly.com/org/cisco/badge/ccna-introduction-to-networks

### Attention

Le badge `CCNA: Introduction to Networks` **n'est pas la certification Cisco CCNA**. Le véritable examen CCNA reste payant.

---

# Certifications Cisco payantes à ne pas confondre

## CCST

Cisco offre gratuitement le self-paced training pour :

- Junior Cybersecurity Analyst ;
- Network Technician.

Mais la **certification CCST** nécessite le passage de l'examen Certiport/Cisco distinct.

## CCNA

Les cours/badges NetAcad peuvent être gratuits ou fournis par une Academy, mais l'examen Cisco CCNA reste un examen de certification payant.

# Shortlist Cisco gratuite

```text
0 $ Networking Basics
0 $ Network Addressing & Basic Troubleshooting
0 $ Network Support & Security
0 $ Junior Cybersecurity Analyst Career Path
0 $ Networking Essentials
0 $ IT Essentials
0 $ Network Security
0 $ CCNA Introduction to Networks course badge
```

Pour un profil infrastructure, le meilleur enchaînement gratuit est :

```text
Networking Basics
→ Network Addressing & Troubleshooting
→ Network Support & Security
→ Network Security
→ Junior Cybersecurity Analyst
```

Ce parcours fournit plusieurs badges Cisco évalués avant même de payer un CCST/CCNA.
