# AI governance, risk, audit & safety

> Credentials professionnels autour de la gouvernance de l'IA, AI risk, audit, responsible AI, sécurité et conformité.
>
> **Vérification : 28 août 2026**

---

| Credential | Prix | Type / contrainte |
|---|---:|---|
| ISACA AAIA | **459 $ membre / 599 $ non-membre + 50 $ application** | credential senior préalable requis |
| ISACA AAIR | **459 $ / 599 $ + application** | credential risk préalable / critères |

# 1. ISACA — AAIA

## Advanced in AI Audit

AAIA est un credential avancé destiné aux auditeurs / advisors déjà qualifiés.

Prix examen :

- membre : **459 $** ;
- non-membre : **599 $** ;
- application après réussite : **50 $**.

## Prérequis

Le candidat doit détenir :

- **CISA** ; ou
- une designation admise comme CIA / US CPA / ACCA/FCCA / certains CPA avec rôle IT audit/advisory selon règles ISACA.

Le coût réel depuis zéro peut donc être bien supérieur au simple voucher AAIA.

Source :

- https://www.isaca.org/credentialing/aaia

**Valeur : ⭐⭐⭐⭐⭐** pour AI audit / assurance.

---

# 2. ISACA — AAIR

## Advanced in AI Risk

Credential avancé orienté risk management de l'IA.

Tarif exam :

- membre : **459 $** ;
- non-membre : **599 $**.

Le modèle ISACA suit également une application/certification après réussite et exige des qualifications / expérience admissibles selon le track.

Source :

- https://www.isaca.org/credentialing/aair

---

# 3. GARP — Risk and AI Certificate

Le **RAI Certificate** est plus accessible côté prérequis : aucun work experience spécifique n'est obligatoire pour s'inscrire.

## Prix octobre 2026

- détenteur FRM / SCR / ERP : **625 $** ;
- Individual Member : **650 $** ;
- non-member : **750 $** ;
- taxes VAT/GST en plus.

Les early rates 2027 commencent à **525 $** pour certains holders.

## Inclus

- curriculum complet GARP Learning ;
- practice exam ;
- exam ;
- émission du certificate ;
- six mois de complimentary membership pour certains nouveaux candidats.

## Examen

- 80 questions ;
- 4 heures ;
- AI/ML tools & techniques ;
- risk factors ;
- responsible AI ;
- data/model governance ;
- regulation / governance frameworks.

Retake : **350 $** au cycle suivant sous conditions.

Sources :

- https://www.garp.org/rai
- https://www.garp.org/rai/fees-payments
- https://www.garp.org/rai/program-exam

**Valeur : ⭐⭐⭐⭐⭐** pour AI risk / governance transverse.

# 4. IAPP — AIGP

## Artificial Intelligence Governance Professional

Prix exam 2026 :

- membre : **649 $** ;
- non-membre : **799 $**.

Le non-member exam actuel inclut la première certification maintenance fee ; ensuite le CMF est **250 $** lors de la recertification pour les non-membres.

## Cycle

- certification term : **2 ans** ;
- **20 continuing education credits** ;
- CMF ou membership IAPP.

Exam :

- 100 questions ;
- 2 h 45 + break ;
- Pearson VUE / OnVUE.

Source :

- https://store.iapp.org/aigp-exam/

**Valeur : ⭐⭐⭐⭐⭐** pour AI governance / regulation / responsible AI.

---

# 5. CSA + Northeastern — TAISE

## Trusted AI Safety Expert

Bundle unique : **795 $**.

Inclut :

- 10 self-paced modules ;
- study guide ;
- final exam ;
- **2 attempts**, valables 2 ans ;
- certificate + digital badge.

Exam :

- 60 QCM ;
- 120 minutes ;
- 80 % requis ;
- online open-book / unproctored selon documentation CSA.

Domaines :

- GenAI architecture ;
- ethics / explainability ;
- model lifecycle ;
- governance ;
- risk ;
- privacy ;
- cloud & AI security ;
- NIST AI RMF ;
- ISO ;
- MITRE ATLAS ;
- CSA AI Controls Matrix.

Sources :

- https://cloudsecurityalliance.org/education/taise
- https://exams.cloudsecurityalliance.org/en/tokens/select

**Valeur : ⭐⭐⭐⭐–⭐⭐⭐⭐⭐** pour AI safety/security, avec une nature de certificate différente d'un examen proctoré ISACA/IAPP.

# 6. ISO/IEC 42001

La norme ISO/IEC 42001 forme une autre famille de credentials :

- Foundation ;
- Lead Implementer ;
- Lead Auditor ;
- certification de personne / auditor grade selon organisme.

Le dépôt contient déjà plusieurs exemples :

- AFNOR certification de compétences ;
- BSI training/auditor tracks ;
- PECB certification model.

Voir :

- `iso-grc-europe-over-500.md`
- `privacy-dpo-france.md`

Ces credentials attestent davantage la capacité à **mettre en œuvre ou auditer un AI Management System** que la maîtrise générale du risque IA.

# 7. Matrice de choix

| Besoin | Credential |
|---|---|
| AI governance / regulation | IAPP AIGP |
| AI risk | GARP RAI / ISACA AAIR |
| Audit IA | ISACA AAIA |
| AI safety + security + governance | CSA TAISE |
| Management system ISO | ISO/IEC 42001 Lead Implementer/Auditor |
| Privacy + IA | AIGP + CIPP/E/CIPM |
| Audit IT + IA | CISA + AAIA |

---

# 8. Coût depuis zéro

Les tarifs bruts sont trompeurs pour les credentials avancés ISACA.

Exemple :

```text
CISA / qualified designation
       ↓
AAIA exam 459–599 $
       ↓
application
       ↓
maintenance
```

Alors que GARP RAI ou CSA TAISE n'imposent pas une certification senior préalable.
