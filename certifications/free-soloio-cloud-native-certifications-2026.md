# Solo.io Academy — certifications cloud-native gratuites — 2026

> Revue : **28 août 2026**. Solo.io Academy propose plusieurs certifications gratuites autour des briques open source cloud-native : Istio, Ambient Mesh, Cilium, Envoy et eBPF.

---

# Modèle de certification

Solo.io décrit le parcours type :

1. inscription gratuite à l'Academy / workshop ;
2. contenu introductif ;
3. **lab hands-on** dans Instruqt ;
4. examen / assessment ;
5. **80 % minimum** ;
6. certification Credly.

Plusieurs parcours sont disponibles **on-demand**, d'autres uniquement en live workshop.

Source générale : https://www.solo.io/blog/service-mesh-certifications

# Parcours recommandé gratuit

Pour un profil Kubernetes / platform engineering :

```text
Fundamentals for Envoy
→ Fundamentals for Cilium
→ Fundamentals for Istio
→ Intermediate for Istio
→ Istio Ambient Mesh Fundamentals
→ Istio Ambient Mesh Intermediate
```

Pour du réseau cloud-native plus bas niveau :

```text
Cilium
→ eBPF Fundamentals
→ eBPF Intermediate
```

Ce programme est particulièrement intéressant car les certifications reposent sur **des labs pratiques**, et pas uniquement sur des vidéos ou un QCM théorique.
