# Certifications et credentials gratuits — hors IT

> Sélection de certifications, tests et credentials accessibles gratuitement, avec un focus sur la valeur CV / LinkedIn.
>
> **Dernière vérification : 28 août 2026**

## Règle de sélection

Cette liste distingue :

- les **certifications avec évaluation** ;
- les **tests standardisés** avec résultat vérifiable ;
- les **digital badges** délivrés par une institution reconnue ;
- les **certificats de formation** utiles mais moins forts qu'une certification professionnelle.

L'objectif n'est pas de collectionner des badges, mais de compléter un profil technique avec des compétences en **anglais, management, leadership, gestion de projet, risque, business et communication**.

# 1. Anglais — EF SET 4 Skills

Le **EF SET 4 Skills** est probablement le credential gratuit non-technique le plus rentable.

Le test dure environ **90 minutes** et évalue les quatre compétences :

- Reading ;
- Listening ;
- Speaking ;
- Writing.

Le résultat est positionné sur l'échelle **CECR A1 à C2** et donne accès à un certificat EF SET partageable.

## Pourquoi le passer

Contrairement à une simple attestation de cours, il fournit une mesure standardisée du niveau d'anglais. Il ne remplace pas forcément un TOEIC, TOEFL ou IELTS lorsqu'un organisme exige explicitement l'un de ces tests, mais il permet de documenter gratuitement son niveau professionnel.

**Priorité : ⭐⭐⭐⭐⭐**

Ressource officielle :

- https://www.efset.org/4-skill/

# 3. IBM SkillsBuild — Project Management Fundamentals

IBM SkillsBuild propose un parcours **Project Management Fundamentals** avec credential numérique.

Le contenu couvre notamment :

- bases de la gestion de projet ;
- planification ;
- suivi ;
- budget ;
- livrables ;
- risques ;
- changements ;
- relations avec les parties prenantes.

Le module Project Management Fundamentals est annoncé à environ **3,5 heures**.

**Priorité : ⭐⭐⭐⭐**

Ressource :

- https://skillsbuild.org/adult-learners/explore-learning/project-manager

# 4. Open University — Leadership and Followership

Cours gratuit avec **digital badge Open University**.

Durée indicative : environ **24 heures**, réparties sur huit semaines dans la proposition pédagogique, mais réalisables à son rythme.

Le badge nécessite notamment de réussir les deux évaluations principales avec **50 % ou plus**.

Le programme porte sur :

- styles de leadership ;
- rôle du leader ;
- rôle du follower ;
- contexte de leadership ;
- développement personnel ;
- difficultés et comportements de leadership.

**Priorité : ⭐⭐⭐⭐**

Ressources :

- https://www.open.edu/openlearn/education-development/learning/leadership-and-followership
- https://www.open.edu/openlearn/mod/oucontent/view.php?id=147525&section=_unit1.1.2

> Ce badge n'est pas un diplôme universitaire et ne doit pas être présenté comme tel.

Éviter de mélanger certifications proctorées, tests standardisés et simples certificats de cours dans une seule longue liste.

Exemple :

