# 1. Anglais — EF SET

## EF SET 4 Skills

Test gratuit couvrant :

- Reading ;
- Listening ;
- Speaking ;
- Writing.

Résultat positionné sur le **CECR A1 à C2**, avec certificat partageable et vérifiable.

Pour documenter gratuitement son niveau professionnel avant éventuellement de passer TOEIC / Cambridge / IELTS, c'est un excellent point de départ.

**Priorité : ⭐⭐⭐⭐⭐**

Source : https://www.efset.org/

# 2. RGPD / Privacy — CNIL

## L'Atelier RGPD

MOOC officiel et gratuit de la **Commission nationale de l'informatique et des libertés**.

Environ vingt heures d'auto-formation autour de :

- notions clés du RGPD ;
- principes de protection des données ;
- responsabilités des acteurs ;
- DPO et outils de conformité ;
- collectivités territoriales ;
- travail et données personnelles.

Chaque module comprend un quiz permettant d'obtenir une **attestation de suivi**.

Ce n'est pas une certification IAPP ou ISO, mais le nom CNIL lui donne une excellente légitimité pour un credential gratuit en France.

**Priorité : ⭐⭐⭐⭐**

Source : https://www.cnil.fr/fr/comprendre-le-rgpd/le-mooc-de-la-cnil

# Parcours « management / direction » à 0 €

Ordre recommandé :

1. **EF SET 4 Skills** — documenter l'anglais ;
2. **CNIL Atelier RGPD** — privacy / conformité ;
3. **CSSC Six Sigma White Belt** — amélioration continue ;
4. **IBM Project Management Fundamentals** — projet ;
5. **Open University Risk Management** — risque ;
6. **Open University Leadership & Followership** — leadership ;
7. **HubSpot Revenue Operations** — processus / organisation / KPI ;
8. **HubSpot Digital Marketing ou Inbound** — culture business ;
9. **Google Ads Certification** si exposition marketing / acquisition ;
10. **HP LIFE Effective Presentations** — communication.

L'objectif n'est pas de tout afficher sur le CV. Le dépôt sert à identifier ce qui peut être obtenu gratuitement, puis à sélectionner les credentials cohérents avec le poste ciblé.
