# 1. Aviatrix ACE Associate — vraie certification gratuite

Aviatrix a supprimé le coût et le proctoring de l'examen final **ACE Associate** depuis le 6 mars 2024.

Parcours :

1. s'inscrire à ACE Academy ;
2. utiliser le code `acemulticloud` lorsque demandé pour rendre le training Associate gratuit ;
3. terminer les modules self-paced ;
4. lancer le final certification exam directement dans la plateforme ;
5. réussir avec au moins **70 %**.

```text
Training               0 $
Final exam              0 $
Durée examen          ~60 min
Score minimum           70 %
Retakes gratuits         2
Badge                  Credly
```

Aviatrix confirme que les deux tentatives supplémentaires sont sans coût.

### Valeur

⭐⭐⭐⭐⭐ pour multicloud networking / cloud networking / cloud security.

Sources :

- https://community.aviatrix.com/ace-certification-forum-2/how-to-take-the-ace-associate-final-exam-365
- https://community.aviatrix.com/ace-certification-forum-2/exciting-update-ace-associate-course-no-longer-requires-proctored-and-paid-final-exam-1545

# 2. RIPE NCC Academy Summer School 2026 — vrais examens proctored gratuits jusqu'au 31 août

## Offre urgente

Du **1er juillet au 31 août 2026**, tout apprenant qui termine un cours e-learning RIPE NCC Academy ayant un examen associé reçoit un **voucher de certification gratuit**.

Conditions :

1. choisir un cours RIPE NCC Academy ayant un exam associé ;
2. terminer le cours ;
3. recevoir le voucher par e-mail ;
4. utiliser le voucher ;
5. **passer et réussir l'examen avant le 31 août 2026**.

L'Academy est ouverte aux **membres et non-membres**.

### Examens actuels intéressants

- **IPv6 Fundamentals — Analyst** ;
- **RIPE Database — Associate** ;
- **BGP Security — Associate** ;
- **IPv6 Security — Expert** ;
- LIR Fundamentals selon disponibilité du parcours associé.

Les examens sont de vrais examens RIPE NCC :

- online ;
- proctored / secure browser review ;
- badge numérique vérifiable ;
- niveaux Analyst / Associate / Expert.

Exemple IPv6 Fundamentals :

```text
Durée           60 min
Questions       50
Passing score   70 %
Niveau          Analyst
```

### Après la promo

RIPE NCC n'est pas normalement gratuit pour tous :

- membres RIPE NCC : vouchers inclus selon règles membership ;
- autres candidats : voucher requis.

### Valeur

⭐⭐⭐⭐⭐ pour networking / ISP / BGP / IPv6.

Sources :

- https://www.ripe.net/about-us/news/ripe-ncc-academy-launches-summer-school-2026/
- https://academy.ripe.net/mod/page/view.php?id=940
- https://getcertified.ripe.net/
- https://academy.ripe.net/mod/page/view.php?id=941

OpenSSF propose plusieurs formations gratuites via Linux Foundation Education avec badges/certificates de completion.

```text
Prix                       0 $

Quiz / final exam           oui

Digital badge              oui

```

Le cours couvre notamment :

- supply-chain security ;


# 7. À ne pas classer comme certification gratuite

## CertiProf Open Exams

CertiProf permet d'accéder gratuitement à plusieurs study materials et **official exams**, mais la page 2026 précise que le **certificate et digital badge sont disponibles contre paiement**.

Donc :

```text
exam          gratuit
certification payante
```

Ne pas les ajouter à une liste de certifications 100 % gratuites.

Source : https://open.certiprof.com/

## Cisco Certificate in Ethical Hacking

Le cours Cisco Networking Academy Ethical Hacker est gratuit, mais l'obtention du **Cisco Certificate in Ethical Hacking** exige aussi la réussite d'au moins un Cisco U Capture The Flag challenge ; Cisco a publié ces challenges comme payants.

Donc le programme complet n'est pas gratuit permanent.

Sources :

- https://www.cisco.com/site/us/en/learn/training-certifications/certifications/ethical-hacker/program.html
- https://blogs.cisco.com/learning/about-cisco-u-capture-the-flag-challenges
