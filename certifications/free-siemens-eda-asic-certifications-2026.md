# Siemens EDA / ASIC / verification — certifications gratuites — 2026

> Revue : **28 août 2026**. Siemens Software / Xcelerator Academy publie une large bibliothèque de badges classés par Credly comme **Type: Certification / Cost: Free**, obtenus par de vrais examens techniques.

Cette grappe est particulièrement intéressante pour :

- ASIC / SoC ;
- RTL verification ;
- SystemVerilog / UVM ;
- low-power design ;
- physical verification ;
- Calibre DRC/LVS/PERC ;
- PCB / Xpedition ;
- Questa / ModelSim.

---

# Modèle d'accès

Les pages Siemens/Credly actuelles indiquent généralement :

```text
Type                 Certification
Cost                 Free
Compte requis        Siemens Support Center
Passing score        80 %
Exam duration        45 à 90 min selon credential
Questions            25 ou 50 selon credential
Badge                Siemens Verified Digital Badge / Credly
```

Lorsque le candidat ne possède pas de subscription Badging Library, Siemens indique d'utiliser le code :

```text
Certnow
```

pour souscrire gratuitement à la bibliothèque de badges et accéder aux examens concernés.

> Le **training ILT complet** Siemens peut être payant. Cette fiche concerne les **certification exams / verified badges gratuits**, pas les cours live premium.
