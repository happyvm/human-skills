# 3. Wolfram U — certifications intégrées à certains cours gratuits

Wolfram U propose des cours interactifs gratuits avec :

- video lessons ;
- exercises/problems ;
- quizzes ;
- final exams ;
- completion certificates ;
- parfois une **Level 1 Certification**.

Attention : **toutes les certifications Wolfram ne sont pas gratuites**. Certaines Level 1/Level 2 séparées demandent un certification fee. Ne classer gratuites que les certifications explicitement incluses dans un cours interactif gratuit.

---

## An Elementary Introduction to Wolfram Language

Page actuelle :

```text
Interactive course     Free
Duration               ~7 h
Completion Certificate oui
Level 1 Certification  oui
```

Pour la Level 1 intégrée :

- passer les auto-graded quizzes ;
- compléter les course exercises ;
- certification de proficiency en Wolfram Language.

Compétences :

- Wolfram Language programming ;
- computational thinking ;
- real-world data ;
- visualization ;
- AI/ML methods ;
- Wolfram Cloud deployment.

Source :

- https://www.wolfram.com/wolfram-u/courses/wolfram-language/an-elementary-introduction-to-the-wolfram-language/

### Valeur

⭐⭐⭐⭐ pour computational programming/data.

---
