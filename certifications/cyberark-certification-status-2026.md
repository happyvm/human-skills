# CyberArk certification status & pricing visibility — 2026

> Revue : **28 août 2026**. Objectif : corriger l'utilisation fréquente d'un ancien tarif « ~200 $ » qui n'est plus suffisamment vérifiable publiquement en 2026.

---

# Conclusion rapide

CyberArk maintient bien ses certifications techniques **Defender, Sentry et Guardian**, mais :

- le **prix 2026 de chaque examen n'est pas exposé publiquement** sur la page Pearson VUE consultable sans compte ;
- le tarif final doit donc être vérifié pendant le parcours de réservation ;
- depuis le **1er novembre 2025**, les examens CyberArk sont **exclusivement en présentiel** en centre de test Pearson VUE ;
- les study guides / sample items publics sont gratuits.

### Classification correcte

```text
Defender / Sentry exam price   checkout / non public
Old ~200 $ references          ne pas utiliser comme prix 2026 confirmé
Study guides                   gratuit
Delivery                       test center only
```

---

# 1. Certifications actuelles

Pearson VUE expose les niveaux suivants.

## Defender

Valide l'exploitation quotidienne et le support des solutions CyberArk.

Examens listés :

- CyberArk Defender Access / IAM — ACC-DEF ;
- CyberArk Defender EPM — EPM-DEF ;
- CyberArk Defender PAM — PAM-DEF.

## Sentry

Valide le déploiement, l'installation et la configuration.

Examens listés :

- CyberArk Sentry PAM — PAM-SEN ;
- CyberArk Sentry CyberArk Privilege Cloud — CPC-SEN ;
- CyberArk Sentry Secrets Manager — SECRET-SEN.

## Guardian

Niveau avancé architecture / stratégie PAM :

- CyberArk Guardian — GUARD.

Source :

- https://www.pearsonvue.com/us/en/cyberark.html

---

# 2. Plus d'OnVUE depuis novembre 2025

Pearson VUE confirme qu'à partir du **1er novembre 2025**, CyberArk a supprimé le proctoring OnVUE à distance pour tous ses examens de certification.

Les examens sont désormais administrés **uniquement en présentiel** dans un centre de test.

### Impact France

Le TCO réel comprend donc potentiellement :

- examen ;
- transport vers centre Pearson VUE ;
- éventuels frais annexes.

Source :

- https://www.pearsonvue.com/us/en/cyberark.html

---

# 3. Prix 2026 : non public

La page publique Pearson VUE CyberArk présente les examens, les règles de test et les liens de réservation, mais **aucune grille de prix** n'y est affichée.

Le portail CyberArk University public expose également les contenus de préparation mais ne fournit pas de tableau clair « Defender = X $, Sentry = Y $ ».

### Conséquence

Les anciennes références web autour de **200 $** ne doivent pas être converties en prix officiel 2026 sans vérification au checkout.

Dans human-skills, CyberArk doit donc être classé :

```text
Prix public confirmé    inconnu
Possiblement <500       oui historiquement, mais non vérifié
Classification          checkout-required
```

---

# 4. Préparation gratuite

Le catalogue public CyberArk University propose gratuitement plusieurs contenus :

- Sentry - Modern PAM Study Guide ;
- Sentry - Secrets Manager - Sample Items & Study Guide ;
- Sentry - PAM Sample Items & Study Guide ;
- Defender - IAM Sample Items & Study Guide ;
- Defender - EPM Sample Items & Study Guide ;
- Defender - PAM Sample Items & Study Guide.

Il est donc possible de préparer au moins une partie des examens avec des ressources officielles gratuites, même si certaines formations CyberArk avancées peuvent être très coûteuses.

Source :

- https://training.cyberark.com/learn/public/catalog/view/1

---

# 5. Retake policy

Pearson VUE publie la règle CyberArk suivante :

```text
échec tentative 1  → attendre 5 jours
échec tentative 2  → attendre au moins 30 jours
maximum            → 3 tentatives sur 12 mois
```

Chaque nouvelle tentative peut entraîner de nouveaux frais selon le checkout applicable.

Source :

- https://www.pearsonvue.com/us/en/cyberark.html

---

# 6. Guardian : coût de préparation potentiellement très élevé

CyberArk University affiche un **Guardian Workshop** à **4 000 $** dans son catalogue public.

Cela ne signifie pas que le workshop est nécessairement le seul chemin possible vers l'examen Guardian, mais cela illustre pourquoi il faut distinguer :

```text
exam_fee
optional_training
mandatory_training
first-cycle TCO
```

Source :

- https://training.cyberark.com/learn/public/catalog/view/1

---

# 7. Verdict

CyberArk reste un credential PAM/IAM fort, mais il faut désormais le présenter correctement :

```text
Defender     credential live     prix checkout
Sentry       credential live     prix checkout
Guardian     credential live     prix checkout
Study guides                     gratuits
Remote exam                      non
```

Avant achat en France : ouvrir le parcours Pearson VUE, choisir l'examen et le centre, puis relever le **prix local réel TTC** avant de l'intégrer à une roadmap budgétaire.
