# Business continuity, resilience & crisis management

> Certifications et qualifications en continuité d'activité, résilience et reprise. Vérifié fin août 2026.

---

# 1. Business Continuity Institute — CBCI

Le **CBCI** est le credential d'entrée / référence du Business Continuity Institute basé sur les Good Practice Guidelines.

**Auto-formation officielle et gratuite (partielle) :** [thebci.org — GPG Lite Edition](https://www.thebci.org/certification-training/good-practice-guidelines.html) — version condensée gratuite pour débuter ; version complète gratuite pour les membres BCI.

## CBCI Self-Study Bundle

Tarif public observé : **1 280 £**.

Le bundle comprend notamment :

- Introduction to Business Continuity eLearning ;
- Good Practice Guidelines ;
- mock exam ;
- examen CBCI online ;
- **1 an de Student Membership** ;
- fenêtre d'accès / préparation d'environ 60 jours selon bundle.

Sources :

- https://www.thebci.org/training-qualifications/cbci-certification.html
- https://shop.thebci.org/

### TCO

Le coût initial est donc déjà nettement >500 €, même sans formation instructor-led.

Le maintien après la période étudiante doit être évalué via le membership BCI approprié.

# 2. DRI International — examen seul

DRI permet de passer son **Qualifying Examination** sans acheter obligatoirement le cours complet.

**Auto-formation officielle et gratuite (partielle) :** [drii.org — webinars](https://drii.org/trainings) et [International Glossary for Resiliency](https://drii.org/) téléchargeable gratuitement ; bourse WBCM pour une formation + examen offerts.

## Qualifying Exam

- durée : **3,5 heures** ;
- 148 questions ;
- score de réussite : 75 % ;
- prix : **500 $** ;
- retake : **500 $**.

La formation DRI est recommandée mais **non obligatoire** pour cet examen général.

Source :

- https://drii.org/education/Q-Exam

---

# 3. DRI ABCP

## Associate Business Continuity Professional

Le parcours nécessite :

1. réussite du Qualifying Exam ;
2. application ABCP.

Aucune expérience professionnelle n'est exigée.

Tarifs de certification DRI publiés :

- application : **200 $** ;
- annual renewal : **200 $**.

### Premier cycle minimal

```text
Exam           500 $
Application    200 $
-------------------
Obtention      700 $
```

Puis 200 $/an de renewal.

Source :

- https://drii.org/public/docs/Certification_FLY_0525.pdf

---

# 4. DRI CBCP

## Certified Business Continuity Professional

Prérequis :

- qualifying exam réussi ;
- **2 ans d'expérience** ;
- expérience démontrée sur 5 Professional Practice subject areas ;
- au moins 2 core areas ;
- références professionnelles.

Tarifs :

- application : **400 $** ;
- annual renewal : **225 $**.

### Premier cycle minimal sans cours

```text
Qualifying exam    500 $
Application        400 $
-----------------------
Obtention          900 $
```

Puis :

```text
225 $ / an renewal
```

hors coût éventuel des CEAPs nécessaires.

Source :

- https://drii.org/public/docs/Certification_FLY_0525.pdf

---

# 5. DRI CFCP

## Certified Functional Continuity Professional

Même logique générale :

- qualifying exam ;
- **2 ans d'expérience** ;
- expertise fonctionnelle ;
- application **400 $** ;
- renewal **225 $/an**.

Source :

- https://drii.org/public/docs/Certification_FLY_0525.pdf

# 6. DRI course bundle

Le cours principal **Business Continuity — BCLE 2000** est affiché à :

**2 850 $**

pour quatre jours.

Le prix inclut :

- cours ;
- Qualifying Exam.

L'application au credential ABCP/CBCP/CFCP reste une étape supplémentaire.

Source :

- https://drii.org/education/BCLE-2000

### Exemple CBCP avec formation

```text
BCLE 2000 + exam     2 850 $
CBCP application       400 $
----------------------------
Initial              3 250 $
```

puis 225 $/an de renewal.

# 7. DRI Cyber Resilience

DRI propose aussi un examen Cyber Resilience :

- examen séparé : **750 $** ;
- formation CRLE 2000 recommandée mais pas nécessairement obligatoire selon marché ;
- dans certains pays, l'examen n'est disponible qu'avec la formation.

Source :

- https://drii.org/coexam/exam/speciality

# Lecture professionnelle

## CBCI

Très identifiable dans l'écosystème business continuity international et basé sur les Good Practice Guidelines BCI.

## CBCP

Credential DRI senior avec expérience vérifiée et maintien annuel.

## ABCP

Bonne porte d'entrée lorsque l'expérience CBCP n'est pas encore disponible.
