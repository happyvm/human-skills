# Free SAP Learning badges & accreditations — 2026

> Revue : **28 août 2026**. SAP Learning propose désormais plusieurs couches de credentials gratuites : **Records of Achievement**, **Knowledge Badges**, course-completion badges, et certaines accreditations produit gratuites sous S-user. À distinguer des certifications SAP proctored payantes.

---

# Modèle SAP Learning

SAP décrit quatre types de badges :

1. **Course completion badge** — questions d'engagement ;
2. **Knowledge Badge** — standalone assessment validant la connaissance d'une Learning Journey ;
3. **Record of Achievement** — réussite de tous les quizzes d'une Learning Journey ;
4. **SAP Certification badge** — examen SAP proctored.

Les trois premiers peuvent être obtenus gratuitement sur les parcours publics concernés. Le quatrième correspond au programme SAP Certification payant.

Source :

- https://learning.sap.com/helpcenter/digital-badges

# 7. Knowledge Badges — nouveau modèle 2025/2026

SAP remplace progressivement les anciens Records of Achievement par des **Knowledge Badges**.

Le Knowledge Badge est :

```text
Standalone assessment    oui
Valide une Learning Journey
Badge                     SAP badge engine
```

Ce modèle est plus fort qu'un simple completion badge car il repose explicitement sur un assessment.

Source :

- https://learning.sap.com/helpcenter/digital-badges

### Règle de collecte

Lorsqu'un Learning Journey affiche un Knowledge Badge :

1. vérifier que le contenu est public sur `learning.sap.com` ;
2. lancer le standalone assessment ;
3. réussir l'assessment ;
4. récupérer le badge depuis `My Learning Activity`.

# Ce qui reste payant

Les **SAP Certifications** professionnelles proctored ne doivent pas être confondues avec les badges ci-dessus.

```text
SAP Record of Achievement   souvent 0 $
SAP Knowledge Badge         souvent 0 $
Course Completion Badge     0 $ sur parcours public
SFX Accreditation           0 $ sous S-user
SAP Certification Exam      payant / exam attempts
```

Les assessments de **Stay Certified** nécessitent par ailleurs un SAP Learning Hub subscription pour les certifications concernées.

Source :

- https://learning.sap.com/helpcenter/certification-support/how-to-stay-certified
