# HackersGen / SORINT.lab — credentials IT gratuits — 2026

> Revue : **28 août 2026**. HackersGen est une plateforme éducative italienne portée par la Fondazione Gianfranco Marilli / SORINT.lab. Ses conditions 2026 indiquent que l'accès aux parcours est **totalement gratuit pour étudiants, enseignants et passionnés**.

Les Focus/Pit Stop et parcours techniques peuvent délivrer :

- certificat PDF ;
- badge numérique Credly validé par SORINT.lab ;
- après réussite d'un test final.

Sources générales :

- https://www.hackersgen.com/
- https://www.hackersgen.com/termini-e-condizioni
- https://www.hackersgen.com/cosa-facciamo

---

# Modèle

```text
Accès plateforme      0 $
Cours                  0 $
Test final             inclus
Certificate PDF        oui
Badge Credly           oui selon parcours
Langue principale      italien
```

> Credly classe plusieurs de ces credentials comme `Type: Certification / Cost: Free`, mais il s'agit avant tout de **certifications de parcours techniques évalués**, pas de certifications vendor high-stakes type CCNA/CKA.

# 3. Introduction to DevOps

Credly classe ce credential :

```text
Type     Certification
Level    Foundational
Cost     Free
```

Le cours dure environ 6 heures et comprend théorie + labs menant au déploiement d'une application.

Compétences :

- DevOps ;
- Docker ;
- Kubernetes ;
- Jenkins ;
- CI/CD ;
- Google Cloud ;
- release d'une application front + back.

Le badge est délivré aux participants qui réussissent le test final.

Source : https://www.credly.com/org/sorint-lab-s-p-a/badge/hackersgen-course-introduction-to-devops

### Valeur

⭐⭐⭐⭐ pour DevOps junior / reconversion.
