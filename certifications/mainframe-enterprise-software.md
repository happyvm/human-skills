# SAP Certification

SAP fait évoluer fortement son programme en 2026 vers des examens **performance-based / practical**, avec IA et environnements SAP réels.

Source :

- https://learning.sap.com/helpcenter/certification-support/exam-essentials

## Une tentative

L'offre US `CER001` affiche :

- **230 $ USD hors taxes** ;
- une tentative ;
- 12 mois d'accès au Certification Hub ;
- remote proctored ;
- applicable aux examens disponibles dans le hub.

Source :

- https://training.sap.com/course/cer001-sap-certification-exam-one-attempt-certification-online-010-us-en

## Six tentatives

`CER006` :

- **576 $ USD hors taxes** ;
- six exam bookings sur 12 mois ;
- maximum trois tentatives par examen.

Source :

- https://training.sap.com/course/cer006-sap-certification-exam-six-attempts-certification-online-010-us-en

### Rapport prix

```text
1 attempt       230 $
6 attempts      576 $
```

Pour quelqu'un visant plusieurs certifications SAP, le bundle multi-attempt est nettement plus intéressant.

# Stay Certified / TCO SAP

SAP impose une logique de maintien annuel.

Avec SAP Learning Hub :

- accès aux short assessments de maintien ;
- practice systems ;
- training ;
- plusieurs exam attempts selon abonnement.

Sans Learning Hub, le candidat doit pouvoir repasser un examen de certification pour rester à jour selon le modèle actuel.

SAP Community indique en 2026 un Learning Hub autour de **1 260 € / 1 488 $** selon région/offre, mais le checkout officiel régional doit être utilisé pour figer le TCO.

Source programme :

- https://www.sap.com/training-certification/sap-certification.html
