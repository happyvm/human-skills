# Transition 2026

En mars 2026, Licensing School a annoncé une refonte de ses examens :

- Licensing Scholar reste gratuit ;
- ses assessments demeurent des tests ciblés ;
- le Core évolue d'une certification séparée vers un **preparation track** pour le BOK Foundation certification plus profond.

Source : https://www.licensingschool.co.uk/new-licensing-school-exams-for-2026/

Donc, dans ce dépôt :

```text
Scholar Core        parcours évalué gratuit + badge
BOK Foundation      certification distincte / modèle à vérifier
```

Ne pas présenter Scholar Core comme équivalent d'une certification Microsoft officielle.
