# Low-code / BPM enterprise — Pega & Appian — 2026

OutSystems et Mendix restent à vérifier (Mendix mentionné une seule fois dans `free-it.md`, sans détail payant).

# Pegasystems (Pega)

## Certified Pega System Architect (PCSA)

Format confirmé directement sur la page officielle Pega Academy :

```text
Format          60 questions (scénario, QCM, drag/drop)
Durée           1h30
Score requis    65 %
Livraison       Pearson VUE (centre ou proctoring en ligne)
```

**Prix : ~175 $** — non affiché sur la page officielle (redirection vers l'inscription Pearson VUE), corroboré par plusieurs guides tiers indépendants convergents. À reconfirmer au moment de l'inscription.

## Lead System Architect (LSA) — premier examen du parcours

**Prix : ~190 $** pour le premier examen du chemin de certification LSA (niveau supérieur, plusieurs examens requis pour le titre complet).

Source :

- https://academy.pega.com/exam/certified-pega-system-architect
- https://academy.pega.com/certifications/PCLSA

# Appian

## Appian Certified Associate Developer (ACD101)

```text
Prix            250 $
Format          60 questions, 60 minutes
Score requis    73 %
Prérequis       aucun formel — ~80h de formation et 1-3 mois de pratique
                recommandés (Community Edition gratuite disponible)
Livraison       Meazure Learning (proctoring)
```

Confirmé par plusieurs sources tierces convergentes ; la page officielle academy.appian.com a renvoyé une erreur d'accès direct (403) lors de cette revue.

Un niveau **Senior Developer (ACD200)** existe également dans le parcours, non chiffré lors de cette revue.

Source :

- https://academy.appian.com/page/appian-certifications

---

# Positionnement

Pega et Appian ciblent un profil **développeur/architecte low-code enterprise** (automatisation de processus métier, BPM, souvent secteur bancaire/assurance/gouvernement) — distinct du low-code grand public (Power Platform, déjà documenté dans `public-cloud-multicloud-under-500.md`). Rapport valeur/prix favorable comparé aux certifications ERP/CRM enterprise équivalentes (SAP, NetSuite) déjà documentées ailleurs dans le dépôt.

**Valeur : ⭐⭐⭐⭐** pour un profil BPM/process automation enterprise — Pega et Appian restent des standards dans les grandes organisations réglementées malgré la montée de Power Platform côté PME/ETI.
