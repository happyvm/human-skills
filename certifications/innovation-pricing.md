# 1. PDMA — NPDP

## New Product Development Professional

La Product Development and Management Association propose le credential **NPDP**, centré sur :

- product innovation ;
- strategy ;
- portfolio ;
- new product process ;
- culture / teams ;
- market research ;
- tools / metrics ;
- lifecycle management.

## Frais 2026

### Application

- Premium / Academic / Corporate Members : **0 $** ;
- Student Members : **100 $** ;
- Professional / Basic / Non-Members : **200 $**.

### Examen

Tous candidats : **250 $** chez Prometric.

### TCO exam-only

```text
Premium/Academic/Corporate member  250 $ + membership éventuel
Student                            350 $
Non-member/basic                   450 $
```

Source officielle :

- https://www.pdma.org/general/custom.asp?page=certification-central

## Tentatives

- eligibility : un an après approbation ;
- jusqu'à trois tentatives sur la période ;
- chaque tentative supplémentaire : **250 $** ;
- minimum deux semaines entre attempts.

---

# 2. NPDP renewal

Cycle : **3 ans**.

Exigence : **60 Professional Development Hours** sur trois ans.

Renewal :

- membre PDMA : **150 $** ;
- non-membre : **200 $**.

Source :

- https://www.pdma.org/page/maintain_NPDP_certif

**Valeur : ⭐⭐⭐⭐⭐** pour innovation / new product development au regard du prix.

---

# 3. Professional Pricing Society — CPP

## Certified Pricing Professional

Le CPP est un programme de spécialisation en pricing.

Online Certified Pricing Professional Program :

- membre : **3 995 $** ;
- prix standard : **4 395 $**.

Il couvre un ensemble de cours et la certification finale.

Source :

- https://membership.pricingsociety.com/itemDetail?iProductCode=CPP_BUNDLE

---

# 4. CPP course credits

Des cours individuels du parcours sont typiquement affichés autour de :

- **495 $ membre** ;
- **695 $ standard**.

Exemples :

- Successfully Managing Pricing ;
- Psychological Aspects of Pricing ;
- Quantitative Methods ;
- documenting value ;
- autres modules.

Le programme CPP exige plusieurs course credits : il ne faut donc pas interpréter 495 $ comme le prix total de la certification.

Source :

- https://membership.pricingsociety.com/Portal/iCore/Store/StoreLayouts/Item_Detail.aspx?iProductCode=SUCCESS_PRICING

---

# 5. Fast Track / conference bundles

PPS vend aussi le CPP avec des conférences et workshops.

Exemple profitABLE26 :

- Premium+ membre : environ **5 495 $** ;
- Premium+ non-member : **5 995 $** ;
- Signature+ : environ **5 095–5 595 $**.

Ces bundles mélangent :

- conference ;
- workshops ;
- CPP enrollment ;
- exam.

Ils ne sont donc pas comparables au simple coût exam/application du NPDP.
