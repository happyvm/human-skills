# 1. Datadog

Datadog propose actuellement trois examens :

- Datadog Fundamentals ;
- APM & Distributed Tracing Fundamentals ;
- Log Management Fundamentals.

**Prix : 100 $ par examen.**

- 90 questions ;
- proctoring online ;
- retakes payants ;
- validité : 3 ans.

Source : https://learn.datadoghq.com/pages/certification

**Valeur : ⭐⭐⭐⭐** pour SRE, observabilité, cloud et exploitation.

---

# 2. Confluent / Apache Kafka

Examens actuels :

- Confluent Certified Developer for Apache Kafka ;
- Confluent Certified Administrator for Apache Kafka ;
- Confluent Cloud Certified Operator.

**Prix : 150 $ par certification.**

Source : https://training.confluent.io/learn/public/catalog/view/108

À ce prix, c'est une certification très intéressante pour les profils :

- architecture data ;
- streaming ;
- middleware ;
- event-driven architecture ;
- exploitation Kafka.

**Valeur : ⭐⭐⭐⭐⭐** dans un contexte Kafka.

# 3. dbt Labs

**Prix : 200 $**.

- 65 questions ;
- score requis : 65 % ;
- recommande environ six mois d'expérience dbt / dbt Core.

Source : https://www.getdbt.com/certifications/analytics-engineer-certification-exam

## dbt Cloud Administrator

Les guides actuels affichent également un tarif de **200 $** pour l'examen Cloud Administrator.

**Valeur : ⭐⭐⭐⭐** pour Modern Data Stack / analytics engineering.

# 5. HPE

Grille Pearson VUE officielle pour les pays développés — dont la France :

| Type d'examen | Tarif |
|---|---:|
| HPE3 | **65 $** |
| HPE2 | **140 $** |
| HPE0 / HPE6 | **260 $** |
| HPE7 | **350 $** |

Source : https://www.pearsonvue.com/us/en/hpe.html

Les intitulés de certifications HPE dépendent du parcours : compute, storage, networking, hybrid cloud, Alletra, GreenLake, etc.

Il faut donc additionner les examens si un credential exige plusieurs tests.

**Valeur : ⭐⭐⭐⭐** dans un environnement HPE.

# 7. ServiceNow

Depuis fin 2025, ServiceNow a modifié son système de vouchers et son prestataire d'examen.

Tarifs 2026 communiqués dans la documentation / communauté ServiceNow :

| Certification | Prix |
|---|---:|
| CSA / CAD / CPOA / certifications mainline équivalentes | **300 $ + taxes** |
| CIS | **450 $ + taxes** |

Les cours on-demand peuvent être gratuits, tandis que les formations instructor-led sont beaucoup plus coûteuses.

Les anciennes histoires de « voucher gratuit après le cours » ne doivent donc pas être reprises automatiquement.

Source de référence : ServiceNow University / documentation de transition Pearson VUE.

**Valeur : ⭐⭐⭐⭐⭐** dans un environnement ServiceNow.
