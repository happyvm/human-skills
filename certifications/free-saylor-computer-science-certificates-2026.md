# Free Saylor University computer science certificates — 2026

> Revue : **28 août 2026**. Saylor University propose de nombreux cours Computer Science entièrement gratuits avec **Certificate Final Exam gratuit** et certificat de réussite.

---

# Modèle Saylor

Les syllabi actuels précisent :

```text
Enrollment               0 $
Course materials         0 $
Assessments              0 $
Certificate Final Exam   0 $
Passing score            70 %
Retake waiting period    7 jours
Course certificate       0 $
```

Saylor propose parfois un second examen optionnel `ACE Recommended Credit Final Exam` pour obtenir des crédits transférables ; cette couche n'est pas nécessaire pour recevoir le **Free Certificate** du cours.

Exemple officiel CS260 :

> This course also contains a free final exam which will award you a course completion certificate.

Source :

- https://learn.saylor.org/mod/page/view.php?id=73818

# Positionnement

Ce sont des **university course completion certificates** avec final exam, et non des certifications industrielles proctorées type RHCSA/CKA/AWS.

Mais la combinaison :

```text
0 $ + cours long + assessments + final exam 70 % + certificat vérifiable
```

leur donne un bien meilleur signal académique qu'une simple attestation de vidéo.
