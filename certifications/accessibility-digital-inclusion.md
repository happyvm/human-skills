# 1. IAAP — CPACC

## Certified Professional in Accessibility Core Competencies

Credential généraliste de l'International Association of Accessibility Professionals.

Prix examen :

- standard : **510 $** ;
- IAAP member : **410 $** ;
- Emerging / Developing Economy : **170 $**.

Compétences :

- disabilities ;
- universal design ;
- assistive technologies ;
- standards / legislation ;
- accessibility management ;
- principes d'inclusion.

Source officielle :

- https://www.accessibilityassociation.org/cpacc

**Valeur : ⭐⭐⭐⭐⭐** pour accessibility lead, governance, product, UX et conformité.

---

# 2. IAAP — WAS

## Web Accessibility Specialist

Credential plus technique.

Prix examen :

- standard : **555 $** ;
- member : **455 $** ;
- Emerging / Developing Economy : **225 $**.

Le tarif membre représente une remise de 100 $ par rapport au tarif standard.

Compétences typiques :

- WCAG ;
- HTML / CSS / JavaScript accessible ;
- ARIA ;
- testing ;
- assistive technologies ;
- remediation ;
- accessibility engineering.

Retake WAS observé dans la grille officielle :

- standard : **330 $** ;
- membre : **270 $** ;
- EDE : **110 $**.

Sources :

- https://www.accessibilityassociation.org/was-exam
- https://www.accessibilityassociation.org/discounts-and-payment-options

**Valeur : ⭐⭐⭐⭐⭐** pour web accessibility / engineering.

# 3. CPWA — Certified Professional in Web Accessibility

Le CPWA est une désignation avancée associée aux compétences généralistes et techniques IAAP.

Dans la pratique, le parcours naturel combine :

```text
CPACC
  +
WAS
  ↓
CPWA / advanced web accessibility profile
```

Au tarif standard des deux examens :

```text
510 + 555 = 1 065 $
```

avant membership, retakes ou préparation.

Ne pas présenter ce montant comme un bundle officiel : il s'agit de la somme indicative des deux examens actuels.

# 4. DHS Trusted Tester — Section 508

Le gouvernement fédéral américain maintient le programme **DHS Trusted Tester** pour standardiser les tests de conformité Section 508.

Le portail Section508.gov décrit :

- self-enrollment ;
- cursus formel ;
- méthodologie standardisée ;
- certification après formation et assessment ;
- version actuelle Trusted Tester **5.1.3** lors de la revue 2026.

La documentation de formation exige un score de réussite de **85 %** pour l'examen concerné.

Le portail officiel ne publie pas de tarif public explicite sur les pages consultées. Des sources externes 2026 décrivent le programme comme gratuit, mais le dépôt le classe prudemment comme :

**🟡 self-enrollment / aucun fee public affiché — vérifier le portail avant inscription.**

Sources officielles :

- https://www.section508.gov/test/trusted-tester/
- https://www.section508.gov/training/

# 5. IAAP — ADS

## Accessible Document Specialist

Credential IAAP spécialisé **documents** (Word, PDF, PowerPoint, Excel, desktop publishing), distinct de CPACC (généraliste) et WAS (web).

Exige **1 à 2 ans d'expérience pratique** en création, remédiation, audit et test de documents accessibles ; la seule connaissance d'outils de vérification automatique ne suffit pas.

Prix examen :

- membre IAAP : **465 $** ;
- non-membre : **545 $** ;
- membre + adhésion incluse (145 $/an) : **≈ 610 $** la première année.

Source officielle :

- https://www.accessibilityassociation.org/ads-exam

**Statut prix : 🟡 partiellement confirmé.** La page officielle IAAP est rendue en JavaScript et n'a pas pu être vérifiée directement par ce dépôt ; les montants ci-dessus sont corroborés par la grille de tarifs IAAP publiée pour CPACC/WAS et par plusieurs sources tierces convergentes — **à revérifier avant achat**.

**Valeur : ⭐⭐⭐⭐** pour un profil déjà orienté production documentaire (publishing, communication interne, secteur public, édition).
