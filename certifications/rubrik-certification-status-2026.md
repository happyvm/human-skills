# Rubrik certification status & TCO — 2026

> Revue : **28 août 2026**. Rubrik est volontairement traité séparément car le parcours officiel est clair sur les prérequis, mais **le prix public du final exam n'est pas exposé clairement sans accès Rubrik University / support portal**.

---

# Rubrik Certified System Administrator — RCSA

Rubrik University maintient le **Rubrik Certified System Administrator (RCSA)** comme credential principal d'administration.

Le credential valide des compétences de gestion opérationnelle de Rubrik Security Cloud / Rubrik Platform :

- protection de workloads datacenter ;
- backup & recovery ;
- SLA automation ;
- disaster recovery ;
- ransomware recovery ;
- administration quotidienne de la plateforme.

Source credential :

- https://www.credly.com/org/rubrik/badge/rubrik-certified-system-administrator-rcsa

---

# Préparation gratuite officielle

Rubrik University publie explicitement un **FREE Certification Learning Path** pour RCSA.

Ce parcours comprend :

1. eLearning de préparation ;
2. practice exams avec tentatives illimitées ;
3. feedback immédiat pour cibler les domaines faibles ;
4. accès au parcours menant au final exam.

Source officielle :

- https://training.rubrik.com/

### Point important

Le bootcamp payant **Introduction to Rubrik Security Cloud**, d'une durée de quatre jours, est présenté comme utile/recommandé mais **pas obligatoire** pour tenter RCSA.

C'est donc l'inverse du nouveau modèle Veeam où les formations sont des prérequis d'éligibilité obligatoires.

---

# Accès au final exam

Credly indique pour RCSA :

- le cours instructor-led 4 jours est **recommended but not required** ;
- un **active support or partner portal credential is required** ;
- des practice exams sont disponibles avant l'inscription au final exam.

Cela signifie qu'un candidat externe sans relation client/partenaire Rubrik peut ne pas disposer du même accès qu'un utilisateur disposant d'un compte support actif.

Source :

- https://www.credly.com/org/rubrik/badge/rubrik-certified-system-administrator-rcsa

---

# Prix : ne pas figer une valeur non vérifiée

La page publique Rubrik University ne publie pas actuellement un prix final exam directement visible sans authentification.

Des sources secondaires 2026 se contredisent :

- certaines annoncent **~200 $**, parfois gratuit pour certains clients/support ;
- d'autres présentent le final exam comme gratuit.

Aucune de ces valeurs secondaires ne doit être transformée en « prix officiel Rubrik » sans visibilité du checkout Rubrik University.

### Classification correcte dans human-skills

```text
RCSA preparation             0 $ officiellement
ILT 4 jours                  facultatif
Support/partner credential   requis pour accès
Final exam price             non public / à confirmer dans portal
```

Donc : **ne pas classer RCSA à 0 $, 200 $ ou 250 $ de manière définitive** tant que le prix final n'est pas vérifiable depuis la source Rubrik authentifiée.

---

# Pourquoi le parcours reste intéressant

Même sans prix public final, RCSA reste potentiellement beaucoup plus économique que VMCE+ car :

- la préparation self-paced est gratuite ;
- la formation instructor-led n'est pas obligatoire ;
- le coût incompressible ne comporte pas trois cours obligatoires avant examen.

Pour un administrateur backup/data protection ayant déjà accès à Rubrik Support, il faut donc **vérifier immédiatement le portal Rubrik University**, car l'accès client peut changer fortement le TCO.

---

# Comparaison Rubrik vs Veeam

| Élément | Rubrik RCSA | Veeam VMCE+ |
|---|---|---|
| Préparation gratuite | **oui** | contenu intro oui, parcours certifiant PRO payant |
| Formation ILT obligatoire | **non** | **formation pertinente obligatoire** |
| Nombre de blocs obligatoires | final exam / accès portal | 3 formations + exam |
| Prix exam public | **non exposé clairement** | **non exposé clairement** |
| TCO from zero | à confirmer | clairement >500 €, souvent plusieurs milliers |
