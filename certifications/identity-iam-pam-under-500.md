# SailPoint

SailPoint sépare les **Knowledge Credentials** et les **Professional Certifications**.

## Knowledge Credentials

Les Knowledge Credentials sont annoncés comme **gratuits** et inclus dans les parcours de formation correspondants.

Exemple documenté :

- Identity Security Leader Knowledge Credential : **0 $** ;
- format online / open-book pour ce credential ;
- badge partageable.

## Professional Certifications

SailPoint indique que les examens Professional Certification coûtent généralement **400 à 500 $**, selon l'examen.

Exemple récent documenté :

- Identity Security Engineer : **400 $** ;
- Identity Security Professional : gratuit avec une Identity University subscription valide dans le schéma annoncé en 2025.

## Recertification

Depuis le programme de recertification 2026 :

- **80 crédits** requis pour une recertification role-based ;
- frais de recertification : **200 $** par certification concernée.

### Verdict

SailPoint est intéressant à deux niveaux :

1. **credentials gratuits** pour ajouter rapidement du signal identity-security ;
2. certifications professionnelles à **400–500 $**.

# BeyondTrust

BeyondTrust University propose du self-paced learning sans coût additionnel pour les clients via **Success Included**, mais cela ne suffit pas à obtenir la certification.

La certification Certified Administrator nécessite :

1. la formation **Instructor-Led Training requise** ;
2. un examen online de **40 questions** ;
3. **75 % minimum** ;
4. deux tentatives maximum avant obligation de racheter une nouvelle formation.

La certification est valide **2 ans** et le renouvellement nécessite **une nouvelle formation + un nouvel examen**.

**Portail officiel :** [BeyondTrust University](https://www.beyondtrust.com/services-training/beyondtrust-university).

Le prix de Success Elevated / Private ILT n'est pas publié sous forme de tarif individuel simple.

### Verdict

À classer en **employer-funded / customer subscription**, et non dans les certifications standalone <500.
