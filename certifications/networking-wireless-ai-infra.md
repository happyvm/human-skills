## Juniper Open Learning — réduction 75 %

C'est l'un des meilleurs dispositifs de certification payante identifié dans le catalogue 2026.

Le principe :

1. suivre gratuitement le curriculum Open Learning éligible ;
2. terminer les modules requis ;
3. réussir le **Voucher Assessment Test à 70 % ou plus** ;
4. obtenir un voucher **-75 %** ;
5. passer l'examen live dans la fenêtre du voucher.

### Prix après voucher

```text
JNCIA     200 $ → 50 $
JNCIS     300 $ → 75 $
JNCIP     400 $ → 100 $
```

Les parcours disponibles dépendent du track et de l'éligibilité / promotion active.

Juniper indique notamment jusqu'à :

- six associate-level tracks ;
- plusieurs specialist tracks ;
- certains professional tracks.

Sources :

- https://learningportal.juniper.net/juniper/user_activity_info.aspx?id=EDU-JUN-CERT-VOUCHERS-HOME
- https://learningportal.juniper.net/juniper/user_activity_info.aspx?id=JUNIPER-OPEN-LEARNING

### Exemples Associate

- JNCIA-Junos ;
- JNCIA-DC ;
- JNCIA-SEC ;
- JNCIA-DevOps ;
- JNCIA-MistAI ;
- autres tracks actifs.

**Priorité valeur/prix : ⭐⭐⭐⭐⭐.**
