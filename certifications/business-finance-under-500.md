# 1. CFA Institute — Investment Foundations Certificate

**Prix standard : 350 $**.

Credential CFA Institute d'introduction au secteur de l'investissement couvrant notamment :

- structure de l'industrie financière ;
- marchés financiers ;
- instruments d'investissement ;
- risque ;
- besoins clients ;
- éthique ;
- rôles dans l'investment management.

Le programme comprend :

- 35 à 65 heures de travail ;
- accès pendant 12 mois ;
- assessment final ;
- certificat partageable.

Les étudiants à temps plein peuvent bénéficier d'un prix spécifique affiché à **79 $**.

Source : https://www.cfainstitute.org/programs/investment-foundations-certificate

**Valeur : ⭐⭐⭐⭐** pour développer une culture finance solide sans entreprendre le CFA Program complet.

# 2. PMI — Agile Certified Practitioner

## PMI-ACP

Tarif 2026 :

- membre PMI : **435 $** ;
- non-membre : **495 $**.

Prérequis annoncés :

- diplôme secondaire ;
- 21 heures de formation aux pratiques Agile ;
- expérience projet ;
- expérience Agile selon critères PMI.

Source : https://www.pmi.org/certifications/agile-acp

À 495 $ non-membre, c'est l'une des certifications les plus intéressantes juste sous notre plafond.

**Valeur : ⭐⭐⭐⭐⭐**.

# 11. Finance — à surveiller

## CFA Institute Principles / Sustainable Investing

Le store CFA affiche actuellement certains produits `Principles of Sustainable Investing` en chinois avec une structure de prix inhabituelle : inscription / curriculum facturés séparément et certaines lignes de certificate à 0 $. Cette offre ne doit pas être présentée comme une certification gratuite générale sans vérifier le parcours exact, la langue et le coût total.

**Statut : watchlist.**

## CFA Program

À partir de 2026 :

- Level I early bird : **1 140 $** ;
- Level I standard : **1 490 $**.

Le CFA Program ira donc dans la future tranche `>500`.

# Ordre intéressant pour un profil technique évoluant vers le management

Sans chercher à collectionner les badges :

1. **TOEIC / Cambridge C1** — preuve d'anglais ;
2. **COBIT Foundation — 175 $** — gouvernance ;
3. **PSM I — 200 $** ou PAL I — leadership Agile ;
4. **Six Sigma Green Belt — 195 $** — amélioration continue ;
5. **CAPM** si besoin de formaliser la gestion de projet ;
6. **TOGAF Foundation — 395 $** — architecture d'entreprise ;
7. **PMI-ACP — jusqu'à 495 $** si les prérequis sont remplis ;
8. **CFA Investment Foundations — 350 $** si l'objectif est d'ajouter une vraie culture finance.
