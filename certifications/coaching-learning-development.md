# Coaching, learning & talent development

> Credentials professionnels autour du coaching, du développement des talents, de la formation et du learning & development.
>
> **Vérification : 28 août 2026**

---

| Credential | Prix officiel | Remarque TCO |
|---|---:|---|
| ICF ACC — Level 1/2 path | **175 $ membre / 325 $ non-membre** | formation + mentor coaching préalables |

# 1. ICF — International Coaching Federation

Le tarif d'application ICF inclut l'application review et l'examen correspondant, mais **pas le cursus de coaching préalable**.

C'est donc un exemple classique où le voucher paraît peu cher alors que le first-cycle TCO dépend surtout de :

- heures de coaching education ;
- mentor coaching ;
- coaching experience ;
- performance evaluation ;
- éventuel programme Level 1 / 2 / 3.

---

## ACC — Associate Certified Coach

### Level 1 / Level 2 path

Pour les candidats ayant achevé un programme ICF accrédité correspondant :

- membre ICF : **175 $** ;
- non-membre : **325 $**.

### Portfolio path

- membre : **475 $** ;
- non-membre : **625 $**.

La Portfolio path exige davantage de documentation et une performance evaluation soumise directement.

Source :

- https://coachingfederation.org/credentialing/icf-credentials-overview/acc/

### Renewal

Tous les trois ans :

- membre : **175 $** ;
- non-membre : **275 $** ;
- ACC : **40 CCE credits** sur le cycle.

---

# 2. PCC — Professional Certified Coach

## Level 2 path

- membre : **375 $** ;
- non-membre : **525 $**.

## Portfolio path

- membre : **750 $** ;
- non-membre : **900 $**.

Le PCC exige notamment une expérience de coaching plus importante et un cursus éducatif conséquent.

Source :

- https://coachingfederation.org/credentialing/icf-credentials-overview/pcc/

**Valeur : ⭐⭐⭐⭐⭐** dans le coaching professionnel.

---

# 3. MCC — Master Certified Coach

Plus haut niveau général ICF.

Prix :

- membre : **675 $** ;
- non-membre : **825 $**.

Le prix est identique pour Level 3 et Portfolio path dans la grille actuelle.

Le MCC demande un niveau d'expérience et de pratique très élevé : le coût de l'application est donc une faible part du TCO réel du parcours.

Retakes :

- performance evaluation : **150 $ par recording** ;
- exam retake : **105 $**.

Renewal trois ans :

- **175 $ membre** ;
- **275 $ non-membre**.

Sources :

- https://coachingfederation.org/credentialing/icf-credentials-overview/mcc/
- https://coachingfederation.org/credentialing/renew-your-credential/

---

# 4. ACTC — Advanced Certification in Team Coaching

Credential complémentaire pour les détenteurs d'un ACC, PCC ou MCC actif.

Tarifs selon path :

- membre : **200–250 $** ;
- non-membre : **300–350 $**.

Prérequis variables :

- credential ICF actif ;
- 30 à 60+ heures de team coaching education selon path ;
- engagements de team coaching ;
- supervision selon route ;
- examen Team Coaching Certification.

Source :

- https://coachingfederation.org/credentials-and-standards/credentials-paths/mcc-credential

---

# 5. ATD — Association for Talent Development

## APTD — Associate Professional in Talent Development

Prix 2026 :

- **525 $ membre** ;
- **800 $ non-membre**.

Le prix inclut :

- application ;
- place d'examen ;
- score report ;
- certificat si réussite.

Les supports et prep courses sont facultatifs.

Source :

- https://www.td.org/certification/aptd/exam

## CPTD — Certified Professional in Talent Development

Prix 2026 :

- **1 099 $ membre** ;
- **1 500 $ non-membre**.

Le CPTD vise des professionnels expérimentés du talent development.

La préparation ATD officielle est facultative et peut ajouter beaucoup au TCO :

- prep on-demand : environ **1 695 $ membre / 1 945 $ non-membre** au catalogue avant promotions ;
- bundles exam + prep existent à plusieurs milliers de dollars.

Source :

- https://www.td.org/certification/cptd/exam

# 6. Recertification ATD

Cycle : **3 ans**.

## APTD

- 40 recertification points ;
- application de renewal : **195 $**.

## CPTD

- 60 points ;
- renewal : **250 $**.

Source :

- https://www.td.org/certification/recertification
