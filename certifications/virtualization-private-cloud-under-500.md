# Pourquoi VMware redevient très rentable

Historiquement, la barrière financière VMware provenait surtout des cours officiels obligatoires.

Le modèle actuel permet de raisonner ainsi :

```text
VCP exam                250 $
Mandatory training        0 $
-----------------------------
Minimum credential TCO  250 $
```

pour les tracks concernés.

Cela change fortement le rapport coût / valeur d'une certification VMware.

# Red Hat — frontière des 500 $

Red Hat indique désormais un **prix catalogue standard de 500 $ USD par examen de certification**, avec variations régionales possibles.

Source :

- https://docs.redhat.com/en/documentation/red_hat_learning_subscription/1-latest/html/red_hat_certification_program_guide/index

Cela concerne des familles telles que :

- RHCSA ;
- RHCE ;
- OpenShift ;
- Ansible Automation ;
- Ceph ;
- specialist exams.

Le point clé est le cumul :

```text
1 examen Red Hat          500 $
2 examens                 1 000 $
5 examens RHCA track      2 500 $ minimum
```

avant formation facultative ou abonnement Red Hat Learning Subscription.
