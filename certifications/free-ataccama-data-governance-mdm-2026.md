# Ataccama ONE — certifications Data Governance / MDM gratuites — 2026

> Revue : **28 août 2026**. Ataccama propose des certifications Consumer gratuites autour de Data Governance & Quality et Master Data Management. L'accès Academy gratuit est explicitement annoncé **pour les clients Ataccama** : il faut donc les classer comme gratuit sous entitlement/environnement client, pas comme inscription publique anonyme garantie.

---

# Politique actuelle

Ataccama a annoncé en février 2025 :

- Academy on-demand **100 % gratuite pour les clients** ;
- certification disponible gratuitement ;
- aucun frais pour les certifications concernées.

Les badges sont toujours émis en 2026.

Source : https://community.ataccama.com/news-announcements-89/exciting-news-ataccama-academy-is-now-100-free-for-customers-1635

# 1. Ataccama ONE — Data Governance & Quality Consumer Certification

```text
Type             Certification
Level            Foundational
Cost             Free
Exam             60 min / QCM
Question pool    150+
Questions exam   80 selon FAQ Ataccama
Retakes          illimités
```

Compétences :

- metadata discovery ;
- data governance ;
- data quality ;
- collaboration ;
- comments / ratings ;
- access requests ;
- workflows ;
- Ataccama ONE Web.

Ataccama précise explicitement que le DQG Consumer Certification est **offered free of charge** et que le nombre de tentatives n'est pas limité.
