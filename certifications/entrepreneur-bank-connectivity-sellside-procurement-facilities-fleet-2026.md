# Entrepreneur — bank connectivity, sell-side readiness & synergies opérationnelles 2026

> Cette fiche couvre le stade où le groupe doit connecter sa trésorerie aux banques de manière industrielle, préparer une vente / vendor due diligence et capter des synergies opérationnelles après acquisition.
>
> Règle `human-skills` : **treasury et standards de paiement = compétences portables**, **TMS = credential éditeur seulement si l'outil est utilisé**, **sell-side readiness = playbook + experts**, et **achats / immobilier / flotte = certifications uniquement lorsque ces fonctions sont matériellement importantes**.

# 1. De la banque en ligne à une vraie architecture de treasury

Le niveau de maturité bancaire d'un groupe ressemble généralement à :

```text
BANK PORTALS
     ↓
MULTI-BANK CASH VISIBILITY
     ↓
TMS
     ↓
HOST-TO-HOST / API
     ↓
SWIFT FOR CORPORATES
     ↓
ISO 20022 / MX
     ↓
PAYMENT FACTORY / IN-HOUSE BANK
```

Le dirigeant n'a pas besoin de devenir administrateur SWIFT, mais doit savoir décider :

- quels comptes / banques centraliser ;
- comment obtenir une vue cash multi-banque ;
- quelles autorisations et contrôles séparer ;
- si un TMS est justifié ;
- si les volumes justifient host-to-host, API ou SWIFT ;
- comment standardiser les paiements et relevés ;
- comment réduire fraude, dépendance manuelle et coûts bancaires.

# 2. AFP — Certified Treasury Professional (CTP)

**CERT — 🌍 INT · US-origin**

Le CTP couvre notamment :

- cash / liquidity management ;
- working capital ;
- treasury operations ;
- corporate finance ;
- financial risk ;
- banking relationships ;
- controls.

La dernière grille publique exploitable stockée dans le repo affiche :

```text
early — AFP member       925 $
early — non-member     1 320 $
final — AFP member     1 025 $
final — non-member     1 420 $
```

Le tarif non-membre inclut une adhésion AFP d'un an sur cette grille. La page publique n'étant pas encore stabilisée sur une nouvelle fenêtre post-janvier 2026 au moment de la revue, **revérifier le checkout avant inscription**.

Maintenance :

- cycle de 3 ans ;
- 36 continuing education credits ;
- membership AFP non obligatoire pour conserver le titre.

Crosslink : [`finance-risk-fraud-over-500.md`](finance-risk-fraud-over-500.md).

### Lecture entrepreneur

Le CTP devient pertinent quand le dirigeant / CFO gère :

```text
plusieurs banques
plusieurs entités
cash pooling
FX / taux
financement
payment controls
working capital significatif
```

Pour une petite holding domestique, ACT CertTF / AwardICM ou une montée en compétence ciblée peuvent être plus rationnels.

# 3. SWIFT / ISO 20022 — quand les paiements deviennent une infrastructure

## Swift Certified Expert — ISO 20022 & CBPR+ Phase 1

**CERT — 🌍 INT**

SWIFT maintient une certification experte sur les messages ISO 20022 / CBPR+ Phase 1.

Le corpus porte notamment sur :

- `pacs.008` ;
- `pacs.009` ;
- `pacs.002` ;
- `pacs.004` ;
- `camt.054` ;
- `head.001` ;
- règles CBPR+ associées.

Le prix individuel n'est pas exposé de manière suffisamment stable publiquement pour enregistrer un faux TCO global :

```text
TCO = Swift / institution / training arrangement dependent
```

## Swift for Corporates Specialist — MX Messages

**CERT — 🌍 INT**

Credential orienté corporate messaging / MX pour les équipes qui utilisent réellement Swift for Corporates.

## Swift for Corporates Client Advisor

**CERT — 🌍 INT**

Pertinent surtout pour les personnes qui conçoivent / accompagnent le dispositif corporate-to-bank ; ce n'est pas un credential prioritaire pour le CEO.

## Swift Smart

**COURSE / RESOURCE — 🌍 INT**

SWIFT Smart fournit des centaines de modules interactifs, dont ISO 20022, paiements, sécurité et connectivité. L'accès dépend généralement du compte Swift lié à l'institution / BIC.

### Pourquoi 2026 compte

La migration ISO 20022 continue de modifier les flux corporate-to-bank. Pour les corporates, SWIFT encourage l'adoption de données structurées ; les règles et releases CBPR+ / MX continuent d'évoluer en 2026.

### Règle entrepreneur

```text
CEO / CFO
→ comprendre l'architecture, les risques et les choix

TREASURY OPS / BANK CONNECTIVITY TEAM
→ certification SWIFT si usage réel
```

# 5. Stablecoins & on-chain liquidity — niche 2026

AFP et Kyriba ont lancé en juin 2026 un certificat commun **Stablecoins & On-chain Liquidity** :

- environ 8 h on-demand ;
- 7,8 CTP credits ;
- digital badge ;
- certificat imprimable après completion.

Le programme est intéressant pour une fonction treasury qui étudie réellement :

- stablecoins de paiement ;
- liquidité on-chain ;
- pilots ;
- gouvernance / risk assessment.

Il reste **optionnel / niche** : ne pas le mettre devant cash forecasting, bank connectivity, controls ou covenant management.

# 6. Sell-side readiness — rendre l'entreprise vendable avant d'ouvrir la data room

Il n'existe pas de certification magique « Vendor Due Diligence » qui rende une société vendable.

Le dirigeant doit préparer :

```text
CLEAN BOOKS
   ↓
NORMALIZED EBITDA
   ↓
WORKING CAPITAL / NET DEBT
   ↓
CUSTOMER / SUPPLIER CONCENTRATION
   ↓
CONTRACTS / IP / HR / CYBER
   ↓
REAL ESTATE / FLEET / ASSETS
   ↓
DATA ROOM
   ↓
MANAGEMENT PRESENTATION
   ↓
VENDOR DD / QoE
   ↓
SPA NEGOTIATION
```

## Les preuves utiles

| Sujet | Credential / ressource | Nature | Pertinence | Portée |
|---|---|---|---|:---:|
| Modèle / valuation | CFI FMVA / IB & PE Modeling | CERT | HAUTE | 🌍 INT |
| Due diligence | CFI Due Diligence / M&A courses | COURSE | HAUTE | 🌍 INT |
| Process M&A | IMAA International M&A Expert | CERT | HAUTE si deals répétés | 🌍 INT |
| Carve-out / TSA | IMAA SCDE | CERT / in-house | HAUTE si périmètre à séparer | 🌍 INT |
| Contrats | WorldCC CCM | CERT | HAUTE B2B complexe | 🌍 INT |
| Cyber | credentials cyber du repo | CERT / QUAL | selon exposition | 🌍 INT / MIX |

### Règle

```text
SELL-SIDE READINESS
→ process + données + contrôles + advisors
≠
collection de certificats
```

Une Vendor Due Diligence / Quality of Earnings produite pour une transaction reste une **mission de conseil / assurance**, pas un credential personnel.


```text

      ↓

      ↓
```

## Credentials à réutiliser

### France opérationnel

### ISM CPSM

**CERT — 🌍 INT · US-origin**

```text
membre       ~1 485 $
non-membre   ~2 385 $
```

### ASCM CSCP

**CERT — 🌍 INT · US-origin**

# 10. Playbook d'intégration des synergies opérationnelles

Une acquisition industrielle ou multi-sites peut être pilotée par workstreams :

| Workstream | 30 jours | 100 jours | Credential utile | Portée |
|---|---|---|---|:---:|
| Banking | inventaire comptes / signataires | rationalisation / connectivity roadmap | ACT / CTP / SWIFT | 🌍 INT |
| Treasury | cash visibility | pooling / forecast / controls | ACT CertTF / CertICM | 🌍 INT · UK-origin |
| Procurement | spend cube / contracts | sourcing waves / renegotiation | CPSM / CIPS | 🌍 INT |
| Facilities | sites / baux / backlog | consolidation / capex roadmap | IFMA CFM/FMP | 🌍 INT |
| Fleet | parc / contrats / coûts | policy / vendors / lifecycle | NAFA CAFM | 🌍 INT · US-centric |
| IT | applications / identity / contracts | target architecture / migration | project + architecture + vendor certs | 🌍 INT / MIX |
| Cyber | exposure / privileged access | hardening / convergence | cyber credentials du repo | 🌍 INT / MIX |

Le credential aide à structurer la fonction ; la **synergie** doit rester mesurée dans le business case : run-rate, one-off costs, délai de capture et risque d'exécution.
