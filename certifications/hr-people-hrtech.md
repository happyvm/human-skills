# 1. SHRM — SHRM-CP / SHRM-SCP

SHRM propose deux certifications professionnelles majeures.

## SHRM-CP

Orienté :

- HR operations ;
- policy execution ;
- employee support ;
- people processes.

SHRM indique désormais qu'aucun diplôme / expérience obligatoire n'est requis pour candidater au SHRM-CP, même si une connaissance pratique RH est naturellement utile.

## SHRM-SCP

Orienté :

- strategic HR ;
- enterprise planning ;
- policy development ;
- leadership.

Éligibilité annoncée : environ **3+ ans de strategic HR work** ou SHRM-CP détenu depuis trois ans selon route.

Source :

- https://www.shrm.org/credentials/certification

# 4. IHRIM — HRIP

## Human Resource Information Professional

Credential spécialisé dans l'intersection **HR + IT + systems + transformation**.

Exam :

- 90 QCM ;
- 120 minutes ;
- online live-proctored ou test center.

Domaines :

- Technology Strategy & Solutions Assessment ;
- HR Technology & Business Processes ;
- Systems Selection / Implementations / Upgrades ;
- HR Systems Operations & Management ;
- Learning & Development Systems.

Source :

- https://www.ihrim.org/education/hrip-certification/

**Valeur : ⭐⭐⭐⭐⭐** pour HRIS / HR tech / people systems.

# 6. CIPD — statut professionnel

Le Chartered Institute of Personnel and Development fonctionne davantage comme une **professional qualification + membership** que comme une certification exam-only.

Grades :

- Foundation ;
- Associate ;
- Chartered Member ;
- Chartered Fellow ;
- autres grades académiques / companion.

---

# 7. CIPD Experience Assessment

Une personne expérimentée peut obtenir un grade professionnel **sans suivre une nouvelle formation** via Experience Assessment.

Le processus comprend :

- submission / evidence ;
- assessment sur knowledge + impact ;
- professional development ;
- professional discussion virtuelle avec assessor.

## Prix 2026/27

| Grade | Assessment | New member total publié |
|---|---:|---:|
| Associate | **2 065 £** | **2 296 £** |
| Chartered Member | **2 115 £** | **2 417 £** |
| Chartered Fellow | **2 460 £** | **2 751 £** |

Le total new member inclut :

- joining fee 40 £ ;
- assessment ;
- membership fee jusqu'au 30 juin 2027.

Source :

- https://www.cipd.org/uk/membership/routes-to-membership/experience-assessment/
