# Pharma, GxP, clinical research & regulatory affairs

> Certifications en qualité pharmaceutique, GMP, affaires réglementaires et recherche clinique. Vérifié fin août 2026.

---

# 1. ASQ — Pharmaceutical GMP Professional

**Auto-formation officielle :** [RAPS — 50+ cours et Regulatory Competency Framework](https://www.raps.org/education/courses), avec checklist de préparation RAC gratuite.

## Certified Pharmaceutical GMP Professional — CPGP

Tarif 2026 :

- prix catalogue : **550 $** ;
- membre ASQ : **450 $** ;
- retake : **350 $**.

### Prérequis

- **5 ans** d'expérience professionnelle dans le Body of Knowledge CPGP ;
- dont **3 ans** en position de décision ;
- emploi full-time rémunéré ;
- **aucune exemption de durée par diplôme**.

Le programme couvre notamment :

- GMP ;
- médicaments humains et vétérinaires ;
- biologiques ;
- API / excipients ;
- packaging / labeling ;
- systèmes qualité ;
- réglementation et contrôle des procédés.

Source :

- https://www.asq.org/cert/pharmaceutical-gmp

### Recertification

CPGP fait partie des certifications ASQ à recertifier tous les **3 ans** :

- 18 Recertification Units ; ou
- repassage de l'examen.

Recertification par journal :

- **120 $ membre** ;
- **160 $ non-membre** pour une certification.

Source :

- https://www.asq.org/cert/recertification

# 6. ACRP — Clinical Research

ACRP propose notamment :

- ACRP-CP ;
- CCRA — Certified Clinical Research Associate ;
- CCRC — Certified Clinical Research Coordinator ;
- CPI — Certified Principal Investigator.

## Grille 2026 flagship

### Early bird

- membre : **435 $** ;
- non-membre : **485 $**.

### Regular

- membre : **460 $** ;
- non-membre : **600 $**.

Membership individuel industrialized-country : autour de **160 $/an** ; membership **non obligatoire** pour obtenir la certification.

### Maintenance

Cycle : **2 ans**.

Tarifs de maintenance :

- early : **225 $ membre / 300 $ non-membre** ;
- regular : **250 $ membre / 325 $ non-membre**.

Le maintien requiert également des points / continuing education selon credential.

Source :

- https://acrpnet.org/certifications

# 7. SOCRA — Certified Clinical Research Professional

## CCRP

Tarifs actuels :

### Amérique du Nord

- membre : **510 $** ;
- non-membre : **565 $**.

### Hors Amérique du Nord

- membre : **570 $** ;
- non-membre : **625 $**.

### Retake

**390 $** dans l'année suivant l'examen initial.

Le dossier exige notamment :

- CV ;
- job descriptions ;
- vérification d'emploi ;
- expérience admissible selon catégorie.

Source :

- https://www.socra.org/certification/ccrp-certification-exam/application-and-fee/

### Recertification

Cycle : **3 ans**.

- **350 $** pour trois ans ;
- ou installment plan **200 + 100 + 100 $** ;
- **45 heures** de continuing education ;
- module réglementaire SOCRA.

Source :

- https://www.socra.org/certification/recertification/ccrp-renewal-of-certification/

# 8. ISO 13485 Lead Auditor (dispositifs médicaux)

Suit le même modèle que les autres Lead Auditor PECB déjà documentés dans `iso-grc-europe-over-500.md` (voir aussi la mise en garde ISO 42001 sur la distinction prix individuel / prix de certification d'entreprise, applicable ici aussi).

- BSI : parcours Practitioner et Professional distincts, prix non exposé publiquement.

- https://pecb.com/en/education-and-certification-for-individuals/iso-13485/iso-13485-lead-auditor
