# Juniper JNCIA-DevOps

## Automation and DevOps, Associate — JN0-224

La certification **JNCIA-DevOps** valide des bases particulièrement utiles pour un ingénieur réseau moderne :

- DevOps et automation ;
- NETCONF/XML ;
- XPath ;
- YAML / JSON ;
- Python ;
- PyEZ ;
- JSNAPy ;
- Jinja2 ;
- Junos REST API ;
- RPC ;
- gestion de configuration.

Détails de l'examen :

```text
Code          JN0-224
Durée         90 min
Questions     65 QCM
Prérequis     aucun
Langue        anglais
Validité      3 ans
```

## Open Learning : examen à 50 $

Le programme **Juniper Open Learning** propose gratuitement le parcours JNCIA-DevOps.

Après :

1. réalisation des modules ;
2. réussite du Voucher Assessment Test à **70 % minimum** ;

Juniper délivre un voucher de **75 % de réduction**, ramenant l'examen live à **50 $**.

Le voucher doit être utilisé dans les 30 jours après émission.

### Verdict

À **50 $**, JNCIA-DevOps est probablement la meilleure certification NetDevOps généraliste low-cost actuellement identifiée.

- https://www.juniper.net/us/en/training/certification/tracks/devops/jncia-devops.html

# Nokia NSP IP Network Automation Professional

C'est l'une des meilleures surprises de cette passe.

**Auto-formation officielle :** [nokia.com/networks/training/nsp](https://www.nokia.com/networks/training/nsp/) — self-paced training et NSP Learning Labs (accès distant 24/7) en complément de l'instructor-led.

## Credential

**Nokia Certified NSP IP Network Automation Professional**

Un seul examen obligatoire :

```text
Exam          4A0-AI1
Prix          125 $ US
Durée         120 min
Questions     80
Prérequis     aucun
Formation     recommandée mais NON obligatoire
Delivery      Pearson VUE, online ou centre
```

Compétences :

- SDN ;
- APIs programmables ;
- REST / RESTCONF ;
- network workflows ;
- intent-based networking ;
- telemetry ;
- automation des opérations réseau ;
- NSP Workflow Manager ;
- YANG ;
- Kafka/Jinja2 selon modules de préparation.

### Point TCO important

Nokia vend des formations eLearning et ILT parfois coûteuses, mais confirme explicitement que **la formation n'est pas obligatoire pour tenter l'examen**.

Il est donc possible d'obtenir la certification avec un TCO examen de **125 $**, en préparant via documentation / practice exam / expérience produit.

### Verdict

**Très fort ROI** pour un credential intitulé explicitement « Network Automation Professional ».

Sources :

- https://www.nokia.com/networks/training/nsp/exams/4a0-ai1/

# Cisco Professional : attention au TCO

Cisco facture actuellement :

```text
Professional core exam           400 $
Professional concentration exam  300 $
```

Une certification Professional complète nécessite typiquement **core + concentration**, soit environ :

```text
400 + 300 = 700 $
```

Le fait qu'un examen individuel coûte moins de 500 $ ne signifie donc pas que la **certification complète** est sous 500 $.

C'est exactement le type de piège que ce dépôt doit éviter.

Source :

- https://www.cisco.com/site/us/en/learn/training-certifications/exams/index.html
