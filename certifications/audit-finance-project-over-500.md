# 1. IIA — Certified Internal Auditor (CIA)

Le **Certified Internal Auditor (CIA)** est une certification de référence mondiale en audit interne.

## Tarifs actuels publiés par The IIA

### Membre IIA

| Élément | Prix |
|---|---:|
| Application | 120 $ |
| Part 1 | 310 $ |
| Part 2 | 280 $ |
| Part 3 | 280 $ |
| **Total certification** | **990 $** |

### Non-membre

| Élément | Prix |
|---|---:|
| Application | 240 $ |
| Part 1 | 445 $ |
| Part 2 | 415 $ |
| Part 3 | 415 $ |
| **Total certification** | **1 515 $** |

Au taux de référence du dépôt :

```text
990 $   ≈ 850 €
1 515 $ ≈ 1 301 €
```

Pour le tarif membre, il faut naturellement ajouter le coût de l'adhésion IIA applicable dans le pays du candidat.

The IIA précise que les prix peuvent varier hors Amérique du Nord via les instituts nationaux ; un candidat français doit donc vérifier la grille IIA France avant achat.

## Maintien

La page tarifaire actuelle indique notamment :

- renouvellement CIA actif : **30 $ membre / 120 $ non-membre** dans les régions relevant directement de cette grille ;
- les frais peuvent varier via les instituts nationaux.

La certification implique également des exigences de formation professionnelle continue.

Sources :

- https://www.theiia.org/en/certifications/new-to-certification/Pricing
- https://www.theiia.org/en/certifications/cia

**Valeur CV : ⭐⭐⭐⭐⭐** en audit interne, contrôle, risk et gouvernance.

# 2. IIA — Certification in Risk Management Assurance (CRMA)

Le **CRMA** est orienté risk management, gouvernance et assurance.

Point important : **le CIA n'est plus un prérequis** dans le programme actuel.

## Prix

### Membre

```text
Application  100 $
Exam         465 $
-----------------
Total        565 $
```

Soit environ **485 €** avant coût de membership et taxes éventuelles.

### Non-membre

```text
Application  220 $
Exam         610 $
-----------------
Total        830 $
```

Soit environ **713 €**.

Le tarif membre est donc un bon exemple de credential dont le voucher + application semble sous 500 €, mais dont le **TCO doit inclure l'adhésion**.

Renouvellement publié : **20 $ membre / 120 $ non-membre** dans la grille globale actuelle, avec variation possible selon institut national.

Sources :

- https://www.theiia.org/en/certifications/crma/
- https://www.theiia.org/en/certifications/new-to-certification/Pricing

**Valeur CV : ⭐⭐⭐⭐⭐** pour risk, audit et governance.

# 4. IMA — Certified Management Accountant (CMA)

Le **CMA** est une certification internationale de management accounting / contrôle de gestion / finance d'entreprise.

## Professionnel

IMA publie actuellement :

| Élément | Prix |
|---|---:|
| CMA Entrance Fee | 300 $ |
| Exam Part 1 | 545 $ |
| Exam Part 2 | 545 $ |
| IMA Membership | 295 $ |
| CMA Annual Maintenance Fee | 30 $ |
| **Première année** | **1 715 $** |

Soit environ **1 473 €** avant matériel ou formation de préparation.

Le maintien impose ensuite :

- renouvellement de l'adhésion IMA ;
- **30 $ de CMA Annual Maintenance Fee** ;
- exigences CPE selon le règlement du CMA.

## Étudiant / académique

Tarifs réduits :

- Entrance Fee : **225 $** ;
- Exam : **407 $ par partie** ;
- Membership : **49 $ étudiant / 160 $ académique** ;
- maintenance : **30 $**.

Source :

- https://www.imanet.org/ima-certifications/cma-certification/enroll-in-the-cma

**Valeur CV : ⭐⭐⭐⭐⭐** pour contrôle de gestion, management accounting et finance corporate internationale.

# 5. ACCA Qualification

L'**ACCA Qualification** ne se compare pas à une certification IT à examen unique : c'est un parcours professionnel multi-examens, avec abonnement annuel et admission finale au membership.

## Frais fixes 2026 publiés par ACCA

Sur la grille globale / européenne consultée :

- inscription initiale : **£89** ;
- abonnement étudiant annuel 2026 : **£140** ;
- Ethics and Professional Skills Module : **£83** ;
- admission finale au membership : **£326** ;
- abonnement annuel membre 2026 : **£326**.

## Exemples d'examens Strategic Professional — décembre 2026

- Strategic Business Leader : **£295** standard ;
- Strategic Business Reporting : **£229** ;
- options AFM/APM/ATX/AAA : **£229 chacune**.

Les examens Applied Knowledge / Applied Skills peuvent dépendre du centre ou de la région, et le nombre d'examens réellement nécessaire dépend des exemptions académiques.

Le **TCO depuis zéro est donc nécessairement un calcul personnalisé** :

```text
registration
+ annual subscriptions pendant le parcours
+ examens réellement nécessaires
+ Ethics module
+ éventuels frais d'exemption
+ admission au membership
+ membership annuel
+ éventuelle préparation
```

Source :

- https://www.accaglobal.com/gb/en/qualifications/accountancy-career/fees/fees-charges.html

**Valeur CV : ⭐⭐⭐⭐⭐** pour comptabilité/finance internationale, mais investissement nettement plus lourd et long qu'un simple credential.

# 6. IPMA France — SMaP

La SMaP publie directement ses **tarifs 2026** pour les certifications IPMA en France.

Les prix affichés sont **hors taxes**, sauf tarifs étudiants.

| Niveau | Prix 2026 HT | Renouvellement / prorogation affiché |
|---|---:|---:|
| IPMA Level D | **440 € HT** | repassage examen |
| IPMA Level C — Atelier | **1 680 € HT** | **370 € HT** |
| IPMA Level C — Rapport | **1 680 € HT** | **370 € HT** |
| IPMA Level B | **2 090 € HT** | **580 € HT** |
| IPMA Level A | **2 530 € HT** | **790 € HT** |

### Level D : frontière des 500 €

Pour un particulier soumis à une TVA de 20 % :

```text
440 € HT × 1,20 = 528 € TTC
```

Il appartient donc à la tranche >500 € au **TTC particulier**, alors qu'il serait classé `<500` si l'on ne regardait que le montant HT.

Le tarif étudiant affiché est **140 €**.

Les certifications A/B/C sont valables cinq ans et suivent un processus de renouvellement. La SMaP indique également que tous les nouveaux candidats bénéficient d'un an d'adhésion.

Source :

- https://www.smap-asso.eu/certifications/

**Valeur CV : ⭐⭐⭐⭐–⭐⭐⭐⭐⭐** selon niveau et environnement projet/programme.

# 8. ACMP — Certified Change Management Professional (CCMP)

Le **CCMP** est une certification professionnelle d'expérience, et non simplement un cours de méthode.

## Tarif 2026

ACMP a confirmé pour janvier 2026 :

- membre : **595 $** ;
- non-membre : **795 $**.

L'application inclut la première tentative d'examen.

Membership individuel professionnel affiché dans les offres ACMP : **199 $**.

### TCO membre minimal avant formation

```text
Membership  199 $
CCMP        595 $
----------------
            794 $
```

Soit environ **682 €**, avant formation admissible.

### Prérequis formation

Le candidat doit justifier **21 heures de formation en change management dans les sept dernières années**, alignées sur le Standard for Change Management.

Cette formation n'est **pas fournie par ACMP** et son coût peut aller de faible à plusieurs milliers d'euros selon le fournisseur choisi.

Il existe aussi des exigences d'expérience professionnelle.

## Maintien

Le handbook ACMP disponible indique :

- **60 PDUs par cycle de trois ans** ;
- renouvellement : **100 $ membre / 150 $ non-membre** dans la grille du handbook actuel disponible publiquement.

Comme la tarification d'application a changé en 2026, le renouvellement doit être revérifié au moment du paiement.

Sources :

- https://www.acmpglobal.org/general/custom.asp?page=ccmp_corporate_packs
- https://www.acmpglobal.org/page/ccmp-training-faq
- https://www.acmpglobal.org/page/guide-to-a-successful-ccmp-application

**Valeur CV : ⭐⭐⭐⭐⭐** pour un change manager expérimenté.

# 9. APMG Change Management — tarif régional à surveiller

APMG permet le **self-study** pour Change Management et vend des examens publics en ligne selon région.

Le prix exact n'est pas exposé de manière stable sur la page globale ; il dépend du portail d'examen / localisation.

Un bundle britannique actuel pour les détenteurs de Foundation confirme toutefois :

- Change Management v3 Practitioner : prix normal **£448 TTC** ;
- promotion bundle UK : **£336 TTC** ;
- Foundation est un prérequis pour ce parcours Practitioner.

À environ 1,166 € par livre, **£448 ≈ 522 €** : le Practitioner au prix britannique normal franchit déjà la barre de 500 €, même avant le coût du Foundation détenu en amont.

Cette donnée britannique ne doit **pas** être appliquée automatiquement à la France ; le prix France doit être récupéré dans le portail régional APMG.

Sources :

- https://apmg-international.com/fr/product/gestion-du-changement
- https://store.apmg-international.com/assessments/change-management-v3-practitioner-exam-bundle

# Comparatif change management — première lecture

| Parcours | Logique | Prix / TCO indicatif |
|---|---|---:|
| SMaP Gestion du changement | Certification française | **1 280 € HT** |
| APMG Change Management | Méthode + Foundation/Practitioner | tarif régional ; Practitioner UK normal **£448 TTC** |
| ACMP CCMP | Certification d'expérience vendor-neutral | **595/795 $ + 21 h de formation** |
| Prosci Change Management | Formation méthodologique + certification | **3 386 € online / 3 810 € présentiel hors taxes** |

Ces quatre credentials ne valident pas exactement la même chose. Le coût seul ne suffit donc pas à choisir.

# Shortlist valeur / coût

Dans cette catégorie, les credentials ayant le meilleur intérêt général sont :

1. **IIA CIA** — référence audit interne internationale.
2. **IIA CRMA** — risk/governance/assurance, particulièrement transversal.
3. **IPMA Level C/B** — gestion de projet et projets complexes en Europe.
4. **ACMP CCMP** — change management expérimenté sans dépendre d'une méthode propriétaire unique.
5. **IMA CMA** — contrôle de gestion et finance corporate.
6. **ACCA** — très puissant pour une vraie trajectoire comptabilité/finance, mais parcours long.
