# AIX

## IBM AIX v7.3 Administrator Specialty

Credential code : **S2113000**  
Exam : **S2000-025 — IBM AIX v7.3 Administrator Specialty**

- statut : Live ;
- un seul examen ;
- prix affiché par IBM : **100 $ US** ;
- domaines : setup, exploitation, troubleshooting, performance/tuning, stockage, sécurité AIX ;
- NIM et scripting shell font partie des compétences attendues.

### Verdict

**Excellent rapport signal/prix.** Une certification UNIX/AIX IBM officielle à 100 $ est particulièrement intéressante pour des profils infrastructure enterprise, banque, assurance, industrie ou legacy modernization.

Source :

- https://www.ibm.com/training/certification/ibm-aix-v73-administrator-specialty-S2113000

# QRadar

## QRadar SIEM Foundation Badge — gratuit

IBM propose un badge **QRadar SIEM Foundation** entièrement gratuit.

Pour l'obtenir :

- compléter les cours requis de la Security Learning Academy ;
- passer un quiz de **63 questions** ;
- obtenir **80 % minimum** ;
- badge Credly à la réussite.

IBM précise que les cours requis sont **free of charge**.

### Verdict

À ajouter au même niveau que les meilleurs credentials IT gratuits du dépôt.

Sources :

- https://www.ibm.com/support/pages/ibm-qradar-siem-foundation-badge
- https://www.ibm.com/training/course/ibm-qradar-siem-foundation-badge-SLA4233

## QRadar SIEM v7.5 certifications

IBM maintient plusieurs certifications live à **200 $ par examen** :

La préparation self-study de certains examens est gratuite via la Security Learning Academy.

# RACF / CICS / IMS

IBM continue à proposer des formations actives sur **RACF** et zSecure, mais cette passe n'a pas permis d'identifier une certification professionnelle live séparée et clairement tarifée pour RACF, CICS ou IMS comparable aux credentials AIX/zOS/Db2/MQ.

Ne pas confondre : **formation IBM active ≠ certification IBM active**.

On conserve donc RACF/CICS/IMS en watchlist jusqu'à confirmation d'un credential live dans le catalogue IBM Credentials.
