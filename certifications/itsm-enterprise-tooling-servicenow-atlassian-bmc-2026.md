# 1. Atlassian

Atlassian dispose de deux niveaux à ne pas confondre :

```text
Atlassian Certificate        gratuit / unproctored
Atlassian Certification      proctored / payant
```

La documentation communautaire officielle Atlassian 2026 indique :

```text
Certified Associate exam      100 $
Certified Professional exam   249 $
```

Les cours on-demand sont majoritairement gratuits ou très peu coûteux selon parcours.

**Auto-formation officielle et gratuite :** [university.atlassian.com](https://university.atlassian.com/) — catalogue 100 % gratuit en on-demand, incluant des learning paths de préparation à la certification.

Sources :

- https://community.atlassian.com/learning/hub/resources-and-support/about-atlassian-credentials/
- https://success.atlassian.com/solution-resources/agile-and-devops-ado/platform-administration/validate-your-expertise-and-advance-your-career-with-atlassian

# 2. ServiceNow

ServiceNow University propose plusieurs types de credentials :

- Mainline Certifications ;
- Micro-Certifications ;
- Accreditations ;
- Expert Programs.

Les **Mainline** sont des examens proctorés. Les Micro-Credentials sont plus étroits et non proctorés.

Source :

- https://learning.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0012292

---

## Certified System Administrator — CSA

Le blueprint CSA a été mis à jour en **janvier 2026**.

Il valide notamment :

- plateforme ServiceNow ;
- navigation / configuration ;
- task management ;
- dashboards / analytics ;
- Knowledge Management ;
- Service Catalog ;
- Workflow Studio ;
- Virtual Agent ;
- database management ;
- CMDB / CSDM ;
- platform security ;
- integrations / migration ;
- UI Policies / Business Rules ;
- scripting.

La livraison est désormais via **Pearson VUE**, en centre ou OnVUE.

Source :

- https://learning.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0011554

### Prix

La FAQ Pearson/ServiceNow 2026 donne un exemple de **full exam fee à 300 $** et un tarif de retake :

```text
CSA / CAD / CPOA retake     150 $
CIS retake                  225 $
```

ServiceNow précise que les prix peuvent varier et que des remises customer/partner peuvent s'appliquer.

La documentation communautaire ServiceNow 2026 confirme également un CSA autour de **300 $ + taxes**.

Source officielle principale :

- https://learning.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0013209

### Retake waiting periods

```text
1er → 2e essai      3 jours
2e → 3e essai     30 jours
ensuite             6 mois
```

---

## CIS / CAD / autres Mainline

ServiceNow maintient notamment :

- CSA — Certified System Administrator ;
- CAD — Certified Application Developer ;
- CPOA ;
- CIS — Certified Implementation Specialist, décliné sur de nombreux produits ;
- expert programs CTA / CMA / autres parcours d'architecture.

Le catalogue CIS couvre de nombreux domaines : ITSM, ITOM, SecOps, CSM, HR, etc.

### Attention TCO

Le prix initial de l'examen n'est qu'une partie du coût :

- certains learning paths / trainings servent de prerequisite ;
- certification maintenance ;
- delta exams ;
- annuel CMP fee selon statut du credential.

Le CSA peut donc rester sous 500 $ à l'entrée mais son **lifecycle TCO** est supérieur au simple exam fee.

Ces micro-credentials / accreditations ne doivent cependant pas être confondus avec une Mainline Certification proctorée.

Accès : [learning.servicenow.com](https://learning.servicenow.com/) — ServiceNow University (ex-Now Learning).

# 3. BMC Helix

**Auto-formation officielle :** [bmc.com/education](https://www.bmc.com/education/training-and-certification.html) — principalement via abonnement (Education Subscription), peu de contenu gratuit confirmé.

BMC maintient des certifications professionnelles autour de Helix, par exemple :

- **BMC Certified Professional: Helix ITSM**.

Le Certified Professional Helix ITSM valide la capacité à :

- deploy ;
- operate ;
- administer ;
- gérer les fonctions OOTB de BMC Helix ITSM.

## Examen

La page BMC indique :

- online proctored ;
- 2 heures ;
- formation recommandée ;
- l'examen peut être **acheté séparément même sans avoir suivi le parcours recommandé** ;
- le dernier cours du learning path inclut une tentative ;
- les tentatives supplémentaires bénéficient d'une remise de 50 % lorsqu'on suit le parcours concerné.

### Prix

Le tarif public exact est derrière **Pricing & Registration / Contact an Advisor** et n'est pas suffisamment exposé pour figer un montant dans le dépôt.

Source :

- https://www.bmc.com/education/courses/certified-professional-helix-itsm-20x-online-proctored-exam.html

### Verdict

Credential réel, mais **checkout/contact-required** pour le prix.

# 4. Zendesk — absent du dépôt jusqu'à cette revue

Zendesk (help desk / customer support, alternative plus légère à ServiceNow pour un profil support client plutôt qu'ITSM enterprise) n'avait aucune mention dans le dépôt. Prix confirmés directement sur la page officielle de l'examen Support Administrator Expert.

```text
Niveau Specialist (Guide, Chat, Talk, Omnichannel Agent...)    199 $ chacun
Niveau Expert (Support Administrator, Explore CX Analyst,
  App Developer)                                               350 $ chacun
```

## Support Administrator Expert — détail confirmé

- **78 questions**, QCM, **105 minutes** ;
- score de passage : **65 %** ;
- pas de prérequis formel, mais Zendesk recommande **3 mois d'expérience** comme Support Administrator et d'avoir suivi le Foundational Support Learning Path ;
- recertification nécessaire au fil des mises à jour produit (guides d'examen + practice exams + repassage).

Des bundles multi-certifications existent pour réduire le coût unitaire.

Source :

- https://academy.zendesk.com/certification-zendesk-support-administrator-expert-exam
- https://academy.zendesk.com/

**Valeur : ⭐⭐⭐⭐** pour un profil support client / CX — écosystème plus accessible que ServiceNow pour des équipes support pur (moins orienté ITSM enterprise complexe), prix raisonnable au niveau Specialist (199 $).

# 5. Intercom (Fin Academy) — gratuit, absent du dépôt jusqu'à cette revue

**Intercom** (customer support/messaging, plateforme rebrandée autour de son IA **Fin** — portail désormais `academy.fin.ai`) propose deux certifications **entièrement gratuites**, confirmées directement sur la FAQ officielle : *« Taking courses on Fin Academy is free! »*.

```text
Support Agent Certification       gratuit
Support Manager Certification     gratuit
```

## Support Agent — détail confirmé

- **55 questions**, QCM, **90 minutes** ;
- score de passage : **75 % (42/55)** ;
- **open-book** — ressources autorisées pendant l'examen ;
- couvre Inbox, conversations/tickets, configuration Messenger, Outbound/Series, Fin AI Agent, Workflows, Help Center, permissions et data model ;
- credential délivré via **Accredible**.

Source :

- https://academy.fin.ai/page/faqs
- https://academy.fin.ai/support-agent-certification
- https://academy.fin.ai/support-manager-certification

**Valeur : ⭐⭐⭐⭐⭐** — alternative gratuite crédible à Zendesk (payant) ci-dessus, bon signal pour un profil support client sur un outil largement adopté par les startups/scale-ups.
