# Free cloud & data microcredentials — 2026

> Revue : **28 août 2026**. Complément à [`free-it.md`](free-it.md). Cette fiche regroupe les **microcredentials, hands-on badges et certificates évalués gratuits** chez de grands vendors cloud/data.

---

# 1. AWS Microcredentials — gratuits pour tous depuis avril 2026

AWS a annoncé le **23 avril 2026** que ses microcredentials sont désormais **gratuitement accessibles à tous les builders**, sans abonnement AWS Skill Builder.

Contrairement à un simple quiz, ces credentials utilisent des **hands-on assessments dans un environnement AWS live simulé**.

Le candidat doit réellement :

- configurer ;
- dépanner ;
- réparer ;
- optimiser ;
- résoudre un scénario métier.

Aucun QCM classique n'est utilisé pour cette famille.

## Microcredentials disponibles lors de la revue

### AWS Serverless Demonstrated

Valide les compétences hands-on sur :

- AWS Lambda ;
- Amazon API Gateway ;
- AWS Step Functions ;
- Amazon DynamoDB ;
- implementation et troubleshooting serverless.

### AWS Agentic AI Demonstrated

Valide la capacité à :

- dépanner des agents IA ;
- réparer / intégrer des agents ;
- améliorer des solutions basées sur **Amazon Bedrock**.

### AWS Application Networking Demonstrated

Valide des tâches pratiques liées à :

- application delivery ;
- performance optimisation ;
- modern application architecture ;
- application networking.

### AWS Incident Response Demonstrated

Valide la capacité à :

- identifier des incidents ;
- contenir ;
- remédier ;
- traiter des incidents de sécurité AWS courants.

AWS annonce d'autres microcredentials pour 2026.

```text
Prix                         0 $
Subscription Skill Builder   non requise
Format                       hands-on
Environnement                AWS live simulé
Credential                   AWS microcredential
```

### Valeur

⭐⭐⭐⭐⭐ : probablement l'un des meilleurs credentials pratiques gratuits disponibles en 2026.

Source :

- https://aws.amazon.com/blogs/training-and-certification/microcredentials-from-aws-are-now-free-heres-why-that-matters/

# 2. AWS Training / Educate digital badges

AWS propose aussi gratuitement de nombreux digital learning badges.

Pour les AWS Training badges concernés :

1. compte AWS Skill Builder gratuit ;
2. suivre le learning plan ;
3. passer l'assessment ;
4. obtenir généralement **80 % minimum** ;
5. réclamer le badge Credly.

AWS indique que la plupart de ses learning badges sont gratuits à obtenir.

AWS Educate est ouvert aux apprenants et propose gratuitement :

- cloud basics ;
- storage ;
- compute ;
- networking ;
- databases ;
- cloud operations ;
- AI topics selon catalogue ;
- hands-on labs ;
- digital badges.

> Les learning badges ne sont pas des AWS Certifications proctored.

Sources :

- https://aws.amazon.com/training/badges/
- https://aws.amazon.com/education/awseducate/

# 3. Snowflake Hands-On Essentials — six badges gratuits

Snowflake University maintient une série de **Hands-On Essentials Badges** gratuite et autogradée.

## Badges visibles

1. **Data Warehousing Workshop — Badge 1** ;
2. **Collaboration, Marketplace & Cost Estimation Workshop — Badge 2** ;
3. **Data Application Builders Workshop — Badge 3** ;
4. **Data Lake Workshop — Badge 4** ;
5. **Data Engineering Workshop — Badge 5** ;
6. **Data Science Workshop — Badge 6**.

Les workshops incluent :

- vidéos courtes ;
- labs step-by-step ;
- reflection questions ;
- challenge labs ;
- vérification automatique des travaux par DORA / grading automation ;

Snowflake confirme que les cours de cette track sont gratuits et qu'un grand nombre de badges le sont également ; les six Hands-On Essentials principaux apparaissent comme **On-Demand Free** dans le catalogue actuel.

> Séparer de **SnowPro Certification**, qui reste payante.

### Valeur

⭐⭐⭐⭐ pour data engineering / Snowflake / analytics.

# 4. dbt Fundamentals — badge gratuit évalué

Le **dbt Fundamentals** badge est délivré aux développeurs qui :

- terminent le cours dbt Fundamentals ;
- réussissent le quiz final.

Le credential est vérifiable via le portail de credentials dbt Labs et **n'expire pas** selon les pages de badge observées.

Le contenu dbt Learn est proposé gratuitement.

```text
Course           gratuit
Quiz final       oui
Badge            dbt Labs verified issuer
Expiration       aucune pour le Fundamentals badge observé
```

> Ce badge n'est pas la **dbt Analytics Engineering Certification**, qui est un examen proctored payant.

Sources :

- https://www.getdbt.com/dbt-learn
- https://credentials.getdbt.com/
- https://www.getdbt.com/blog/new-learn-courses

# 5. Redis University — certificates évalués gratuits

Redis University confirme en 2026 que :

- tous les cours et learning paths sont **complètement gratuits** ;
- un certificate de completion est obtenu en réussissant les examens et quizzes ;
- seuil typique : **80 % ou plus**.

```text
Courses                 0 $
Quizzes/exams           inclus
Certificate completion  0 $
```

### Important

L'ancienne **Redis Developer Certification** a été dépréciée en juin 2024. Redis travaille sur un nouveau programme de certification formelle en 2026, dont les examens devront être achetés via Kryterion.

Donc :

- Redis University certificate = gratuit ;
- nouvelle Redis professional certification = payante / future.

Sources :

- https://redis.io/tutorials/university/
- https://redis.io/blog/redis-developer-certification-is-here/
- https://redis.io/legal/redis-certification-program-terms-and-conditions/

# 7. Cockroach University — cours gratuits avec final exam / certificates

Cockroach University propose des parcours gratuits de formation sur CockroachDB, y compris des cours développeur avec :

- vidéos ;
- hands-on labs ;
- final exam ;
- Certification / Certificate of Completion selon le cours.

Exemple historique toujours pertinent pour le modèle de programme : **CockroachDB for Python Developers** comprend 12 labs et un final exam ; après réussite, un Certificate of Completion est délivré.

En 2026, Cockroach Labs continue d'étendre University, notamment avec de nouveaux cours Agent Skills gratuits.

> Le catalogue et les accès certification évoluent ; vérifier le nom exact du credential sur le cours choisi avant de l'ajouter comme certification professionnelle.

Sources :

- https://learn.cockroachlabs.com/
- https://www.cockroachlabs.com/blog/ai-cockroachdb-training-courses/
- https://www.cockroachlabs.com/blog/cockroachdb-for-python-course/
