# Free openHPI Records of Achievement — 2026

> Revue : **28 août 2026**. openHPI est la plateforme de formation en ligne du Hasso Plattner Institute (Potsdam). Les cours publics sont gratuits et les cours actifs de format adéquat peuvent délivrer un **Record of Achievement** après devoirs évalués et examen final.

---

# Modèle openHPI

openHPI indique :

```text
Course access              0 $
Admission restrictions     aucune
Weekly graded assignments  oui
Final exam                 oui
Passing threshold          >50 % des points
Record of Achievement      oui
Verification               anti-counterfeit link + QR code
```

Les exercices/examens peuvent inclure :

- QCM ;
- multiple-answer ;
- exercices de programmation pratiques ;
- CodeOcean / LTI pour certains exercices de code.

Le Record of Achievement contient notamment :

- nom du participant ;
- titre et résumé du cours ;
- crédits/points ;
- performance ;
- indication top 5/10/20 % le cas échéant ;
- lien anti-contrefaçon ;
- QR code ;
- signature de l'enseignant.

Sources :

- https://open.hpi.de/pages/certificates_and_guidelines?locale=en
- https://open.hpi.de/pages/roa_guidelines
- https://open.hpi.de/pages/faq?locale=en

# Important : Record of Achievement ≠ ancien proctored Certificate

openHPI ne propose **actuellement plus** son ancien type `Certificate` avec webcam/proctoring.

Le credential gratuit actuel pertinent est le **Record of Achievement**.

Donc :

```text
Confirmation of Participation  = présence / matériel consulté
Record of Achievement          = travaux notés + exam réussi
Certificate proctored          = actuellement non proposé
```

Cette fiche ne valorise que le **Record of Achievement**, pas les simples confirmations de participation.

# Autres catégories à surveiller

openHPI couvre historiquement et actuellement :

- programming ;
- cybersecurity ;
- cloud computing ;
- databases ;
- AI / data science ;
- digital transformation ;
- Internet technologies ;
- software engineering.

Pour chaque nouvelle session :

1. ouvrir la page du cours ;
2. vérifier qu'elle affiche **Record of Achievement** ;
3. vérifier que le cours est encore actif (pas uniquement archive/self-study) ;
4. terminer les assignments avant leurs deadlines ;
5. passer le final exam.

### Pourquoi l'activité du cours est importante

openHPI précise qu'après la fin d'un cours, les nouveaux inscrits en self-study ne peuvent généralement plus soumettre les tâches évaluées avec deadline ; ils n'obtiennent alors qu'une Confirmation of Participation.

Source :

- https://open.hpi.de/pages/faq?locale=en

# Positionnement

Le Record of Achievement n'est pas une certification industrielle proctorée type RHCSA/CKA/Pearson VUE.

Mais il est plus solide qu'un simple course certificate :

```text
free course
+ graded weekly work
+ final exam
+ teacher signature
+ performance score
+ anti-counterfeit URL
+ QR code
```

Pour enrichir gratuitement un portfolio IT/AI académique, openHPI est donc un excellent complément à **Harvard CS50**, **University of Helsinki**, **Purdue Global** et **MathWorks Academy**.
