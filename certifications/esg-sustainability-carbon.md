# 1. CFA Institute — Sustainable Investing Certificate

Prix catalogue 2026 :

**890 $**

Le programme comprend :

- materials ;
- self-paced learning ;
- 6 mois d'accès ;
- environ **100 heures** ;
- **1 examen** ;
- 20 Professional Learning Credits selon CFA Institute.

Le contenu couvre notamment :

- ESG ;
- climate-related factors ;
- analyse ;
- valuation ;
- portfolio construction ;
- sustainable investing.

Source :

- https://www.cfainstitute.org/programs/sustainable-investing-certificate

# 2. IFRS Foundation — FSA Credential

Le **FSA Credential** est désormais directement lié à l'écosystème ISSB / sustainability-related financial information.

Il faut réussir **deux examens**.

## Level I

- non-membre : **450 $** ;
- IFRS Sustainability Alliance member : **400 $** ;
- aucun prérequis.

## Level II

- non-membre : **650 $** ;
- Alliance member : **500 $** ;
- prérequis : avoir réussi Level I.

## TCO examens depuis zéro

### Non-membre

```text
Level I       450 $
Level II      650 $
------------------
Total       1 100 $
```

### Alliance member — prix examens

```text
400 + 500 = 900 $
```

mais il faut évidemment intégrer le coût de l'adhésion si elle est souscrite uniquement pour bénéficier de la remise.

### Groupes

IFRS affiche également des prix groupés :

- 5–29 candidats : **900 $** par personne pour I+II ;
- 30–49 : **850 $** ;
- 50+ : **800 $**.

Source :

- https://www.ifrs.org/products-and-services/sustainability-products-and-services/fsa-credential/

# 3. GHG Management Institute — Certificate of Proficiency

GHGMI propose des cours techniques en GHG accounting, verification et carbon management.

Tarification standard :

- cours seul : généralement **300 $** ;
- cours + examen pour un **Certificate of Proficiency** : généralement **435 $** ;
- cours GHG Verification : **400 $** course-only ou **750 $** avec examen/certificate.

Source :

- https://ghginstitute.org/how-does-it-work/

### Exemple

`Basics of Organizational GHG Accounting` se trouve dans une fourchette autour de 275–490 $ selon formule active.

Ces certificates individuels se situent donc souvent sous ou autour de 500 $.

# 5. GHG Professional designation — EP(GHG)

GHGMI documente aussi la désignation professionnelle **EP®(GHG)**.

Tarifs en dollars canadiens :

- application EP(GHG) : **350 CAD** ;
- renewal annuel : **230 CAD**.

Pour EPt(GHG) :

- application : **230 CAD** ;
- renewal : **130 CAD/an**.

Le maintien exige notamment :

- professional development ;
- work logs GHG ;
- respect du code éthique ;
- renouvellement de période de certification tous les **5 ans**.

Source :

- https://ghginstitute.org/certification-professionnelle/

> L'éligibilité professionnelle et les éventuels prérequis de formation doivent être intégrés au TCO d'une candidature depuis zéro.

# 6. IEMA — Environment & Sustainability

IEMA fonctionne davantage comme un **professional membership framework** que comme une simple série de vouchers.

## Associate — AIEMA direct entry

Pour une personne disposant déjà des connaissances nécessaires, IEMA propose une voie d'entrée directe avec examen.

Prix publié :

**263 £**

composé de :

- **97 £ application fee** ;
- **166 £ première année de membership**.

Renouvellement : **166 £/an**.

L'examen online dure environ une heure et peut être orienté environment ou sustainability.

Source :

- https://www.iema.net/membership/join/professional-membership/

## Foundation Certificate in Environmental Management

Le Foundation Certificate mène directement à Associate Membership.

Le prix dépend du **Training Partner** choisi, IEMA ne publie donc pas un tarif mondial unique.

## Practitioner

Le Certificate in Environmental Management peut conduire au niveau Practitioner / PIEMA ; là aussi, le coût de formation dépend du partenaire.

Sources :

- https://www.iema.net/learn/courses/foundation-certificate-in-environmental-management/
- https://www.iema.net/learn/courses/iema-certificate-in-environmental-management/

# 7. GARP SCR / Sustainability and Climate Risk

Le dépôt documente déjà **GARP SCR** dans le catalogue premium finance/risk.

Grille 2026 typique :

- GARP credential holder : **625 $** ;
- Individual member : **650 $** ;
- non-member : **750 $** ;
- taxes éventuelles.

SCR reste l'un des credentials les plus identifiables pour :

- climate risk ;
- sustainable finance ;
- transition risk ;
- physical risk ;
- risk management.

Voir : [`paid-over-500.md`](paid-over-500.md).
