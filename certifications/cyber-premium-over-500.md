# Cybersécurité premium — certifications pratiques et parcours >500 €

> Tarifs vérifiés fin août 2026. Pour les examens en devises étrangères, la frontière dépend de la TVA et du taux de change ; le fichier conserve donc la devise officielle.

---

# 1. CREST

CREST propose une progression particulièrement claire : Practitioner → Registered → Certified.

## Prix 2026

| Niveau | Credentials | Prix hors taxes |
|---|---|---:|
| Practitioner | CPSA, CPTIA, CPIA | **275 £** |
| Registered | CRT, CRTIA, CRIA | **600 £** |
| Certified | CCT INF, CCT APP, CCRTS, CCRTM, CCTIM, CCIM | **1 600 £*** |

`*` CREST précise que les examens de niveau Certified sont composés de deux parties qui doivent être réservées séparément.

Les taxes applicables sont ajoutées au checkout Pearson VUE.

Source :

- https://www.crest-approved.org/skills-certifications-careers/certifications-pricing-booking/

### Lecture

- Practitioner reste dans le catalogue `<500` ;
- Registered dépasse déjà 500 € au change courant ;
- Certified est une certification technique premium.

# 2. OffSec

## Course + Certification Exam Bundle

Pour de nombreux parcours 200/300-level, OffSec affiche :

**1 749 $**

avec :

- 90 jours d'accès cours/labs ;
- une tentative d'examen.

Exemples :

- OSCP+ / PEN-200 ;
- OSEP / PEN-300 ;
- OSWE / WEB-300 ;
- OSED / EXP-301 ;
- autres tracks selon catalogue.

Sources :

- https://portal.offsec.com/checkout/
- https://www.offsec.com/courses-and-certifications/

## Learn One

**2 749 $ / an**.

Comprend :

- 365 jours sur un cours 200/300 ;
- 2 tentatives d'examen ;
- Proving Grounds Practice ;
- bonus KLCP + OSWP ;
- contenus fondamentaux.

Source :

- https://www.offsec.com/products/learn-one/

## OSCP+ exam-only

Pour une personne sans OSCP et sans bundle actif, OffSec documente un examen standalone à **1 699 $** avec deux tentatives.

Les retakes standard après épuisement des tentatives de bundle sont autour de **249 $** selon les règles du programme.

Source :

- https://help.offsec.com/hc/en-us/articles/29840452210580-Changes-to-the-OSCP

# 3. OSCE3

OSCE3 n'est pas un examen unique.

Le titre s'obtient en cumulant :

- OSEP ;
- OSWE ;
- OSED.

Au tarif Course + Cert de **1 749 $ × 3**, un parcours depuis zéro représente environ :

```text
5 247 $
```

avant taxes et retakes.

Avec Learn One pour chaque parcours, le coût peut être encore supérieur mais donne davantage de temps et de tentatives.

Le credential OSCE3 est donc un bon exemple de **TCO multi-certifications**.

---

# 4. OSEE — OffSec Exploitation Expert

OSEE est séparé du modèle Learn One.

OffSec précise que :

- l'examen OSEE est réservé aux participants ayant suivi la formation live **Advanced Windows Exploitation (EXP-401 / AWE)** ;
- Learn One ne donne pas accès à l'examen ;
- l'examen pratique dure environ 72 heures.

Le coût dépend donc du prix de la session AWE / événement et des déplacements éventuels.

Source :

- https://help.offsec.com/hc/en-us/articles/4403407883156-Learn-One-FAQ
- https://help.offsec.com/hc/en-us/articles/360046458732-EXP-401-Advanced-Windows-Exploitation-OSEE-Exam-Guide

**Statut prix exact : session-dependent.**

# 5. Altered Security — bundles avancés

Beaucoup de certifications Altered Security sont individuellement sous 500 € avec le plan minimal :

- CRTP : 249 $ ;
- CRTE : 299 $ pour 30 jours ;
- autres tracks selon lab.

Mais les learning paths cumulés deviennent premium.

Exemples observés :

- Advanced Learning Path bundle : environ **2 380 $ après remise** ;
- bundle plus large : environ **3 091 $ après remise**.

Les bundles incluent plusieurs certifications et labs ; ils doivent être comparés au prix unitaire de chaque credential.

Source :

- https://www.alteredsecurity.com/on-prem-red-team-labs

### Renouvellement

Altered Security a revu son modèle en 2026 : les certifications expirent, mais le renouvellement peut inclure gratuitement le cours et une tentative de renouvellement pour les titulaires éligibles ; lab supplémentaire et retakes restent optionnels.

Source :

- https://www.alteredsecurity.com/post/renewal-process-for-altered-security-certifications

---

# 6. Zero-Point Security — bundle

Les certifications individuelles RTO / RTO II restent proches ou sous 500 € selon conversion :

- RTO : 365 £ course-only + exam ;
- RTO II : 399 £ course-only + exam.

Le bundle **RTO + RTO II** course-only, avec les deux vouchers, est affiché à :

**724 £**.

Source :

- https://training.zeropointsecurity.co.uk/bundles/red-team-courses

Il s'agit cependant d'un bundle de deux credentials, pas d'un prérequis obligatoire pour l'un d'eux.

---

# 7. GIAC / SANS — extrême premium

GIAC facture autour de **999 $** pour de nombreux examens challenge / certification sans formation.

La formation SANS associée peut porter le TCO dans plusieurs milliers de dollars ou euros par certification.

Le bon classement doit donc distinguer :

```text
GIAC exam only
vs
SANS course + GIAC attempt
```

Source :

- https://www.giac.org/pricing

### GSE

Le GIAC Security Expert et les parcours multi-GIAC doivent être évalués comme des trajectoires cumulatives avec plusieurs prérequis, et non comme un simple voucher.

# Valeur / coût

Le marché cyber premium se divise en trois philosophies :

## Examen indépendant

CREST / GIAC.

## Formation + examen hands-on

OffSec / Altered Security / Zero-Point.

## Trajectoire cumulative

OSCE3 / GSE / bundles avancés.
