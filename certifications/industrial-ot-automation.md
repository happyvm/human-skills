# Industrial automation, OT & ICS cybersecurity

> Certifications en automatisme industriel, instrumentation, contrôle-commande et cybersécurité OT. Vérifié fin août 2026.

---

# 1. ISA — certifications professionnelles sous ~500 $

ISA propose plusieurs certifications professionnelles dont l'examen reste relativement abordable.

**Auto-formation officielle et gratuite (partielle) :** [ISA — Free Training](https://programs.isa.org/free-training) — modules self-paced gratuits en essai, Skills Development Resource Navigator gratuit.

## Certified Automation Professional — CAP

Tarifs 2026 :

- **373 $ membre ISA** ;
- **467 $ non-membre**.

Le CAP valide des compétences larges en :

- automation systems ;
- control systems ;
- instrumentation ;
- process control ;
- integration ;
- lifecycle ;
- project management ;
- operations / maintenance.

### Recertification CAP

Deux voies :

- par Professional Development Points : **270 $ membre / 340 $ non-membre** ;
- par examen : **336 $ membre / 420 $ non-membre**.

Source :

- https://www.isa.org/certification/cap

---

# 2. ISA/IEC 62443 Cybersecurity Certificate Program — premium

La famille ISA/IEC 62443 est un **certificate program**, distinct du CAP/CCST.

Chaque module comprend la formation et l'examen correspondant.

## Certificate 1 — Cybersecurity Fundamentals Specialist

Cours IC32 : *Using the ISA/IEC 62443 Standard to Secure Your Control Systems*.

Tous les formats principaux sont affichés à :

- **1 728 $ membre** ;
- **2 160 $ non-membre**.

Formats : classroom, virtual classroom, instructor-guided online, self-paced modular.

---

## Certificate 2 — Cybersecurity Risk Assessment Specialist

Cours IC33 : *Assessing the Cybersecurity of New or Existing IACS Systems*.

Tarifs :

- classroom / virtual / instructor-guided : **2 520 $ membre / 3 150 $ non-membre** ;
- self-paced modular : **1 728 $ membre / 2 160 $ non-membre**.

---

## Certificate 3 — Cybersecurity Design Specialist

Cours IC34 : *IACS Cybersecurity Design & Implementation*.

Tarifs :

- classroom / virtual : **2 520 $ / 3 150 $** ;
- self-paced modular : **1 728 $ / 2 160 $**.

---

## Certificate 4 — Cybersecurity Maintenance Specialist

Cours IC37 : *IACS Cybersecurity Operations & Maintenance*.

Tarifs :

- classroom / virtual : **2 520 $ / 3 150 $** ;
- self-paced modular : **1 728 $ / 2 160 $**.

---

## ISA/IEC 62443 Cybersecurity Expert

ISA indique qu'une personne qui obtient les **Certificates 1 à 4** reçoit la désignation :

**ISA/IEC 62443 Cybersecurity Expert**.

Aucun renouvellement des certificats 62443 n'est requis.

### TCO minimal depuis zéro — self-paced

En prenant systématiquement le format self-paced le moins cher publié :

```text
IC32M   1 728 $ membre / 2 160 $ non-membre
IC33M   1 728 $ / 2 160 $
IC34M   1 728 $ / 2 160 $
IC37M   1 728 $ / 2 160 $
-------------------------------------------
Expert  6 912 $ membre / 8 640 $ non-membre
```

Le membership ISA peut évidemment modifier le TCO réel et doit être ajouté si l'on choisit la grille membre.

Sources :

- https://www.isa.org/certification/certificate-programs/isa-iec-62443-cybersecurity-certificate-program
- https://www.isa.org/certification/certificate-programs/certificate-programs-faqs

# 4. Schneider Electric University / Data Center Certified Associate

Schneider Electric University propose gratuitement plusieurs centaines de cours, notamment sur :

- énergie ;
- datacenter ;
- power ;
- cooling ;
- efficiency ;
- physical infrastructure.

Le **Data Center Certified Associate — DCCA** valide des fondamentaux :

- cooling ;
- power ;
- racks ;
- cabling ;
- fire protection ;
- management ;
- physical security.

Les cours de préparation sont gratuits. Schneider indique cependant que **l'examen de certification est payant**.

Le tarif public actuel de l'examen n'est pas suffisamment exposé pour être figé dans le catalogue 2026.

Source :

- https://www.se.com/ww/en/work/support/resources-and-tools/training/energy-university/

**Statut : prix final à récupérer via le portail de certification.**

# Lecture valeur / coût

## Automatisme général

**ISA CAP** est probablement le credential le plus lisible sous 500 $.

## Technicien contrôle / instrumentation

**CCST**.

## OT cybersecurity

Le programme **ISA/IEC 62443** a un signal fort mais son TCO est sans commune mesure avec les certifications IT classiques.

## Functional safety / SIS

Les certificates ISA SIS visent des profils industriels beaucoup plus spécialisés.
